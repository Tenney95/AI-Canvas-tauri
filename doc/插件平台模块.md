# 插件平台

插件市场、发布元数据和插件资源下载支持 GitHub 网络故障后单次国内加速；保留原仓库身份、包校验和大小上限。共用边界见 [GitHub 下载加速](./plans/2026-10-18-github-download-fallback.md)。

负责用户插件的安装、更新、启停、信任注册、节点工具执行和自定义 UI。插件接口详细合同统一维护在[插件开发规范](./插件开发规范.md)。

## 运行时合同与开发支持

- `plugin_host_inspect` 通过 Registry/MCP 返回有界公开合同、能力和按需健康状态；不反射内部服务，不返回源码、路径或凭据。目录入口是 `pluginContractCatalog.ts`，工具入口为 `chat/tools/pluginInspectionTools.ts`。
- 插件设置的诊断区分用户启用与原生活动 revision，复用 `get_plugin_registration_status` 核对摘要及私有快照；刷新不会重新安装或激活。
- 开发界面预览从用户选择目录加载已校验 UI，以模拟数据运行在专用 opaque iframe 中；不安装/激活，不执行主工具、Python、模型、联网或文件 effect。生产 loader 的私有协议限制不变。
- API 2 可声明至多 16 个依赖并要求 `plugin.dependencies` 能力。必需依赖缺失/版本不足或图循环阻塞，可选缺项只诊断；没有跨插件 RPC。原生 registry 是可用性权威，依赖换版/停用/卸载撤销反向调用与资源，旧结果不得写回。
- `pluginLifecycleScope.ts` 对宿主管理的资源逆序、幂等清理；依赖图事务协调保留无依赖插件间并行，不把关闭 UI 等同取消允许后台执行的复刻任务。

上述能力已写入，**本次未运行测试，待用户验收**。统一范围、桌面步骤与回退见 [Harness 借鉴专项](./plans/2026-11-06-harness-capabilities.md)；不以模拟预览代替真实安装/原生隔离验收。

## 关键边界与当前交互

- 工具和自定义节点的每轮 `input.locale`、自定义界面的 `props.locale` 提供实际生效的宿主语言。内嵌界面实时同步，独立窗口重新聚焦时同步；仅更新语言并通知插件重绘，不重新挂载或覆盖编辑参数。插件自行维护翻译字典，宿主不传递完整配置或字典。

- 运行身份同时绑定 `sourceDigest` 与 `revisionDigest`；原生注册表是执行权威，停用、卸载或更新后旧租约不得继续写回。
- API 2 增加最低宿主版本和所需能力声明；API 1 保持兼容。前端安装与原生 stage/启用/执行均校验声明，UI 和工具接收安全的 host 能力/额度信息。普通工具 effect 总计 32 次，各类别独立计数且模型仍最多 4 次；额度不替代权限。
- 普通节点/工具和 UI 提交均监听画布、项目与插件 revision，并向模型、网络和原生 Runtime 传递取消。单次取消仅主窗口可调用，原生登记有并发上限和取消先到记录；JS 错误保留工具、阶段及有界源码位置，不记录源码与输入。
- 本地安装成功后可在当前面板重新载入同一目录，复用原安装事务和授权；目录不持久化，ID 变化拒绝覆盖。开发 CLI 只生成与校验产物，不执行或自动安装作者代码。
- `network.request` 按 Manifest 精确 HTTPS 来源授权，原生确认绑定 revision；DNS 公共地址校验、连接固定、禁重定向/代理、超时及体积限制都在 Rust 执行。`settings.read/write` 仅保存插件自己的非敏感偏好，更新/重启保留、卸载清理，设置写入与版本变更共用注册表锁。两个新增命令仅授予第一方主窗口，插件页面继续通过受信 UI Broker 调用。
- UI 参数补丁与提交在合并后严格校验，超限保留原值；联网与设置各有独立操作额度，不占模型额度。关闭、停用或换版撤销请求与租约，迟到结果不得生效。JSON 与 API 合同见插件开发规范。
- 本地安装区在桌面端接收当前 WebView 的原生拖放，按窗口缩放比例判断落点，只处理上传区内的插件目录或清单；浏览器端保留 HTML 拖放。面板打开期间阻止画布接收外部文件，关闭后清理监听并恢复；读取和安装仍复用清单声明校验与原生信任确认。
- 卸载先停用当前会话并撤销资源授权，原生注册和 IndexedDB 记录均删除成功后才移除列表项；任一步失败都保留停用项供重试，并尝试持久化停用状态，避免重启后造成“已删除插件重新出现”的错觉。注册表 JSON 损坏且无法从备份恢复时，设置页提供显式修复入口；原生二次确认后重建空注册表、终止全部插件调用并清理私有 revision，IndexedDB 安装记录保留但统一停用，供用户卸载或重新安装。权限、路径和普通 I/O 错误不得触发重建。
- 内嵌 UI 使用隔离 iframe；独立 UI 使用专用 WebView。模型、文件 effect 和画布写回由主窗口宿主执行。可信 Python 是当前用户权限的本地代码，不是 OS 沙箱。
- 逐帧拉片默认在主窗口弹窗显示，关闭按钮旁提供独立窗口入口；创建或聚焦成功后关闭原弹窗，失败保留。当前不迁移未保存的镜头编辑或模型选择。
- 逐帧拉片的原视频位于采样方式和分析设置之间；当前预览通过分段读取生成页面 Blob，单视频上限 16 MiB。插件本体由独立仓库维护、用户安装，宿主这里只管理公共能力。
- `image.lineArt` 仅处理当前调用已授权的派生图像，复用已有读取/输出权限及本地媒体操作额度，不调用模型或重复消耗分段读取额度。每个原图 ID 最多缓存一个线稿 PNG，与原图共用 48 MiB 额度，并随资源租约撤销。
- 节点集图像可选择 `original` / `lineart` 表示，省略时使用原图；宿主整批预检后保存实际选定字节，分镜引用同批文件。缺失线稿拒绝输出，保存或最终写回失败回收已写文件。插件需与支持此操作的宿主配套更新，旧宿主不能生成线稿节点。
- API 2 可信 Python 节点工具可显式声明 `pythonExecution`：时限 30–120 秒，只从活动 revision 读取；未声明的工具仍为 30 秒。媒体工作区仅暂存当前节点的一个已授权视频（最多 256 MiB），原生路径只进入本轮可信 Python。产物限定 MP4、每项 16 MiB、总计 48 MiB、最多 18 项，经路径/文件结构/摘要校验后以不透明 ID 回传，宿主通过 `artifactKey` 原子导入视频节点。
- 媒体工作区与调用、工具及双摘要绑定，新增命令仅接受真实主窗口。取消、换版、停用和最终释放撤销工作区；文件导入失败或过期写回回收本轮已保存文件。视频复刻业务独立维护为用户插件，宿主不内置 ReShot、模型权重或自动安装 Python 依赖。
- `video.nodeSetGeneration` 显式授权最多 6 个逐镜视频生成条目；安全目录覆盖已配置 API 模型及 ComfyUI 视频工作流。节点一次提交后调用既有视频批次，长轮询不占插件 UI 会话；失败保留素材和节点，不自动重投。
- `video.replicaPipeline` 为可信 Python 视频插件提供主窗口后台全片任务：自动或手动切点后按有效模型能力再拆分，逐段提取控制素材、音频/对白、生成并裁切合成。上限 300 秒、64 段、512 派生节点和 1 个并行任务；状态查询独立计数。启动后 UI 仅观察绑定任务，关闭后任务继续，旧句柄同步释放。重启、未知提交不自动续跑或重投。
- 全片任务复用视频批次、生成器和剪辑导出；可选生成/导出租约在提交、返回和写回前复核版本、项目与输入。源视频、替换引用及派生素材变更后拒绝旧结果。默认配回原片声音，另支持模型声音或静音；SenseVoice 只返回分段对白文本，首次权重下载须明确选择。控制推理依旧由用户插件执行，宿主不安装 ReShot。
- 视频复刻仅保留一键全片流程与时间轴切点；Python 工具只接受后台任务的 `replicate-segment`，已删除手动镜头编辑与独立物料提交。`video.playbackPreview` 为大文件准备连续预览，隔离页面使用原生 `<video>`，以媒体时钟同步时间轴；专用顺序读取无 12/16 MiB 预览体积限制，不能用于任意文件读取，普通资源额度不变。实现与桌面验收缺口见视频复刻专项计划。
- `prompt.mentions` 与 `prompt.references.read` 为隔离 UI 提供现有提示词来源：当前/上游节点、项目人物/场景/道具、全局角色及资源库图片。插件只持有调用级不透明引用；正文和实际素材由宿主解析，最终改写为正式提示词引用。引用变更或租约撤销拒绝写回，候选查询不消耗模型额度。全局角色以明确作用域解析，不隐式复制进项目。
- 引用查询可显式请求有界缩略图，宿主重编码后仅返回 JPEG data URL、裁剪参数和小标；源路径、源地址和原图不跨越隔离边界。视频复刻插件在构建时直接复用共享 `MentionPicker` 及其 CSS，React 展示依赖随插件 UI 打包，不加载主应用或访问其存储。

## 安装时准备本地语音模型

声明 `video.replicaPipeline` 的插件在 GitHub 安装／更新、本地导入和桌面拖放时，均在信任审核后检查 SenseVoice 权重与词表。缺失或校验不符时，可选择“下载并继续安装”或“仅安装插件”；选择下载后，模型未准备完成不会进入插件暂存事务。取消下载停止本次安装，已完成的模型文件保留；失败不影响此前安装的插件版本。已安装插件的设置卡片提供“准备语音模型”入口，不要求重装插件。语音转写仍是可选功能，不下载模型时可关闭对白转写。

资源元数据集中在 `src/constants/localSpeechModels.json`，固定公开上游版本、文件大小和 SHA-256，前端与 Rust 共用。缓存和新下载均校验完整内容，错误页、Git LFS 指针、截断或损坏文件不能被当作已安装。下载继续复用模型目录、字节进度、取消和临时文件发布边界，不新增解释器、Python 包或 ReShot 下载。

模型下载使用 Hugging Face 官方源和 `hf-mirror.net` 国内镜像，按实际目标文件的有界前缀选择来源，完整下载并通过校验后才缓存成功源；网络或临时 HTTP 故障最多切源一次。取消、本地存储和内容校验失败不切源，整个下载结束后才清理取消身份。复刻界面保留宿主生成的安全下载原因，不向插件传递原始 URL、路径或错误正文。插件包的 GitHub 国内加速仍走独立的 `gh-proxy.com` 策略。

2026-10-28 源码已实现，待用户验收。本机有限联网检查确认旧 `hf-mirror.com` 对这两个语音文件返回 308 并跳回官方；替代镜像的固定版本小范围读取可独立返回数据，声明大小与官方一致。仅完整读取了小词表以计算摘要，没有下载完整权重，也未验证其他地区网络。本次未运行测试、类型检查、编译、打包或桌面验收；提交时由既有钩子对本批 TS／TSX 文件执行定向 ESLint，通过后才提交。

1. 在无语音模型的环境，从插件市场安装复刻插件并通过信任审核，应提示下载或仅安装；下载时设置窗口上方显示真实字节进度。完成后再进入原生插件确认，安装成功后开启对白转写，应不再因缺失模型报错。已有完整模型时不弹下载、不访问模型网络。

## 可信 Python 运行时

Python 插件沿用 Manifest 的 `runtime: "python"`／`main.py`，JavaScript 沿用 `main.js`。原生 `plugins/runtime.rs` 探测本机可用 Python 3，通过独立子进程的有界 stdin/stdout JSON 信封执行活动 revision 中的代码；复用已有 site-packages，不自动安装 requirements、下载解释器或创建环境。缺少解释器、超时或输出／协议无效应明确失败，不写回画布。

这是当前用户权限的可信代码，并非 OS 沙箱。安装、更新、重新启用仍须原生高风险确认；普通执行 IPC 只提交插件 ID、双摘要、工具和调用身份及裁剪输入，代码与 runtime 由原生注册表解析。旧实施步骤中的 Renderer 传源码／runtime 或 `trustedPythonConfirmed` 布尔授权已被[原生信任注册表](./adr/0010-native-plugin-trust-registry.md)取代，不能重新作为实现合同。宿主字段、effect、项目／revision 与派生写回校验同样适用，不向 Agent／MCP 新增任意 Python 或 Shell 工具。

Python 初版计划没有单独记录已执行检查；后续阶段的实际验证、Windows／Linux／发布包及原生授权交互缺口保留在[插件平台专项](./plans/2026-08-23-user-plugin-platform.md)。本次未运行测试。验收需分别检查缺解释器、导入本机包、原生确认接受／拒绝、取消／超时及迟到结果拒绝；进程回收不能替代对插件来源的信任。回退需停用不兼容插件并保留其用户数据，不能通过恢复旧 IPC 或降低注册表校验来兼容。
