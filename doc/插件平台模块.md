# 插件平台

负责用户插件的安装、更新、启停、信任注册、节点工具执行和自定义 UI。插件接口详细合同统一维护在[插件开发规范](./插件开发规范.md)。

## 主要入口

| 入口 | 职责 |
|---|---|
| [PluginSettings.tsx](../src/components/settings/PluginSettings.tsx) / [store.plugins.ts](../src/store/store.plugins.ts) | 安装管理与原生注册编排 |
| [pluginRuntime.ts](../src/services/plugins/pluginRuntime.ts) / [pluginResourceService.ts](../src/services/plugins/pluginResourceService.ts) | 执行、宿主 effect 和不透明资源授权 |
| [pluginUiSessionService.ts](../src/services/plugins/pluginUiSessionService.ts) / [pluginUiWindowService.ts](../src/services/plugins/pluginUiWindowService.ts) | 内嵌 UI 会话与独立窗口生命周期 |
| [原生 plugins](../src-tauri/src/plugins/) | 私有快照、活动 revision、执行与 UI 原生边界 |

## 关键边界与当前交互

- 运行身份同时绑定 `sourceDigest` 与 `revisionDigest`；原生注册表是执行权威，停用、卸载或更新后旧租约不得继续写回。
- 内嵌 UI 使用隔离 iframe；独立 UI 使用专用 WebView。模型、文件 effect 和画布写回由主窗口宿主执行。可信 Python 是当前用户权限的本地代码，不是 OS 沙箱。
- 逐帧拉片默认在主窗口弹窗显示，关闭按钮旁提供独立窗口入口；创建或聚焦成功后关闭原弹窗，失败保留。当前不迁移未保存的镜头编辑或模型选择。
- 逐帧拉片的原视频位于采样方式和分析设置之间；当前预览通过分段读取生成页面 Blob，单视频上限 16 MiB。插件本体由独立仓库维护、用户安装，宿主这里只管理公共能力。
