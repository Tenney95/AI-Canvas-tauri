# 桌面运行时与安全

负责 Tauri 应用命令、窗口调用方校验、路径与凭据保护，以及原生下载、推理和进程生命周期边界。插件与导演台的业务协议各自维护。

## 主要入口

| 入口 | 职责 |
|---|---|
| [lib.rs](../src-tauri/src/lib.rs) | Tauri Builder、插件装配与命令注册 |
| [path_policy.rs](../src-tauri/src/path_policy.rs) | 调用方窗口与真实路径授权校验 |
| [secret_store.rs](../src-tauri/src/secret_store.rs) / [providerSecretService.ts](../src/services/providerSecretService.ts) | 原生凭据存储与前端桥接 |
| [permissions](../src-tauri/permissions/) / [capabilities](../src-tauri/capabilities/) | 命令 allow/deny 与窗口 capability 声明 |
| [原生 media](../src-tauri/src/media/) | ONNX Worker、模型下载与媒体原生能力 |

## 关键边界

- Tauri 外层 ACL 与命令内部调用方/路径校验同时保留；新增命令同步准确的权限声明，不能为了构建或功能放松安全配置。
- secrets、agent-private、plugin-private 与 Blender 私有目录不得经通用文件能力暴露，递归操作还需拒绝这些目录的祖先。
- 原生凭据不回落到普通配置或 IndexedDB；进程回收、超时和 Job Object 属于生命周期控制，不等于 OS 沙箱。
- Rust 源码按领域目录维护，禁止在一般功能变更中顺手重构逻辑命名空间。
