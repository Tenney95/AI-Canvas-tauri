# 桌面运行时与安全

负责 Tauri 应用命令、窗口调用方校验、路径与凭据保护，以及原生下载、推理和进程生命周期边界。插件与导演台的业务协议各自维护。

## 主要入口

| 入口 | 职责 |
|---|---|
| [lib.rs](../src-tauri/src/lib.rs) | Tauri Builder、插件装配与命令注册 |
| [native_rendering.rs](../src-tauri/src/native_rendering.rs) / [nativePerformanceModeService.ts](../src/services/nativePerformanceModeService.ts) | Windows 性能模式启动参数、设置同步与保存后重启 |
| [path_policy.rs](../src-tauri/src/path_policy.rs) | 调用方窗口与真实路径授权校验 |
| [secret_store.rs](../src-tauri/src/secret_store.rs) / [providerSecretService.ts](../src/services/providerSecretService.ts) | 原生凭据存储与前端桥接 |
| [permissions](../src-tauri/permissions/) / [capabilities](../src-tauri/capabilities/) | 命令 allow/deny 与窗口 capability 声明 |
| [原生 media](../src-tauri/src/media/) | ONNX Worker、模型下载与媒体原生能力 |

## 关键边界

- 独立助手窗口打开/关闭串行处理；已有窗口恢复并聚焦，关闭完成后释放标签。Windows 性能参数经进程环境统一应用，避免共享 WebView2 profile 的主/独立窗口 EnvironmentOptions 不一致。前端三入口统一防重与失败恢复，见[双窗口专项](./plans/2026-10-03-chat-window-state-sync.md#2026-10-12-打开失败补丁)；真实桌面操作待用户验证。

- Agent Package 的 `.aicanvas-agent` / `.tgz` / `.tar.gz` 导入复用 [agent/package.rs](../src-tauri/src/agent/package.rs) 的解包与清单校验。全局 PAX 只按归档元数据处理；局部 PAX 解析后的实际路径继续校验，超限元数据、链接和特殊项仍拒绝。Renderer 可显示原生返回的导入错误，但不能因此恢复包内脚本执行或任意路径访问。
- 方舟本地用量账本通过 `lib.rs` 注册的用途固定 billing commands 访问 SQLite；目录配置、迁移、导出及手动清理沿用原生边界，不能将账本目录扩展成通用任意文件能力。业务及验收归[模型与生成](./模型与生成模块.md)。

- Windows 性能模式在主窗口创建前读取原生布尔开关，采用不透明主窗口与固定 `--force-gpu-mem-available-mb=4096`，保留硬件加速；普通模式保持原窗口配置与浏览器参数。开关只经已校验本地来源的主窗口命令写入固定配置文件，不接受路径、脚本或任意浏览器参数。
- 开启性能模式先保存配置，再在主窗口遮罩下收集防抖设置、冻结设置写入、保存当前项目并复核项目/画布未变化，然后自动重启；保存失败留在应用内并解除冻结。已有前端性能模式的用户在项目启动完成后补齐一次原生配置；原生状态已匹配时不重复重启。关闭后下次启动恢复原生默认，运行中的任务会随重启中断。范围与验收见[性能模式原生兼容修复](./plans/2026-09-09-canvas-interaction-performance.md#第十批windows-原生性能模式与保存后自动重启)。

- Tauri 外层 ACL 与命令内部调用方/路径校验同时保留；新增命令同步准确的权限声明，不能为了构建或功能放松安全配置。
- ComfyUI 安装选择由 [installation.rs](../src-tauri/src/media/comfyui/installation.rs) 的主窗口原生命令私有持久保存，启动及管理逐次复核；普通配置路径仅是显示镜像，重启不依赖易失 fs scope。旧镜像无原生记录时需要既有合法授权或一次原生信任确认；更换走原生选择器，取消/保存失败保留旧授权。`privacy_plugin` 紧随 fs 插件注册，在 `Builder::build` 的插件初始化阶段拒绝私有记录的 fs/asset 访问，早于各平台配置窗口/Renderer 创建；初始隔离失败终止应用启动，每次记录读写再次复核。通用路径入口同样拒绝该私有域及递归访问其祖先；损坏、离线或链接替换失败关闭，未提交临时记录不能恢复授权。独立管理窗口仅持有用途限定的内存会话，不扩大公共 fs/asset scope；关窗撤销会话并回收管理进程树。源码识别限定安装根内固定候选，根外同级源码不自动纳入授权；无源码的 Windows 安装只保留默认固定启动器兜底。Git 下载默认停用，pip 依赖另经原生确认，不执行 `install.py`，原始进程输出不回传 Renderer 日志。已实现，待用户验证；本次未运行测试，验收与回滚见[ComfyUI 独立管理计划](./plans/2026-10-11-comfyui-management.md)。
- secrets、agent-private、plugin-private 与 Blender 私有目录不得经通用文件能力暴露，递归操作还需拒绝这些目录的祖先。
- 原生凭据不回落到普通配置或 IndexedDB；进程回收、超时和 Job Object 属于生命周期控制，不等于 OS 沙箱。
- 凭据读取、条件比较、更新和删除共用原生 `credentials.lock` 跨进程锁，最多等待 1 秒，在 blocking worker 中运行。锁文件随主文件/临时文件纳入 asset 拒绝清单，fs scope 与 path_policy 仍拒绝整个私有目录。写入先同步临时文件，再替换并同步当前文件；Unix 另同步父目录。保留原 JSON 字符串映射格式，不从临时文件或旧备份自动恢复凭据。
- 凭据 IPC 只返回白名单错误代码；缺失、锁忙/共享冲突、权限拒绝、损坏、空间不足和未知失败分开处理，不返回系统路径或凭据。写入/删除支持可选预期值或 SHA-256 指纹，新调用在锁内比较，旧调用参数仍兼容。旧版本不遵守跨进程锁协议时不保证并发安全。
- [设置可靠性验收](./plans/2026-09-11-settings-reliability/task_plan.md)：Windows 原生凭据 10 项、路径边界 7 项测试及默认特性 cargo check 通过；包含三个独立测试进程写入和退出后释放锁。定向测试使用 --no-default-features 排除本机 MSVC/ONNX 链接不兼容；未完成默认特性测试链接、真实桌面重启、突然断电或 Unix 运行时验收。
- Rust 源码按领域目录维护，禁止在一般功能变更中顺手重构逻辑命名空间。
