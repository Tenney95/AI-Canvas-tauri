# 桌面运行时与安全

负责 Tauri 应用命令、窗口调用方校验、路径与凭据保护，以及原生下载、推理和进程生命周期边界。插件与导演台的业务协议各自维护。

Muse 的登录和任务使用专用外部 WebView，不授予 Muse 页面应用 capability；原生命令复核受信调用方，页面回传还须匹配窗口、来源和随机请求身份。登录 Cookie 只保存在 `secret_store` 的原生专用 `muse/session` 条目，Renderer 通用凭据命令拒绝 `muse/`。隔离 profile 和结果位于凭据私有目录，沿 fs、asset 与路径策略拒绝普通访问；页面只获得固定生成脚本。媒体取回分块并核验体积、文件头和参考图摘要。实现与尚未验收的跨平台边界见 [Muse 专项](./plans/2026-11-09-muse-webview.md)。

## 外部 Codex 执行器

`agent/codex_runtime.rs`、`codex_process.rs`、`codex_protocol.rs`、`codex_contract.rs` 实现固定 0.167.0 的受限建议调用。七条 `codex_runtime_*` 命令由专用权限/capability 仅授予本地真实 main，内部再次检查调用方；独立助手/工作台通过主窗口协议请求，不传 executable/argv/cwd/env。

用户须原生登记并信任本机程序；摘要绑定不构成 OS 沙箱。原生生成私有 HOME/cwd、固定 provider/静态 ModelInfo、只读与 never、关闭危险工具/Skill/MCP/插件，拒绝额外配置或组织要求。凭据只存现有 secret_store 的固定条目，原生仅注入所属子进程，不复制桌面 auth 或订阅账户。配置预检完成前不发送任务文本。

登记版本查询及每次执行都从已打开的源句柄生成私有可执行快照，复制限额并检查取消，回读摘要一致才启动；Windows 保持拒绝写/删除共享的快照读句柄，Unix 目录/程序为用户私有权限。原安装路径的后续替换不改变本次实际运行字节，结果仍须通过 generation、程序与凭据身份的最终复核。

turn/start 交给 writer 前记录 turnSubmitted；仅明确 false 的终态回执证明未启动，无记录或晚期租约变化仍是未知。取消传 interrupt 并回收所属进程树，不声称撤销账单或外部副作用。真实固定版本桌面调用、取消与 ACL **尚未验收**；完整来源、权限表和回退见 [专项](./plans/2026-11-06-harness-capabilities.md#46-外部执行器的新增原生权限)。

- 凭据读取、条件比较、更新和删除共用原生 `credentials.lock` 跨进程锁，最多等待 1 秒，在 blocking worker 中运行。锁文件随主文件/临时文件纳入 asset 拒绝清单，fs scope 与 path_policy 仍拒绝整个私有目录。写入先同步临时文件，再替换并同步当前文件；Unix 另同步父目录。保留原 JSON 字符串映射格式，不从临时文件或旧备份自动恢复凭据。
- 凭据 IPC 只返回白名单错误代码；缺失、锁忙/共享冲突、权限拒绝、损坏、空间不足和未知失败分开处理，不返回系统路径或凭据。写入/删除支持可选预期值或 SHA-256 指纹，新调用在锁内比较，旧调用参数仍兼容。旧版本不遵守跨进程锁协议时不保证并发安全。

## 受控 SPA 网页渲染

`webPageService.ts` 保留静态 GET／正文提取优先；只在识别到 SPA 页面壳且正文不足时调用 `assistant_web_render`，结果继续进入同一提取与裁剪链。原生实现为 `src-tauri/src/agent/web.rs`：先执行公网 URL 校验，再创建隐藏、无持久登录态的隐私 WebView；限制同源顶层导航，拒绝新窗口和下载，通过只读初始化脚本与 CSP 约束网络行为，禁止表单、写请求、WebSocket、EventSource 和 sendBeacon。成功、失败及超时均尝试关闭窗口。

渲染、正文稳定、展开和翻页均有时间／数量／体积预算，不接受 Renderer 注入脚本或自由交互命令；返回内容仍是不可信网页资料。登录页、跨源导航和依赖未能完成不代表已获取正文，不能降低限制或转为通用浏览器权限。

旧实施清单未记录真实页面验收结果；源码已有 `tests/services/webPageService.test.ts` 及原生 web 单元入口，本次仅静态核对。Tauri 验收应覆盖匿名 SPA 静态回退、同源正文、加载／提取超时、窗口回收与跨源／写请求拒绝，不把单元测试当作真实 WebView 证据。回滚时一并关闭前端回退及原生命令接线，保留静态读取与公网 URL 校验，不删除用户数据或放宽 Tauri 权限。

## Windows 应用内更新与推理进程

应用内更新在签名验证完成后、启动安装器前，经 `app_update.rs` 停止接收新的本地 ONNX 推理进程，终止并有界等待当前应用拥有的 Worker 退出；无法确认退出则返回失败，不启动安装。安装失败返回时恢复接收任务。进程登记与启动共用关闭门禁，只保存本进程持有的系统句柄，不按 exe 名称批量结束其它实例或按可能复用的 PID 猜测归属。

Windows Worker 仍使用独立进程执行推理，并纳入关闭即回收的 Job Object。更新器会直接退出主进程，不能依赖 `Drop` 或普通关窗事件完成清理；Job 为已登记 Worker 在主进程退出时提供系统级兜底，安装前等待用于确认实际退出，而非只依赖安装器的固定延时。更新终止使用独立取消分类，安装失败恢复门禁后，旧推理也不会误触发 GPU 故障回退或保存 CPU 配置。Legacy 无本地 ONNX 的构建及 macOS/Linux 不新增这项更新调用，不调整下载源、验签或文件权限。

该修复覆盖源码中已确认的残留 Worker 路径；截图中的 exe 写入失败尚未在用户机器复现，仍可能涉及其它实例、目录权限或安全软件。新客户端安装后才执行新清理流程，旧版升级到修复版的首次安装仍需先保存工作并彻底退出旧进程，再重试安装；不要跳过主程序文件。无法退出的残留进程可在重启系统后重新安装，保留项目与素材数据。

本次未运行测试、构建或真实更新，待用户验收。Windows 桌面使用可丢弃的测试项目和有效签名的测试更新包，分别在未使用本地模型、完成本地推理、推理仍在执行时触发应用内更新，确认自有 Worker 已退出才启动安装，主程序可覆盖并启动；回归多窗口、重复更新、安装启动失败后的任务恢复及 GPU 配置保持、推理启动与更新并发，以及无 ONNX 的 Legacy 构建。内联测试覆盖关闭门禁、弱引用回收、锁等待期限，以及自有进程退出后取消标记保持；未覆盖真实安装器与 GPU 推理。由用户在 Windows 的 `src-tauri` 目录执行 `cargo test --lib windows_worker_lifecycle::tests`；另执行 `cargo check --lib` 和 `cargo check --lib --no-default-features` 核对本地 ONNX 与 Legacy 构建。上述命令尚未执行，不能代替桌面安装验收。

### NSIS 更新安装器按需授权（2026-10-28）

安装包继续使用 `currentUser`，更新继续使用 `passive`。[nsis-hooks.nsh](../src-tauri/windows/nsis-hooks.nsh) 仅为 `/UPDATE` 的 NSIS 原位更新增加按需 UAC：非破坏地检查现有主程序与目标目录的写入权限，仅 `ERROR_ACCESS_DENIED` 可请求同一安装器提权重启一次。普通可写目录不提权，不更改安装目录 ACL，也不要求主应用以管理员身份运行。下载、验签、自有 Worker 清理及原生安装入口沿用既有流程；不新增 Renderer 可指定程序、参数或路径的执行入口。

提权上下文使用进程令牌的真实用户 SID 校验，在页面初始化和安装前重复检查；提权实例还须确认实际令牌已提升。门禁通过后复用 Tauri 既有的当前用户进程关闭逻辑，再探测写入权限。跨账号、MSI 迁移歧义、参数超限、共享冲突或其他写入错误均停止，不猜测新的目录或安装范围。重启保留原更新、被动、重启及应用参数，目标目录参数始终放在末尾；当前用户注册表和快捷方式范围保持不变。静默 `/S` 安装不会主动请求 UAC；取消或启动失败不继续覆盖文件，交接成功只表示子安装器已启动，不代表更新完成。

该路径主要覆盖管理员成员使用普通令牌启动应用、更新受保护安装目录的情况。真正的标准账户若在 UAC 中改用另一管理员账户，会因 SID 不同而停止；应使用正确账号处理安装，或重新选择当前用户可写目录。目录和主程序探测不等于验证所有资源的单独 ACL，仍可能遇到安全软件、文件只读或其他进程占用。Tauri Windows 更新器在交给安装器后可能已经退出主应用，取消 UAC 后可按普通方式重新启动旧版；不能承诺前端继续留在原窗口。安装准备阶段可能创建目标目录或处理 WebView2，不将“未覆盖主程序”描述成安装器完全没有副作用。

状态：两文件范围已实现；使用现有 MakeNSIS 3.11 对隔离脚本执行 UTF-8、`/WX` 编译，退出码为 0、无警告，覆盖 hook 提前包含、晚定义产品参数和原进程关闭宏重复展开。仅生成临时编译产物，未运行测试、应用构建、安装器或真实提权。桌面验收使用可丢弃测试项目和有效签名的测试更新包：

2. 用同一管理员账户的普通令牌启动安装于受保护目录的旧版，保存工作后更新；应只在安装器阶段弹一次 UAC，确认后原位更新，不新增另一份安装记录。更新后按普通方式启动并核对版本、项目与素材。
