## 验证与剩余验收

用户本轮已授权提交和发版。正常 `pre-push` 在隔离检出上执行 `npm run ci`，包含全仓 ESLint、应用与测试类型检查、全量 Vitest 及生产构建；失败即阻止推送，不绕过钩子。同 SHA 源码 CI 的 `Full source quality`、`Frontend quality`、三平台 `Rust check` 与精确前端产物通过后，发布 `Quality gate` 才允许打包。Rust 保持 1.99.1，不重装或更改依赖来掩盖失败。

Tauri 桌面待验收：本地与远程有声视频提取、播放、另存、撤销／重做、保存重开、分组和自定义工具栏；无音轨、解码失败、超限、磁盘失败，以及提取／保存中换项目或换源。剧本拆分覆盖全文／章节、自动／固定集数、Skill、草案预览与应用、材料变更和未保存编辑；写作核对关系图来源与后续分集隔离。上传使用真实的图片／全媒体服务，回归缺配置、失败及方舟 TOS；平台安装和自动更新仍需实机检查。
