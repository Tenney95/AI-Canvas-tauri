## 范围与兼容性

- 本地 ComfyUI 读取所选服务真实参数声明，复用云端参数浮层、常用项排序、类型化控件及 C# 原节点编号；参数覆盖在上传前复核，保留连线、原工作流及 H3 专用设置边界。
- RunningHub 默认输入和 @ 输入绑定、定义重读保留合法选择、删除后清理编辑状态；按完整 API 图识别正面／负面／共用用途，未知保留未判定。默认正文不在普通参数重复显示，保护语音子字段与负面／共用词，取消任务不影响 UI 声明读取。
- 批量入口复用单节点执行，排队项出队前核对身份与输入，混合队列最多 3 个节点任务；导入、画布订阅、历史快照、素材索引和搜索、独立对话同步与 Markdown 区块处理收敛重复工作。不把减少重复处理等同于已测量的性能收益。

数据库仍为 v27，项目包仍为 v3，无本版新增迁移。旧客户端无法回退已升级数据库；升级前备份。项目云同步继续手动，HTTP 仅用于可信网络。Windows Legacy 不含 ONNX 或自动更新；macOS 仅 Apple Silicon，临时签名且未经公证。

## 已知限制

本地内部批量大于 1 时，当前生成与恢复仅接收首份匹配产物，浮层已提示其余在 ComfyUI 查看，完整多产物交付及恢复尚未实现；画布多节点批量是另一入口。提示词角色只追溯已支持的连线节点；旧 RH 记录需重新读取完整图。大于 JavaScript 安全整数范围的种子覆盖拒绝，不静默截断。按 C# 分组和搜索参数仍为后续建议。

## 桌面验收（待用户执行）

准备备份后的测试项目、可用本地 ComfyUI、具有权限的 RH 测试连接及包含多个采样器的工作流。以下真实调用可能产生费用，按需验收：

1. 本地与 RH 打开参数，确认常用项置顶，C# 对应原图且与画布编号区分；修改不同采样器的步数／CFG，关闭重开后独立保留，恢复默认只清该项。
2. 通过输入框与快捷指令提供正文和图片，检查 ★ 默认目标及 @ 指定目标；确认提交正文正确、负面和共用文本不被旧兜底覆盖，原工作流及连线不变。
3. 缺插件、离线、枚举或范围变化、失效字段、超大种子和 H3 专用设置冲突时应在素材上传／付费提交前提示；取消生成后重新打开参数可正常加载。语音 DynamicCombo 的 task.text 继续来自正文。
4. 内部 batch_size 设为 2 应显示首份产物限制；在 ComfyUI 核对其余产物。另验画布多节点批量：排队时改／删节点或切项目后不发旧请求，部分失败不重投付费任务，已提交项保留恢复记录。
5. 文本、Markdown 和媒体从菜单及拖放导入；异步期间切项目或删除节点后不回填错误对象。核对撤销／重做、项目缩略图、共享素材搜索，以及长对话和独立窗口最后编辑交接。
6. Windows／Legacy、Linux、Apple Silicon Mac 安装升级、更新签名、下载与首次打开仍待实机；真实付费生成、S3、双机协作、磁盘满和中断恢复未在本轮执行。
