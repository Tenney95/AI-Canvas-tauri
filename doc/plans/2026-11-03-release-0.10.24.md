## 范围与兼容性

- 数字种子默认随机，可按 C# 切固定；工作流和尺寸偏好恢复到新建空节点，图片工作流比例同步外框。输出历史支持原任务重新下载与本地放弃，不重提生成或重抽种子。
- Windows 多层素材路径、失效单产物缓存与历史来源引用的导出处理，以及缺失素材／协议字段定位；有效依赖与归档路径安全校验保持。Markdown 上传显示正文并绑定项目文件。
- 多选节点按实际拖动成员逐项结算分组归属；启动与项目切换遮罩适配主题且保持不透明。工作流列表排版、按钮和配色统一。
- 退役 MiniMax H3 文生／参考生视频普通版及 Turbo 版四项；启动和重置按原内置 ID 清理，用户沿原 ID 的修改也会清理，升级前需导出保留。手动导入的独立副本及其他 H3 图生／PDD 保留。旧 JSON 仅作兼容回归样本，内置资源配置排除。

数据库沿用 v27、项目包沿用 v3，无新增迁移。内部工作流多产物仍只接收首份，种子受安全整数及服务声明约束；旧失败历史没有原任务回执时不能凭空恢复。云同步继续手动，HTTP 仅用于可信网络。Windows Legacy 不含 ONNX 或自动更新；macOS 仅 Apple Silicon，临时签名且未经公证。
