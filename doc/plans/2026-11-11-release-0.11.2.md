## 升级与兼容边界

- 应用数据库沿用 v27，无 schema 升级、依赖版本变更或 CSP 放宽；旧项目和素材目录原样保留，正式迁移关闭。升级前备份；回退旧安装包不会反向转换数据。较早严格 v4 读取器仍可能拒绝含输出历史字段的新项目包。
- 新项目只清理已核验普通未引用原件；待续／未知任务、发布素材等继续保护，扫描不完整时不开放删除。整作品删除后保留的素材目录本版仍不开放清理。
- 最近 Skill 是本机界面偏好，不随项目迁移或归档，不是调用授权；升级前漏记的包 Skill 需重新选择后记录。旧五角色资料可读，冻结任务沿原成员，不自动加角色或调用；新默认模板需配置新增角色模型并满足预算。
- macOS 名称别名修复不恢复真实缺失文件；蒙板／标注辅助图层的独立跨设备身份仍未补齐。prompt-only 全局素材可移植性、MCP 独立剪辑工程创建与连续节点位置，以及 Muse 参考图／视频和 Mac／Linux 网页能力仍按[上一版边界](./2026-11-10-release-0.11.1.md)验收，不宣告解决。
- 平台矩阵仍为 Windows、Linux、Apple Silicon macOS 与 Windows Legacy；Legacy 无本地 ONNX 和自动更新，macOS 临时签名、未公证且无 Intel 包。

## 验收与回退

本轮实现已补回归源码；本次文案准备未运行测试，待发布门禁。旧提交的检查不作为最终发布提交证明。原生窗口、真实文件、跨平台和付费模型行为仍需桌面验收：

1. 独立助手输入草稿后点击优化分镜，再关闭／收回、发送后关闭、快速重开及交接中切项目。只显示一个助手，草稿留在原会话，已发送正文不复活；失败可编辑重试，任务不重投。
2. 连续选择两个已启用包 Skill 和上传 Skill，`/` 第一层按最近顺序显示最多 5 项；重启、包目录后加载不丢顺序，停用项隐藏，简介可读。
3. 同排分组反复开合并手动移动、撤销重做、保存重开；无累积漂移，真实编辑历史保留。快速换图和切项目无旧预览覆盖。
4. 新项目拖入／上传／粘贴参考图后生成，同图身份补齐不误拒；真实输入变化仍停止。macOS 重新编译桌面端后验证蒙板保存与重开、Unicode 文件名导出及缺失定位。
5. 可丢弃新项目的普通废弃原件可清理；引用、在途任务／复制及多根同名文件正确保留，其他项目不被连带禁用。
6. 方舟勾选 Flash 后核对单图参数与可控错误，未知提交不重试；团队新增角色需模型与预算，旧任务不扩员。真实付费调用不由 CI 成功推断。

回退按各模块专项撤销前后端对应接线，保留会话、草稿、项目、媒体文件和任务回执，不删除资料或开启迁移。旧版不能推断新角色任务与分组让位记录可完整恢复，回退前保存项目副本。
