# v0.11.12 发布准备 · 参考素材直传与画布恢复改进

日期为 2026-11-23。发布内容包含当前默认分支和本次 Uguu 修复。上一公开版为 v0.11.11（`a30681d6`），本版累计收录该标签之后至 `8224bb44` 的改动。[上一版 Release](https://github.com/Tenney95/AI-Canvas-tauri/releases/tag/v0.11.11)

| 用户变化 | 源码依据 |
| --- | --- |
| 自定义图片和视频协议支持本地文件表单，可从常见 cURL 文件字段导入。 | `bc562006` |
| 万象官方视频连接的受支持型号按块上传参考文件，文件大小和格式由厂商校验。 | `006549e5` |
| 内置 Uguu 对齐官网上传地址，macOS 系统静态代理兼容新旧入口。 | `8224bb44` |
| 修复浏览短剧资产后图片回填失败，支持定位已保存原图。 | `b7a0d116` |
| 续开每部剧上次成功打开的分集，修复项目库异常时的新建和最后一个普通项目的删除。 | `885a6352`、`6daf866e` |
| 空模型菜单说明缺少的配置，并在主窗口提供入口。画布、历史记录和恢复流程减少重复处理。 | `45e4636d`、`2a556627`、`802f9ab9` |

本版新增万象视频上传的原生命令与对应权限，且涉及项目存储和任务恢复。发布标签由远端冻结文件范围并执行全量源码门禁。数据库和项目包版本保持原有格式，旧项目不会自动迁移。Windows Legacy 不含本地 ONNX 与自动更新。macOS 仅 Apple Silicon 临时签名包，Linux 安装包仍暂停。[打包与发版流程](../打包与发版流程.md)

| 核对项 | 验收条件 |
| --- | --- |
| 版本资料 | 五份版本文件、四语言 README 徽章、官网与说明书、Release 标题和正文对应 v0.11.12。保留旧版说明书锚点。 |
| 原子推送 | 远端 `master` 与稳定标签 `v0.11.12` 同次推送，标签解引用等于发布提交。 |
| 远端门禁 | 同标签、同 SHA、同一次尝试的前端、Rust、全量质量证明和前端制品通过发布门禁。 |
| 安装包 | Windows x64、Apple Silicon 和 Windows Legacy 构建与产物验证成功后，由工作流公开 Release。 |

Uguu 已在本机隔离的 macOS Tauri 开发版实传合成 PNG，经静态系统代理上传并下载，文件逐字节一致。前端定向 360 项、Rust 库检查和代理匹配用例通过。原报错机器仍待安装新版复测。自定义服务真实 multipart、万象超过 65 MiB 的视频与取消续查、跨平台安装升级和大画布操作按各环境验收。远端门禁和产物以当前目标的 Actions 为准。[源码 CI](https://github.com/Tenney95/AI-Canvas-tauri/actions/workflows/ci.yml) · [发布工作流](https://github.com/Tenney95/AI-Canvas-tauri/actions/workflows/release.yml)
