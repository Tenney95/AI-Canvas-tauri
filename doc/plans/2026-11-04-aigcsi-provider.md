# Amam（AIGC SI）接入

日期：2026-11-04。类型：平台能力。状态：代码与回归源码已实现，待 Tauri 桌面及真实渠道验收；本次未运行测试、lint、类型检查、构建或付费调用。本阶段仅本地提交，不推送。

## 依据与范围

- 来源：[主站接口文档](https://aigc-si.com/docs)，2026-11-04 在已打开的浏览器文档中核对；不把页面登录状态或积分余额当作 API Key 授权。
- Base URL：`https://aigc-si.com/v1`；Bearer Key 沿用原生凭据存储。厂商跳转使用用户提供的[邀请链接](https://aigc-si.com/?ref=OAXZHWXT)。
- 宣传语：“Muse 视频生成每秒 2 分，快速稳定，轻松创作。价格以平台为准。”价格口径由用户明确确认；文档当前为不同秒数每条 2 积分，未提供人民币换算，应用不据此计算扣费，也未验证速度与稳定性。
- 新增模型清单、目录注册和策略，复用现有声明式执行器、通用模型同步、菜单与 MCP；无需专用 UI、依赖、权限或数据库迁移。厂商名称和介绍沿用既有目录元数据展示，不新增 UI 未消费的多语言词条。

## 已适配合同

图片 9 个：`image-2.5-flare`、`image-2.5-sunburst`、`image-2`、`image-2-原生`、`香蕉-pro`、`香蕉-2`、`香蕉2.1`、`香蕉`、`香蕉-v2`。

图片按官方能力与价格共同明确的比例取交集；普通档为 1K／2K／4K，香蕉 2.1 仅 1K，不承诺固定像素输出。`quality` 的普通档语义是分辨率别名，不重复添加生成质量控件；透明背景尚无具体型号确认，不借其他站同名模型配置。支持 1–4 张输出；有参考图走 `POST /images/edits/async`，否则走 `POST /images/generations/async`。默认配置展示包含参考图映射的编辑协议，执行时仅完整内置模板按素材数选择临时协议；原存储不改写。协议编辑器直接试跑默认编辑模板时需提供真实参考图；无参考图场景通过画布文生图入口验收，不将编辑模板冒称为通用动态路径。

视频 10 个：`muse-video-1`、`seedance2.5-15`、`seedance2.5-12`、`seedance2.5-max-1`、`seedance2.5-14`、`seedance2.5-13`、`seedance2.0-930-1`、`seedance2.0-15`、`seedance2.0-7`、`minimax-h3-5`。

Muse 支持 720p、16:9／9:16／1:1、5／6／8／10 秒及最多四张普通参考图，无视频／音频参考。其他渠道的分辨率、时长及各类参考数量分开声明，不拼接不同渠道的上限。只开放普通参考用途；除 Muse 省略模式字段外，使用文档允许的 `reference_mode=asset`。不推断帧率、音轨开关或首尾帧模式。

## 目录与结果恢复

默认目录可见但不自动选中，填写 Key 后通过 `/models` 核对。普通目录优先 `api_model`，缺失时只用明确的具体 `id`；停用项排除，重复调用值去重。远端分类和未知能力不覆盖已核对合同。认证或目录请求失败不伪装成功，同名自定义连接以显式 `catalogId` 为准。

异步提交保存 `id`，图片查询 `/image-jobs/{id}`，视频查询 `/videos/{id}`；配置两小时客户端等待期限，每五秒查询。等待到期不等于远端失败，继续原任务，不自动再次 POST。新提交使用调用级幂等键，查询和下载不带该键；不声称本站可凭幂等键找回缺失任务号。

图片完成读取 `result.data[*].url`；以单个 `/` 开头的结果按 API origin 解析，拒绝网络路径和改变 origin 的路径。普通完整 CDN 地址保持原样。同源结果保存由原连接当前 Key 鉴权，外部 CDN 不附 Key。视频完成后固定按文档下载 `/videos/{id}/content` 原始 MP4，复用同源校验和 MIME 检查。仅保存和目标回填成功后确认交付；查询／下载／保存异常保留原身份，明确任务失败则清理本次待续记录。

## 保留边界

- 两款原生 2.5 跨协议池必须读取认证能力 profiles，不能按各字段最大值拼合同；本批未添加。MJ 按组多候选也不混入普通图片模型。
- 无文本、TTS 或音乐生成合同，不补同名模型。普通视频参考格式为 URL／内联媒体，不是 Files API 编号；本站未开放 Files API，不编造专属上传。
- 图片复用现有内联准备限制：最多六张，准备后单图最多 8 MiB、合计最多 24 MiB，比厂商原图接收预算更窄。其他媒体沿用应用现有内存和上传预算；不因此声称已放开厂商全部单文件／合计预算。远程素材可访问性、参考时长及更严格的厂商规则仍由真实渠道验证。
- 声明式二进制结果当前单项 64 MiB、累计 128 MiB，视频超过该限制会保留原任务并提示交付问题；不为新站放宽全局内存边界。
- 用户修改的协议保留原路径、参数与鉴权。默认编辑协议的直接试跑边界见上文；自动切换仅用于完整内置合同的实际生成入口。

## 桌面验收步骤

前置：使用更新后的 Tauri 桌面版本和有权限的 Amam Key；以下真实生成由用户决定是否执行，会产生平台费用。

1. 设置 → API Key → 添加厂商 → Amam（AIGC SI）。未填 Key 应能看到 19 个默认候选且无自动勾选；检查宣传语、官网跳转。无效 Key 拉取应报认证错误，不能显示验证成功；有效 Key 只展示实际返回且已适配的型号。
2. 启用 Muse 和一个图片型号保存。图片／视频节点以及对话媒体模型菜单应出现当前连接的独立分组；不出现文本／音频型号。重新打开设置应保留已选型号、协议和参数。
3. Muse 选择 720p、8 秒、9:16，用提示词生成。完成后应从原任务下载 MP4 并回填；后台完成不等于客户端已交付。回归 5／6／10 秒、1:1，以及切换其他型号时保留兼容参数。
4. Muse 引用普通图片，应按顺序传递，最多四张；第五张、视频／音频参考及首尾帧角色应在提交前明确拒绝。其他渠道分别核对其参考类型与上限，不混用型号。
5. 图片分别无参考、有真实参考生成；请求应分别走异步生成／编辑且只提交一次。完成应保存所有实际结果，检查站内相对 URL、完整同源 URL、外部 CDN 和 1–4 张输出；普通图片不显示未经确认的独立质量／透明背景。
6. 模拟或等待查询断网、下载 401、保存失败，点击继续查询／保存应只取回原任务，不新增生成 POST。明确 `failed` 应直接显示失败；提交响应丢失仍保持未知，不自动重投。切换项目、删除目标节点、取消等沿用派生结果守卫。
7. 使用可控协议返回 `//外站` 或带反斜杠导致来源变化的路径，应拒绝交付；完整公开 CDN 不附站点 Key。修改内置图片协议路径后保存，实际执行不得再被内置路由覆盖。MCP 使用已有模型目录与媒体工具核对参数，不在工具参数或日志中提供 Key。

补充回归源码位于 `aigcsiModelManifest.test.ts`、`providerCatalogService.test.ts`、`providerPolicies.test.ts`、`defaultModels.test.ts` 和 `modelRequestTransport.test.ts`。本次仅静态阅读差异与严格 UTF-8 核对，未执行这些用例。
