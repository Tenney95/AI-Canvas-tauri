# UI Kit 公用视频播放器

## 范围与边界

任务类型为架构收敛，用户已确认本阶段 10 个文件的范围。将全屏资产预览的播放控件抽取到 `components/shared/VideoPlayer.tsx`，样式归入 `styles/ui-kit.css`，在样式预览窗口加入可选择本地视频的真实样例；资产预览保留生成历史、提示词、参数和文件信息。Tab 资产抽屉与独立资源搜索继续沿用现有浮动播放方式。

公用播放器只接收媒体地址、封面、名称及播放选项，通过回调返回尺寸/时长、错误、结束和宿主 Esc 操作；不依赖 Store、文件服务或生成历史。默认手动播放，全屏资产宿主显式开启自动播放。倍速、音量、时间格式、悬停预览与播放器全屏由播放器管理，宿主负责资源地址的取得和对象 URL 的回收。

## 实现

- 进度条使用主题色。播放期间逐帧更新进度几何，按真实倍速补齐媒体时钟的采样间隙（最多领先 250ms），不逐帧重绘业务信息面板；React 的时间文字更新不重置进度位置。暂停、缓冲、结束和拖动时同步真实位置，切源和卸载停止更新。
- 主视频和悬停预览视频复用既有媒体释放工具。StrictMode 重放恢复媒体源，迟到的播放失败不能写入已释放实例。
- 嵌入样例不抢占页面及其他播放器的 Esc；资产宿主可提供关闭回调。菜单打开时 Esc 先收起菜单，原生全屏时先退出播放器全屏。
- 鼠标点击或悬停不显示进度条外圈；键盘操作使用 `:focus-visible` 在当前位置标记上保留焦点指示，不给整条进度条加外圈。
- UI Kit 样例支持选择、替换和移除本地视频，替换或卸载回收临时对象 URL，不保存素材。

## 验证

- 播放器、资产预览、资源浮层与资产面板共 4 个测试文件 76 项通过，覆盖平滑进度、播放控制、异步清理、焦点与 Esc、历史查询和原有浮层行为。
- 应用类型检查和定向 ESLint 通过。完整测试类型检查仍受既有 `HiddenFilmSet.tsx` 的 `number` / `Timeout` 类型错误阻塞，本阶段未修改该文件。
- 隔离浏览器使用真实测试视频验证 UI Kit 的本地文件选择、倍速与样例移除，以及明暗主题、无整圈边框与键盘标记焦点；资产预览验证提示词/参数、无历史文件、菜单打开时直接关闭、Esc 返回和关闭后释放播放器。实测读取到分数进度，视频结束保留信息面板。桌面原生窗口全屏和不同视频编码仍需运行时验收。

## 回滚

撤销本阶段差异可恢复资产预览内的播放器及业务样式。没有新增依赖、持久化迁移或原生权限变更；不影响既有素材与生成历史。

## 视频节点接入

- 视频节点与节点大屏共用 `VideoPlayer`，大屏不再使用浏览器原生播放控件；节点使用 UI Kit 紧凑变体，悬浮或选中时显示控件，小宽度自动分行。
- 宿主通过 `active` 保留封面按需加载，通过 `mediaRef` 和媒体事件保留截帧、音量恢复及节点与大屏间的播放位置同步；公用组件仍不依赖 Store。闲置节点不挂载视频，紧凑模式不创建额外悬停预览视频。
- UI Kit 真实样例可切换标准与紧凑模式；两种模式共用主题变量。Esc 收起菜单或退出原生全屏时不会同时关闭节点大屏。
- 紧凑模式时间靠右，音量条在音量按钮右侧横向展开并复用 `ui-slider`；暂停或释放媒体实例后仍可调节音量，下次播放恢复最新设置。
- 进度滑块悬浮轻微放大，拖拽按前后方向倾斜，松手回正并轻微回弹；离开进度条释放、取消和卸载均清理拖拽状态，减少动态效果设置下关闭动效。
- 定向 ESLint、UTF-8 校验及 `git diff --check` 通过。按用户要求不运行功能测试、构建或类型检查；播放、截帧及桌面全屏交互交由用户验收。
