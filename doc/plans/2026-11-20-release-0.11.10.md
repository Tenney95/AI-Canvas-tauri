## 性能对照与兼容性

标题中的约 70% 指同一个 600 节点、1,353 条连线密集画布的 macOS 桌面开发版远景缩放对照。缩放帧间隔 P95 中位数从 265 ms 降到 81 ms，下降 69.4%。Windows 同场景从 76.45 ms 降到 27.70 ms，下降 63.8%。样本属于相应测试提交、设备和轨迹。近景 Canvas 2D 与 WebGPU 保留开发版对照入口。 [画布性能专项](./2026-09-09-canvas-interaction-performance.md#win-和-mac-的合并验收)

应用数据库沿用 v27。新结构项目包为 v4，继续兼容 v1–v3 项目包，旧项目不会自动迁移。Windows Legacy 不含本地 ONNX 与自动更新。macOS 仅提供 Apple Silicon 临时签名安装包，未经 Apple 公证。Linux 安装包暂停。
