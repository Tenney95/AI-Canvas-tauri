## 门禁与待验收

普通分支推送和 PR 不自动运行源码 CI，官网自动构建部署保留。按[发版流程](../打包与发版流程.md)在同一提交准备版本与资料，原子推送 `master` 和 `v0.11.6`；本地不重复运行门禁。本版包含依赖锁及原生路径／权限变化，按高风险全量源码检查准备；最终冻结的目标／基线 SHA、模式、清单及实际结果以 Actions Summary 为准。发布工作流须核验同标签、同 SHA、同次尝试的可信检查证明与前端产物，通过后才可构建和公开。

Tauri 桌面验收尚待用户完成：

1. 从启动页项目右键进入全页工作台，核对顶部返回／切换画布和当前项目；编辑大纲、原文、剧本后往返页面与画布，草稿保持，保存与取消关闭行为正确；回归深浅主题、窄窗口与画布快捷键。
2. 同剧两集新建并保存 MD／TXT、切集重开；导入各支持格式，断网核对 PDF 翻页／缩放、PPT／PPTX 和 DOCX 只读预览及旧 DOC 转换提示。外部改文件、只读目录、无效 UTF-8、损坏／加密、超限、链接和读取中切换目标时，拒绝错误写入并保留草稿。
3. 智能体中心上传单文件／压缩包／外部文件夹，改名后检查菜单与重启恢复；删除最后一个托管来源记录时清理托管副本，外部目录保留。取消删除不改动，权限／占用失败保留条目和可读提示。
4. Windows 标准包、Legacy 与 macOS M 系列安装、升级及首次打开另做实机验收；自动化检查不能替代这些步骤。macOS 临时签名、未经 Apple 公证的既有边界保持。
