# v0.11.6 发布准备：全页剧本工作台与大纲资料

日期：2026-11-16。状态：按用户明确要求继续尚未公开的 v0.11.6；已核对 GitHub 最新正式版本仍为 v0.11.5，此前未公开的发布尝试已取消。本版尚未公开，重新绑定标签后的目标 SHA 必须重新取得源码检查和发布证明；准备完成或构建启动不等于发布成功。

## 范围与来源

用户说明以已公开的 [v0.11.5](https://github.com/Tenney95/AI-Canvas-tauri/releases/tag/v0.11.5) 为基准，覆盖该版本后的功能与修复。正文见[发布说明](../../.release-notes.md)，标题见[标题文件](../../.github/release-title.txt)。

- 启动页项目右键直达全页剧本工作台，顶部返回启动页、切换画布与创作操作统一导航，保留草稿和原有分集编辑语义。顶栏采用原生深层拖动区域，标题、副标题和空白可拖动窗口，按钮保持原有点击行为。入口为 `ProjectLibraryModal.tsx`、`ScriptWorkbench.tsx`、`App.tsx` 和 `Titlebar.tsx`，见[画布模块](../画布与项目模块.md#项目卡片直达剧本创作工作台)。
- 大纲资料支持命名新建 MD／TXT，导入 MD、TXT、PDF、PPT、PPTX、DOC、DOCX；文件名与图标左对齐，长名称省略和脏稿标记保留。同剧共享固定 `outline-documents/` 目录；单文件 32 MiB、可编辑文本 2 MiB。PDF、PPT／PPTX、DOCX 离线只读预览，旧 DOC 保留原件并提示转换。正文和本地路径不进入普通持久化或窗口摘要，冲突、权限及过期上下文保护保留草稿。入口为 `OutlineFilesPanel.tsx`、`OutlineDocumentPreview.tsx`、`outlineDocumentService.ts` 和 `documentPreviewService.ts`，见[大纲资料文件](../画布与项目模块.md#大纲资料文件)。
- 智能体中心展示手动上传的 Skill，提供上传、修改显示名和删除入口。删除同一托管来源的最后一条记录时清理软件托管副本，外部链接文件夹和旧来源文件保留；原生复核来源和路径，权限／占用失败不自动提权。入口为 `AgentCenterPanel.tsx`、`UploadedSkillCard.tsx`、`store.skills.ts` 和 `files/skill_storage.rs`，见[Skill 专项](./2026-10-11-unified-skill-access.md)。
- 保留原始异常 `cause`，预览的 200／500 页限制提示使用完整翻译键。内部去重、原生基础件与按风险检查策略累计纳入，不扩写为新创作能力。本版包含预览依赖及锁文件变化，本轮版本归并不改变依赖解析结果。
