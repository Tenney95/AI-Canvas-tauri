## 用户桌面验收与边界

升级前备份项目和应用数据。用对应平台包在测试项目验收，真实付费模型调用由用户自行决定；Web 或源码检查不能替代桌面和厂商服务验收。

1. 保留旧连接／全局 Uguu 设置，测试内置中转的受支持本地参考路径，确认只走所属厂商；取消或厂商上传失败不能换图床重试。显式自定义连接仍按原上传设置。
2. 万象图片文件编辑及 A、2.0 C1／H3 已接入的图／视频／音频随请求文件提交；检查来源本地优先、同类素材编号、旧配置和历史任务查询。仅 HTTPS 合同的本地素材明确拒绝，不推断未公开能力。
3. 万象2.5 C本地音视频、APIMart未接入上传的音视频、GRSAI H3与Amam视频中未确认的本地参考，按限制提示改用支持的HTTPS或协议。不能宣称所有模型、所有类型都支持本地上传。
4. Sora2U 两款图片分别测试纯 HTTPS、本地、混合与 Tauri asset URL；图片最多4张、内联解码合计20MiB，混合按原序准备，不把本机HTTPS地址发给服务端。视频参考图检查对应内联字段。
5. 回归自定义字段／响应映射、工作流、取消、缓存隔离及旧任务恢复；图片可用变量新增两别名，自动字段导入条件仍保持原规则。
6. Windows 标准／Legacy、macOS Apple Silicon 的升级、启动、项目保存和更新清单分别验收；实际结果记录到对应任务，不补写没有执行的通过结论。
