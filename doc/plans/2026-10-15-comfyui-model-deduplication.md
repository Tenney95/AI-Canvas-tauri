# ComfyUI 模型去重实施计划

**Goal:** 在 ComfyUI 独立管理页扫描内容相同的模型，由用户选择保留副本，将其他原路径替换为文件链接，兼容同内容不同文件名。

**Architecture:** 复用固定版本 Czkawka Core 的完整内容哈希引擎，授权遍历、候选分组与结果租约由应用原生层管理。扫描范围可选安装内模型/插件、整盘或指定文件夹；外部根必须由原生目录选择器登记为本窗口用途授权。原生内存保存目录和会话绑定的扫描结果，Renderer 只提交不透明 ID；链接替换沿用管理操作锁、目录策略及原生确认。

**Tech Stack:** React、TypeScript、Tauri 2、Rust、`czkawka_core = 10.0.0`（MIT）、文件身份识别；不新增 IndexedDB 持久化。

## 实施步骤与源码入口

1. `src-tauri/src/media/comfyui/model_dedupe.rs`：默认通过既有安装授权扫描模型目录，可包含 `custom_nodes` 模型二进制；整盘/指定文件夹通过 `choose_comfyui_model_scan_root` 原生选择器授权，Renderer 只传 `rootId`。跳过链接、私有子树、系统/环境/输出/缓存及小文件。复用 Czkawka 完整内容哈希，不以文件名判断相同，不自动执行删除 API 或库级不受控遍历。
2. `model_dedupe_links.rs`：单组与全部替换复用同一原生流程，仅接受扫描、分组和文件 ID；批量请求全部校验后一次消费快照、一次原生确认，逐项复核内容，失败停止后续。保留各目标的原文件名、扩展名与路径。同卷硬链接为默认，可显式选择软链接，失败不退化为复制或直接删除。
3. `management.rs`、`mod.rs`、`lib.rs`、`permissions/comfyui-management.toml`：注册精确命令和内存状态，窗口销毁撤销扫描租约、外部目录用途授权并取消读取；不向远端 ComfyUI 页面授予 IPC。`path_policy.rs` 专用浅层枚举方法只允许逐层经过私有目录祖先，每次进入子目录重新校验；普通文件、通用递归读取/归档/删除的私有目录保护保持不变，不扩展 fs 或 asset scope。
4. `src/types/comfyModelDedupe.ts`、`src/services/comfyModelDedupeService.ts`、`src/components/comfyui/ComfyModelDedupe*.tsx` 和 `src/utils/comfyModelDedupeSelection.ts`：复用 UI Kit 和管理窗口忙状态，保留所有组的当前选择；右侧「全部替换」包含搜索隐藏/未展开组，预览明确列出范围及数量。范围与链接方式启用 `Select.fixedMenu`，避免裁切。扫描说明条数与跳过项数分开显示，可展开最多 200 项具体相对路径和原因，未展开数量明确提示。
5. 写入与上述边界匹配的 Rust/前端回归用例，默认不运行测试、lint、类型检查、构建或应用验收；用户要求后再执行。
6. `src-tauri/src/media/comfyui/model_dedupe_history.rs`：参照历史存于既有 ComfyUI 原生私有目录，不扩大 fs/asset 或路径授权。不可变计划、逐项 processing/linked/result 和最终记录均有界持久；链接验证及 linked 阶段保存成功后才删除原恢复副本。历史存储失败触发回滚或停止，不隐藏中断；读取和清理只访问固定命名记录，不按历史模型路径执行文件操作。

## 关键边界

- 字节相同才可归为同组；同名、同大小、同模型架构、不同量化或不同存储格式不代表相同内容。
- 扫描结果不授予后续任意路径读写权限；处理前复核真实路径及文件状态，扫描后被修改的文件失败关闭。
- 已共享同一物理文件的数据不重复计算可释放空间；预计空间不代表磁盘分配块级测量。
- 链接共享的是文件内容，任一插件原地改写会影响其他路径。只对模型权重使用，执行前停止服务与下载；软链接保留副本移动/删除后会失效，包括停用/卸载其所在插件。界面默认优先保留已共享文件，否则优先 `models/` 中的副本。
- 替换失败保留原件或可恢复备份，结果如实显示已完成项；不自动重试写入，不因窗口关闭丢失恢复线索。
- 每批（跨全部组）最多处理 256 个目标，超过上限明确禁用并提示分批，不静默截断。已取消勾选的组不参与「全部替换」，各组保留项和链接方式保持用户选择。发现恢复记录时，去重及内核/插件写入均阻止，先恢复再继续；损坏记录只允许清理未移动原件的空目录或残留日志，未知文件完整保留。
- 「扫描说明 X 条」是汇总提示数量，不是重复组数。`skippedFiles` 与具体异常跳过项对齐；正常过滤的小文件、非模型文件、环境/系统目录不算读取失败。私有/未授权条目只提示已授权父级和通用原因，不暴露原始系统错误或绝对路径。
- 历史记录最近 100 次操作的时间、根目录简称/盘符、保留与替换相对路径、BLAKE3 摘要、链接方式、成功/失败/未处理和逻辑释放量。根简称同名时可能相同；历史不保存绝对根路径，不授予路径权限，也不承诺文件当前仍存在或提供自动回滚。缺失/损坏阶段和未完成项不能显示为整批成功。
- 整盘模式只接受本地卷根，指定文件夹递归扫描所选目录；都仍只比较至少 1 MiB 的已支持模型格式，并非通用全文件去重。遍历最多 500 万条目、25 万目录、64 层，候选最多 2 万个、结果最多 2000 组；超过限制请缩小范围。
- 外部根绑定物理目录身份与本次窗口会话，不进入 IndexedDB 或通用授权。恢复列表聚合本窗口已选择的范围并标出来源；关窗后需重新选择原目录才能找回其恢复记录。历史根被移走或磁盘拔出时失败关闭，可关窗重开后重新选择有效根。
- Czkawka Core 不是仅重复扫描的精简 crate，会引入图像/音频相关依赖；固定版本，关闭默认 feature，不自行升级构建工具链。

当前仅完成源码、调用链、权限声明、UTF-8 和差异的静态核对；没有修改实际模型或启动应用。依赖锁定增加 Czkawka 所需依赖，尚未通过编译验证。回归源码包含扫描异名分组/取消/已有硬链接计数、批量冲突与上限、链接事务/回滚/恢复冲突、历史阶段失败和中断，以及前端选择保留、IPC 进度和批量不重试写入。

## 用户验收

前置条件：Tauri 桌面端选择一个测试 ComfyUI 安装，在 `models` 和测试插件目录准备大小超过 1 MiB 的模型文件副本，不使用唯一原件做首次验收。

1. 打开「设置 → ComfyUI → 设置 → 模型去重」，扫描模型目录及插件目录；同内容不同文件名应在一组，原路径完整显示；同名同大小不同内容不能分组。仅扫描时所有原文件不变。
2. 扫描进度更新、取消后可重新扫描；切换作用范围、新扫描和关闭管理窗口均不能沿用旧选择执行。已有软链接、目录联接及已硬链接文件不能造成越界读取或虚增释放量。
3. 先保持服务运行并请求替换，应被拒绝；停服后选择保留项和其他目标，原生确认取消时所有文件保持不变。
4. 在同卷测试硬链接，处理后两个不同文件名和路径均存在，重启 ComfyUI 后从各插件加载；重新扫描不应继续把它们算作独立占空间的副本。共享模型原地修改的影响需明确展示。
5. 软链接权限不足、跨卷硬链接、模型被下载器改写、只读目录及失效扫描 ID 应给出准确反馈，保留未完成原件；完成若干项后失败时应准确报告部分完成。
6. 模拟替换事务中断后重新打开管理页，检查恢复入口；恢复不覆盖不同内容、不删除唯一副本。长中文路径和较小窗口下，结果列表可独立滚动，深浅主题下均可读。
7. 展开扫描范围，应完整显示四项；缩小窗口后打开范围菜单、在结果底部打开链接方式菜单，均不被卡片/滚动容器裁切，Esc 只关闭下拉，点击与键盘选择正常。
8. 选「指定文件夹」，在系统对话框选择安装目录之外的测试目录；扫描结果只属于该根，异名同内容仍在一组。取消选择不改变已有范围；未选根不能开始扫描。选「整个磁盘」并选择本地卷根，子目录应被提示改用指定文件夹；扫描期间可取消。
9. 外部目录进行一次测试替换并检查读取；模拟中断后切换范围，原恢复记录仍能找到且来源明确。关窗重开后重新选择原根，恢复记录应重新出现；目录改名/磁盘拔出、旧 rootId 和伪造路径不得使旧快照继续写入。模型目录、插件列表和常用设置保持既有行为。
10. 扫描包含链接或不可访问条目的测试目录，展开「扫描说明 X 条 · 跳过 Y 项」；Y 对应具体跳过项，最多 200 条加明确剩余量，不能把 X 当作重复组数。11 组重复即使只在视口内看到两张卡片，仍应保留 11 组及独立结果滚动。
11. 修改两组的保留副本、勾选项及链接方式，搜索只显示其中一组，再点右侧「全部替换」；预览必须包含全部已选组并保留各组配置，取消时文件不变。确认执行后一次原生确认，全部成功或准确停止于失败项，不自动重试；超过总 256 项须明确提示。
12. 单组及批量替换后打开「替换历史」，核对时间、根简称、保留/替换相对路径、摘要、方式和逐项结果；重开窗口仍可查看。中断、阶段记录缺失/损坏必须标记待核对；历史保存失败不得继续删除原件。历史仅作参照，模型原件恢复仍走原旁恢复入口，深浅主题与较小窗口均可读。

用户需要执行自动化检查时：在仓库根目录运行 `npm run test -- tests/services/comfyModelDedupeService.test.ts tests/utils/comfyModelDedupeSelection.test.ts tests/components/select.test.tsx`；在 `src-tauri/` 运行 `cargo test model_dedupe --lib` 与 `cargo check --lib`。这些命令尚未执行。本次未运行测试，待用户验收。
