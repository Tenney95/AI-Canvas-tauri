## 数据兼容与回退边界

- 旧项目仍按原格式、ID 和目录读取，不自动迁移真实数据；正式迁移开关继续关闭。通用 IndexedDB 沿用 v27，新建项目独立仓储不等于已激活旧库迁移。新目录按“项目名＋短 ID”创建，已有绑定目录不自动重命名或搬移。
- 新项目使用 v4 包；旧项目保留原导出路径，旧 v1/v2/v3 包继续可导入。v4 新增可选 `history.payload.outputs` 与输出画布作用域，不放宽外部未知字段校验；本版或明确支持这些字段的读取器才能完整接收，早期严格 v4 客户端可能拒绝。
- 输出历史按 c2 画布隔离，保留原稿、参数白名单和相对文件身份，不携带绝对展示路径、凭据、下载任务或执行租约。旧成功回执缺少原稿或生成时间时明确未记录，不把当前改稿补造为过去事实。
- 新副本导入重新分配历史与画布身份。更新在原生内容提交后、finalized 前幂等追加输出历史，历史写入失败保留原 journal 供续接；相同来源不重复，删除或裁剪不复活。每画布保留最新 16 条，沿用原留存规则。内容恢复保留当前历史、任务、预算和审计，不回退它们。
- 只有完整、身份及摘要可验证的本机产物才交付。明确失败可由用户手动重试；提交未知、响应丢失或查询接口故障不能据此判定生成失败，也不能自动重投。项目包不授予旧任务执行权。
- 升级前分别备份项目包与应用数据。回退源码或安装旧程序不会把新库转换回旧格式；新结构项目需保留原备份与能读取 v4 的客户端。已推送标签保持不可变，发布问题通过后续补丁修复，不删除媒体、回执或私有任务。

## 已知限制与待验收

| 项目 | 本版边界与规避方式 |
|---|---|
| MCP 独立剪辑工程 | 验收发现创建 ID 与节点 ID 不匹配，可触发原生拒绝；暂从桌面创建剪辑节点，再操作已有工程 |
| MCP 媒体占位 | 连续创建可能使用相同位置而重叠，暂手动拖开；不能把节点数量与可见数量混同 |
| 提示词中的全局引用 | 仅通过 prompt 引用的全局素材尚未全部冻结到 v4 包；跨机器交接前把参考素材保存到项目并实际核对导入结果 |
| 新的墓碑画布历史更新 | incoming 包中本机从未纳入的墓碑画布输出更新失败关闭，需导入独立副本，不把历史目标恢复为活动执行租约 |
| 输出历史与复杂恢复 | 本轮输出历史相关隔离回归与类型检查已通过，最终发布门禁与桌面回归仍待核验。真实进程重启、多窗口剪辑及含新增素材/结构/工程变化的完整恢复仍需按测试记录验收 |
| Muse 网页模型 | 登录与会话识别有用户桌面截图确认；真实文本/图片/视频调用、连接保存回归与 Mac/Linux 网页能力仍待验收。比例/时长只作目标请求；网页变化、登录轮换可能中断取回，不保证跨重启自动续写。Muse 普通问答不执行工具；私有任务与登录不导出 |
| 原生平台 | Windows、Linux、Apple Silicon macOS 与 Windows Legacy 按现有矩阵发布。Legacy 无本地 ONNX/自动更新；Mac 为临时签名，未公证，下载后首次打开仍需用户实机核对 |
