# 通用视频输入校验设计

## 目标

在付费视频任务提交前拦截厂商已经明确声明的无效输入，同时让相同机制可以用于其他中转站和自定义通用接口。

## 方案

- 模型能力层声明约束，不在 Provider 分支里散落模型 ID 判断。
- 统一校验服务负责字符计数、Base64 解码字节估算、媒体元数据读取和范围判断。
- Sora2U manifest 写入固定规则；未声明约束的其他模型不受影响。
- 自定义视频模型的能力编辑器提供可选数值字段，留空即关闭对应限制。
- 元数据规则采用失败关闭：不能确认尺寸或时长时不发起付费请求。

## 边界

- 本阶段只实现用户确认的五类规则，不扩展参考素材总数量、HTTPS-only 或任意表达式规则。
- 不改变请求模板、鉴权、轮询和生成结果解析。
- 不新增依赖、数据库迁移或原生能力。

## 验收

- Sora2U 的 10 字、20 MiB、300 px、视频 `<15s`、音频 `3–15s` 均有自动测试。
- 边界值 3 秒允许、15 秒拒绝。
- 元数据不可读时阻止提交。
- 无 `inputConstraints` 的旧模型保持原行为。
