# WSAGENT 同机项目互联

AI Canvas 是已发布图片的权威库，两个应用分别保存自己的作品与工作内容。一个 WSAGENT 项目配对一个 AI Canvas 作品，AI Canvas 分集共用作品级身份。

## 使用入口

1. 安装支持插件注入的 macOS 或 Windows 版 WSAGENT 和 AI Canvas。Windows 使用 AI Canvas 安装程序注册唤醒文件类型。在 WSAGENT「设置 → 画布接入 → AI Canvas」点击「插件注入」，AI Canvas 会接收并启用内置的「WSAGENT 互联」插件。若当前打开的画布与发起注入的 WSAGENT 项目已配对，画布会自动添加节点。再次点击会复用已有节点。
2. 首次配对时，在目标作品的画布右键选择「添加插件节点 → WSAGENT 互联」，再点击节点上的「连接 WSAGENT」。当前作品已有配对时复用对应项目，初次连接自动在 WSAGENT 建立对应项目。各分集沿用该配对。「资源库 → 项目文件 → WSAGENT 共享图片」也能连接或解除配对。
3. 在 WSAGENT 项目素材库发布一张本项目图片，在 AI Canvas「打开共享素材」预览并插入画布。在 AI Canvas 的项目文件上右键发布另一张图片，也可把项目图片连到互联节点的「待发布图片」端口后在面板发布。WSAGENT 的「共享」页自动更新目录，取回原件后可作为本地项目媒资使用。
4. 节点标题栏的「打开 WSAGENT」用于启动或切到桌面工作台。连接后，节点内的「项目素材」会显示配对 WSAGENT 项目已保存到本机的图片、视频和音频，包括生成结果与上传的文件。可按类型筛选。点击「取到画布」，或点选某条素材后从右侧对应端口拉线，即可生成标准素材节点。拉线落在兼容输入口时会接到该输入口。
5. 在两端打开配对作品。在 AI Canvas 的项目角色／短剧资产库或 WSAGENT 的角色、场景母图、道具文档创建条目并保存。WSAGENT 使用带稳定 ID 的二级标题解析条目。名称、简介、视觉说明和主参考图会同步到对端原有编辑入口，互联节点显示同步状态。
6. 在 AI Canvas 保存作品剧本或「剧本创作工作台 → 本集剧本」，WSAGENT 配对项目的「剧本」分类出现对应文档。打开该文档保存修改后，正文会回到原作品或原分集。首次已有一份 WSAGENT 剧本时，可以自动对应作品剧本。已有多份时，用相同正文确认唯一对应稿，或使用 Canvas 后续自动建立的文档。

## 实现边界

- AI Canvas 通过 `src/services/wsagentSharedImages.ts` 协调作品身份，原生 `src-tauri/src/files/wsagent_shared.rs` 提供主窗口操作与项目素材回环接口。点击连接后，同一个 macOS 或 Windows 用户下的两个原生进程通过私有发现文件和专用回环接口交换项目授权。有效配对复用既有项目，首次自动创建使用稳定作品身份，显示名称仅用于展示。项目切换使旧请求失效，重开作品恢复原有配对。
- 原件及清单位于 AI Canvas 私有应用数据中，同项目按完整 SHA-256 去重。首期接受能够解码的 PNG、JPEG、WebP，单张上限 20 MiB，最长边 8192 像素、总像素上限约 2400 万。修改后的字节作为独立条目发布，旧引用继续使用已保存的本地副本。现有 S3 共享仍走原入口。
- WSAGENT Electron 主进程使用加密存储保存项目凭据，通过现有 Go 媒体库物化原件，保存共享来源并避免循环发布。生成参考沿用正常项目媒资入口。AI Canvas 负责解除项目授权。
- 插件源码归入 WSAGENT 的 `source/plugins/ai-canvas-wsagent`，版本为 `0.1.0`。WSAGENT 由同一个按钮提交内置的 `wsagent.aicplugin`，并读取 AI Canvas 的通用[桌面插件投递回执](../插件开发规范.md#桌面软件投递插件包)。宿主只按完整包摘要识别已登记发行包，安装沿用现有插件注册与启用流程。
- 互联层在安装后，通过原有受保护的本机凭据查询请求对应的 WSAGENT 项目。只在 AI Canvas 仍打开配对画布时添加节点。Windows 由 AI Canvas 的当前用户 NSIS 安装程序注册通用包类型，已运行实例通过受保护的 Windows 事件接收唤醒。Windows 本期覆盖插件注入与项目配对。
- 插件声明 `wsagent.autoConnect`、`wsagent.sharedImages` 宿主能力与 `wsagent.shared-images` 权限。AI Canvas 隐藏该连接节点的通用模型输入，保留专用素材面板。主窗口 Broker 复核项目、节点、插件版本及直接连线授权。
- 插件 `0.1.0` 增加 `wsagent.projectMedia` 宿主能力。列表和有界缩略图经配对的同机接口读取。取用时由原生层流式保存原件，单份上限 4 GiB，复核项目配对和文件的目标目录。节点记录端口选择的素材身份，取回的素材节点引用当前 AI Canvas 项目副本。已发布的共享图片继续由 AI Canvas 的共享库管理。
- 创作资产以 Canvas 业务 ID 与 WSAGENT 文档条目 ID 配对。AI Canvas 随打开的作品自动同步，本端保存触发短延迟检查，另每三秒检查对端。WSAGENT 核对条目版本再写入，项目页接收正常的文档变更通知。连接中断后重试。双方改不同文字字段时合并，同一字段各自改为不同内容时保留两端记录并提示。全局库、分集草稿、声音、动作和模型绑定始终归原应用。卡片删除各端独立；确认改名沿用原身份。
- 主参考图按项目内媒资传输。AI Canvas 发布使用现有共享图片库，支持 PNG、JPEG、WebP，单张 20 MiB。WSAGENT 在同项目取回后用原有选图记录绑定。反向使用现有原件读取，在当前项目落盘后才修改卡片引用。图片暂时不可取时仍同步文字，并保留图片待重试。换图与取消选图保留原件，AI Canvas 在收到取消选图时只清除导入的主图引用，保留本地备用图。
- 剧本同步使用已保存的 Markdown 正文。普通作品、全剧与各分集分别绑定稳定身份，重命名和分集调整顺序保留关联。同步目录只交换文档身份、标题和内容摘要，正文有变化时单独传输。每份正文上限 1,000,000 UTF-8 字节。AI Canvas 复用剧本及分集 TXT 的保存事务与编辑会话，WSAGENT 复用剧本文档版本与变更推送。正在编辑的草稿延后接收，两端同时保存不同正文时保持各版本并提示。同步只写剧本正文，大纲、分镜、批注和文档布局依原应用管理。删除稿件时保留对端正文。

## 验证与回退

- 插件注入桌面验收使用两套支持该功能的 macOS 安装包。在已配对的画布点击注入，预期出现一个「WSAGENT 互联」节点。重复点击仍只有一个。切到其他画布或返回启动页后再注入，预期插件就绪，画布内容保持原样。
- 上一版专用入口在 macOS 实机验证了首次启动、安装并启用 `0.1.0`、恢复配对画布和节点去重。
- 通用入口已通过两端定向测试、macOS 原生回归、Windows x64 原生模块交叉检查和 Windows 安装器钩子编译。验证覆盖未登记包需确认、包撤回后终止安装及会话切换后继续处理下一次投递。
- 通用入口的桌面验收需两端都更新。在 macOS 和 Windows 上，先用空白测试画布配对，再分别在 AI Canvas 退出及已运行状态点击「插件注入」。预期恢复匹配画布时只有一个节点，打开未匹配画布时只完成安装。Windows 用含空格的安装路径覆盖系统文件关联。另用不同 ID 的本地测试插件核对首次确认和拒绝后的回执。回退时两端一并切回使用旧投递协议的版本，已有插件和项目仍由各自原有存储管理。
- 自动配对版本已用隔离 macOS Tauri 与 WSAGENT Electron/Go 实测。选中互联节点时通用模型提示词框隐藏，点击「连接 WSAGENT」完成对应项目创建，重复连接复用同一项目，配对后可发布图片。已在使用原项目库的试用安装核对 AI Canvas 节点按钮及 WSAGENT 简化后的设置页，真实项目由用户发起连接。
- 本轮插件包校验与 5 项测试通过，AI Canvas 相关 Vitest 151 项及 Rust 互联 5 项通过。WSAGENT 定向 Vitest 11 项，Go 定向测试与 vet，以及 Electron、渲染端类型检查通过。本轮 WSAGENT 隔离界面停在欢迎页，已发布图片的自动刷新仍待在实际共享页验收。
- macOS 实机已验证两端配对、双向发布和原件 SHA-256，WSAGENT 重复取回复用同一媒资。插件安装后已验证目录、预览、按原始文件名插入普通图片节点、连线发布新图及重复发布去重。错用 WSAGENT 项目或从 AI Canvas 离开配对作品后，真实回环接口拒绝访问。实际付费生成未执行。
- AI Canvas 相关 Vitest 5 文件、179 项，Rust 互联与原生权限 3 项，修改范围 ESLint 通过。WSAGENT 的 Go 定向验证、3 文件 28 项 Vitest，以及 Electron、渲染端类型检查通过。独立插件的宿主清单校验及 5 项测试通过。AI Canvas 全量类型检查还受 `relayonProviderGroups.ts` 中既有类型错误影响。
- 三类素材的 Tauri 桌面隔离验收已验证一键配对、列表从空到分批自动更新、视频筛选、PNG 和 MP3 按钮取用、MP4 拉线取用、共享图片面板打开。三份写入 AI Canvas 项目的文件均与上传原件的 SHA-256 一致。未调用生成模型。新增连线相关 Vitest 148 项、Rust 互联 7 项和插件 5 项通过。当前源码的完整类型检查仍受同一个 `relayonProviderGroups.ts` 错误影响。

- 可在两个测试项目各放一张不同内容的图片，按上面的入口验证发布、查看和取回。发布同一张两次应保留一条，取回同一张两次应复用已有媒资。另用不同内容的同名图片核对内容分别保留。离开配对作品后重试，应提示打开已配对作品；重开后可继续使用。
- 回退时从 AI Canvas 解除配对并停用插件。已插入画布和取回 WSAGENT 的项目副本可继续使用。当前交付为源码与本地插件包，正式桌面安装包留待发布流程。
