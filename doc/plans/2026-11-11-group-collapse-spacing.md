# 分组开合自动让位

目标：横向排列的分组折叠为文件夹时，同排后续内容自动靠近；展开时恢复空间，保留原间距和用户手动移动。

## 范围与实现

采用现有 Zustand Store 和 React Flow 坐标，复用 `toggleGroupCollapsed`，不增加布局引擎、动画、依赖或数据库表。

1. `src/utils/groupCollapseLayout.ts` 集中处理同层后继筛选、偏移叠加和解除关系。以标题顶边差不超过 28 个画布单位判断同排，仅选择位于原右边界之后的可见节点；左侧、其他行、其他父级不动。锁定节点作为锚点，自己及其后续内容不参与本轮靠拢。整组只移动组根，子节点相对坐标不变。
2. `src/store/store.groups.ts` 一次写入尺寸、选择与让位；收起时记录本次实际移动的节点 ID、父级和宽差，展开移除这份贡献。多个收起组的贡献可叠加；旧文件夹没有记录时只恢复尺寸，不猜测补推。
3. `src/types/index.ts` 在节点 data 中增加可序列化的 `groupLayoutOffsetX` 和 `groupCollapseLayout`。既有保存路径保留这些数值与 ID，不保存运行时句柄或完整节点副本；旧记录缺省为无偏移。
4. `src/store/store.history.ts` 和 `src/utils/historyOperationLabels.ts` 按扣除自动偏移的用户坐标比较及还原。开合不新增历史、不截断重做；恢复后按当前折叠记录重算偏移。收起期间撤销真实缩放，也同步修正对应宽差。
5. 节点复制／粘贴、换组／脱组和分组创建／解散入口清理旧展示关系，保留可见位置；复制的文件夹不得驱动原节点。

展开按本次收起名单反演，不重新按收起后的边界查找，以免错误移动原本就重叠的节点。手动移动在现有位置上叠加，展开不恢复旧绝对坐标。折叠后新放入空隙的节点不自动加入旧记录；这不是全局避碰或自动重排。

自动回归入口：`tests/store/groupFolders.test.ts`、`tests/utils/historyOperationLabels.test.ts`。用户可在仓库根目录执行 `npx vitest run tests/store/groupFolders.test.ts tests/utils/historyOperationLabels.test.ts tests/store/history.test.ts`。

Tauri 桌面验收：

1. 前置：加载本轮前端，在同一水平线上放置至少三个展开分组，保留清晰间距，并放一个位于其他行的节点。双击第一个分组头部或名称收起，应只让右侧同排内容靠近，其他行不动；双击文件夹展开，原间距恢复。
2. 分别按 A→B 收起、A→B 展开，以及 A→B 收起、B→A 展开操作数轮，确认无累积漂移。被移动分组内的节点、连线和相对排列应保持；锁定一个右侧节点，确认它及其后续段不动。
3. 收起后手动移动右侧分组，再展开，手动移动增量应保留；保存重开后展开，也应归还原自动位移。旧版本保存的文件夹首次展开不额外推远右侧内容。
4. 收起期间手动移动、撤销／重做，开合不能占用历史步骤或截断重做；另检查收起期间撤销真实分组缩放后再展开。删除与撤销恢复、复制／粘贴、重新归组和解散不能继承错误的自动关系。
5. 回归此前整个头部双击收起、名称编辑后保存、颜色与运行按钮、文件夹双击展开，以及深浅主题。

回滚恢复上述实现及直接回归差异，无数据库迁移。旧版本仍可读取当前可见坐标，但不会自动恢复本轮记录的让位关系。
