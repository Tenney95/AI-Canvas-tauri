# 分组开合自动让位

目标：横向／纵向排列的分组折叠为文件夹时，同排／同列后续内容自动靠近；展开时沿原排列方向让出空间，保留间距和用户手动移动。

## 范围与实现

采用现有 Zustand Store 和 React Flow 坐标，复用 `toggleGroupCollapsed`，不增加布局引擎、动画、依赖或数据库表。

1. `src/utils/groupCollapseLayout.ts` 通过 `toggleGroupLayout` 统一开合：撤去本源当前贡献、求目标尺寸与关系、一次投影。关系使用扣除全部自动偏移的用户坐标，实际碰撞与投影使用仅撤去本源贡献后的可见坐标；因此其他来源的移动不会打散原同行关系，用户手动增量仍保留。收回按 28 个画布单位判断同排／同列，下方同行一起靠近，并检查终点是否制造新重叠，受阻时保留该轴整段。展开按实际碰撞建立连带后继，右侧向右，下方及其同行向下，同源正贡献不双推。旧正名单也重新判方向、隐藏与锁点，不直接激活。锁定／隐藏期间冻结现有可见位置及偏移，解除后仍按原用户坐标恢复。主动尺寸优先于旧测量缓存；只移动组根，子节点相对坐标不变。
2. `src/store/store.groups.ts` 一次写入尺寸、选择与让位。每轴 `nodeIds` 记录收起的负向靠拢，`expandedNodeIds` 记录展开新增的正向避让；两份名单分相生效，另一份休眠。收起先归还正贡献，仅将没有旧负向身份的纯新增正名单排除在新负名单之外，避免多组叠加时重复压缩，同时保留原有靠拢关系。旧文件夹和复制出的文件夹首次展开也执行实际碰撞避让。
3. `src/types/index.ts` 的 `groupLayoutOffsetX/Y` 和 `groupCollapseLayout` 只保存可序列化数值与 ID；根字段保留旧横向记录，纵向放在可选 `vertical`（`deltaY` 与两份名单），缺省为零贡献。既有保存路径保留这些数据，不保存运行时句柄或完整节点副本，无数据库迁移。
4. `src/store/store.history.ts` 和 `src/utils/historyOperationLabels.ts` 按扣除双轴自动偏移的用户坐标比较及还原。仅比较阶段将坐标统一到百万分之一画布单位，避免浮点加减误差把纯开合记成移动；实际坐标与恢复过程不量化。开合不新增历史、不截断重做；恢复后按当前记录重算偏移，换组撤销恢复两轴的活动／休眠名单。收起期间撤销真实缩放，也同步修正对应宽差和高差。
5. 节点复制／粘贴、换组／脱组和分组创建／解散入口清理旧展示关系，保留可见位置；复制的文件夹不得驱动原节点。

手动移动在现有位置上叠加，开合不恢复旧绝对坐标。不同来源的贡献叠加；收起后新放入右侧／下方空隙的节点可进入展开名单。不同父级和隐藏内容不新增关系；锁点与收回终点碰撞可能限制靠拢空间。算法针对开合引起的布局变化，不自动重排整个画布的既有重叠。

Tauri 桌面验收：

1. 前置：加载本轮前端，在同一水平线上放置至少三个展开分组，保留清晰间距，并放一个位于其他行的节点。双击第一个分组头部或名称收起，应只让右侧同排内容靠近，其他行不动；双击文件夹展开，原间距恢复。
2. 分别按 A→B 收起、A→B 展开，以及 A→B 收起、B→A 展开操作数轮，确认无累积漂移。被移动分组内的节点、连线和相对排列应保持；锁定一个右侧节点，确认它及其后续段不动。
3. 旧版本保存的文件夹或复制出的文件夹，紧贴右侧放置节点后首次展开，碰撞内容和同行后继应让开；相差超过 28px 但仍被展开区域遮挡的节点也应让位。右侧原本已留够空间时位置不变。收起后新放入空隙的节点再次展开应避让；手动移动右侧分组（包括移到远处）并保存重开，反复开合应保留手动增量。
4. 收起期间手动移动、撤销／重做，开合不能占用历史步骤或截断重做；另检查收起期间撤销真实分组缩放后再展开。展开正让位后，将节点拖进其他组，分别保持展开或先收起源组再撤销，返回节点应恢复当前相位及休眠名单。删除与撤销恢复、复制／粘贴、重新归组和解散不能继承错误的自动关系。将两个旧文件夹依次展开再交错收起，后继不能被双重压缩到前面。
5. 回归此前整个头部双击收起、名称编辑后保存、颜色与运行按钮、文件夹双击展开，以及深浅主题。
6. 截图复现：同列上下放置两个文件夹，上方展开后，下方保持横坐标并按高度差移到展开区下面；连续开合、手动纵向移动及保存重开后无漂移。另测试三个竖排文件夹正反顺序开合，下方锁定锚点与其他列不被误移。下方文件夹右侧再放同排节点，依次展开上、下两组，再收起上组，下组仍展开时右侧节点不能重新被包住。

回滚本轮避让时，需同时回滚双轴两相贡献、历史重接与回归源码；无数据库迁移。旧版本仍能读取当前可见坐标，但不理解新增正贡献与 `vertical`，回退前应先收起涉及新让位的分组并保存；旧版不能自动归还新的纵向靠拢关系。
