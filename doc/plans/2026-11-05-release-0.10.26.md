## 桌面验收（待用户执行）

1. 在 Tauri 桌面选择图片、视频、音频工作流，分别使用正式输出、临时预览、中文子目录及文件名自带相对目录；核对原服务取回正确媒体，混合输出不误把视频当图片或图片预览当成片。
2. 让结果生成后因目录授权、磁盘不足、网络或 HTTP 失败暂停，核对具体安全提示与单套恢复／终止入口。修复后继续保存应回填同一任务，不新增生成请求。
3. 对已记录文件位置的新任务，清理远端历史但保留原文件后续取；应直接取件。删除文件或拒绝访问时任务保留且明确失败。旧任务无文件记录时仍按原历史查询，不虚构可恢复结果。
4. 对只有 WebSocket 图片或其他未识别输出的已完成工作流，确认显示文件输出要求、保留任务并阻止重复生成；补好输出节点后按需要新建任务，不能把旧帧当新结果。
5. 下载期间取消、切项目、删除／替换节点或改变画布后，旧结果不得误填当前节点；视频计时与原任务身份保留。工作流内部批量仍只接收首份匹配产物。
6. 跨设备导入中文／空格／多层素材项目，关闭并重开后编辑保存、重新导出并核对素材关联；损坏包和真实缺失素材仍拦截。先备份原数据，不用生产项目测试异常清理。
7. 按 [Amam 接入](./2026-11-04-aigcsi-provider.md) 与 [MCP 可靠性](./2026-11-04-mcp-reliability.md) 核对真实连接、余额单位、断连恢复与取消；跨项目独立窗口跟随正确会话。付费生成、双客户端、S3 及安装升级／自动更新仍需实机验收。
