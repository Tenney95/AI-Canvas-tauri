# 通用视频输入校验实施方案

## 实施步骤

1. 扩展 `VideoModelCapability`，增加可选的声明式输入约束类型。
2. 新增视频输入校验服务，覆盖 Prompt、Base64、视频宽度/时长和音频时长。
3. 在通用声明式视频协议提交前调用校验服务，并贯通取消信号。
4. 为 Sora2U 全部视频模型声明统一默认规则。
5. 扩展自定义视频能力编辑器，让用户调整或清空约束。
6. 增加边界、失败关闭和旧配置兼容测试。
7. 更新 ADR 与 Agent 能力实施记录，运行类型、测试、Lint、编码和差异检查。

## 回滚点

- 类型字段均为可选，不需要数据库回滚。
- 删除生成入口的单一校验调用即可停止运行时拦截。
- 删除编辑器区块不会影响已有模型参数与协议。
