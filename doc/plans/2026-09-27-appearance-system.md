# 全局外观系统实施计划

## 范围

- 设置页新增“外观”，统一管理页面配色、主题模式、画布、节点、连接线、连接手柄与动效。
- 外观以完整快照保存；内置深色、浅色、跟随系统入口，以及太阳系、磨砂暖光完整预设。
- 自定义预设持久化到 IndexedDB；桌面图片保存在安装目录 `theme/`，支持携带图片的 `.aicanvas-theme` JSON 导入与导出。

- 旧版 `theme/canvasBackground/customBackground*` 仅作为一次性迁移输入，常规页不再展示旧画布背景控件。

桌面验收：

1. 前置：Tauri 桌面端准备一张 PNG/JPG/WebP 或自包含 SVG，进入“设置 → 外观 → 界面布局与底色”。点击画布空白、示例节点和各悬浮面板，预期打开对应背景卡片；四个栏位提供“关联其他区域”开关，小地图使用窗口背景；编辑预览不应新增节点、打开真实侧栏或改变画布选择。
2. 分别修改纯色、切换图片、上传/替换/移除图片，并检查三种铺图方式。关闭卡片后检查预览与真实界面一致；画布网格的开关与颜色同步，“更多界面配色”和下方详细设置显示相同值。取消文件选择保留当前设置，异常或超限图片报告错误并保留原图。
3. 切换浅色、深色、自定义预设，再选择跟随系统并改变系统明暗，预期布局位置保持，预览跟随当前外观。重开设置、重启桌面端，以及保存预设后切换回来，应恢复已保存的配色和图片；导入导出沿用下方既有验收步骤。
4. 缩窄设置窗口，检查底部工具栏、颜色色板和卡片内容不相互遮挡或横向溢出。使用 Tab、Enter/空格打开区域设置，Esc 或点击遮罩只关闭当前卡片，焦点回到触发按钮，设置主弹窗保持打开。
