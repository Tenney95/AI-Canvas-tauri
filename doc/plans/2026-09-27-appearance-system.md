## 本地图片与预设传输（2026-10-13）

- 已实现，待用户验证。本次未运行测试、类型检查、Rust 检查、构建或桌面验收；提交时由既有钩子执行本次改动前端文件的定向 ESLint。
- `services/fs/themeAssets.ts` 与原生 `files/theme_assets.rs` 负责二进制上传和图片读取。桌面端只向可执行文件旁的 `theme/` 写入摘要命名的 PNG/JPG/WebP/SVG；开发版对应开发可执行文件旁的目录，安装版对应安装目录。相同内容复用文件，不改变用户选中的原图片。
- 为兼容旧主题，沿用 `imageDataUrl` 字段名，新的持久化值为 `theme-asset:摘要.扩展名`；不保存 Base64、绝对路径或当前窗口 URL。运行时通过用途固定的只读图片协议解析引用，主窗口与 UI Kit、聊天、资源搜索、视频编辑和 ComfyUI 管理窗口共用图片文件。
- 启动先读取配置，再迁移当前外观与已有自定义预设中的内嵌图片。全部图片写入成功才替换对应快照；目录不可写时报告迁移失败并保留原配置。保存、复制、覆盖和改名均经过同一持久化入口。
- 新导出文件使用版本 2 容器，包含完整外观快照和去重后的资源表；仅在导入/导出期间临时转换资源正文。导入同时兼容旧版直接快照，先校验资源完整性、摘要与图片内容，再写入文件并保存预设。单图仍限制 5MB，整份文件限制 64MB；导出不会把资源正文写回配置。
- 原生写入只有可信本地窗口可调用；文件名、目录真实位置、软链接/重解析点、图片格式和内容摘要均在原生侧校验。未扩大通用文件访问范围，新增图片协议只读取固定 `theme/` 中的图片；SVG 响应禁止脚本与外部资源。删除/切换预设不自动删除图片文件，避免破坏其他预设共享引用。Web 演示没有安装目录，保留内嵌图片兼容路径。
- 预设操作使用 UI Kit 按钮和表单，窄窗口允许工具栏换行；导入、导出、保存、覆盖时禁用重复操作并展示状态，等待自动保存草稿完成后再操作。

桌面验收：

1. 准备 PNG 与自包含 SVG，进入“设置 → 外观”，分别上传到画布、节点、手柄、窗口/弹窗及普通/主按钮和悬停状态。确认真实界面、设置预览和 UI Kit 都显示图片；在安装目录 `theme/` 可看到摘要文件，同图重复上传不产生第二份文件。
2. 保存新预设、覆盖预设、改名，切换后重启桌面端，确认图片、按钮颜色/圆角和铺放方式恢复。检查外观配置与预设记录只保留 `theme-asset:` 引用；旧版内嵌图片在成功迁移后不再留在对应配置中。
3. 导出后在另一份安装目录或另一设备导入；预期无需原图片路径即可恢复全部图片与配色。普通/悬停或多个槽位使用同图时，导出只携带一份资源。快速重复点击操作只应创建一个预设或启动一次导出；窄窗口按钮文字保持单行。
4. 分别导入旧版内嵌图片 JSON、缺失资源、摘要不符、损坏图片和超限文件。旧版应恢复；异常文件不得激活或产生预设列表条目。取消导出保持当前预设；目录不可写时上传/导入报错并保留原配置，已存在且完整的图片仍可复用。
5. 删除/移动一张已引用的本地图片后重新打开应用，确认应用仍可使用，相关背景使用底色；导出应提示图片缺失，不生成无法恢复的主题。回归纯色、图片替换/移除、明暗模式、Enter 保存命名、Esc 取消和预设删除。
