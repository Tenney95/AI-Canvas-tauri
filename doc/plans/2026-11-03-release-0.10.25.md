## 范围与兼容性

- 选择 RH 工作流或 AI 应用后，`@ → ComfyUI` 开放图片／视频／音乐／文本定向输入、节点搜索和原字段身份；有画布素材保留输入图默认页，RefMod 角色目录仍仅限本地工作流。普通模型及未声明输入的工作流 API 不伪造输入节点。
- 数字种子随机／固定、新建空节点的最近工作流及尺寸、图片工作流比例同步外框、输出历史原任务重新下载与本地放弃，均保留原调用及项目守卫。
- Windows 多层素材路径、失效单产物缓存与历史来源引用的导出处理，以及缺失素材／协议字段定位；Markdown 上传正文与文件关联。有效依赖和归档路径安全检查不放宽。
- 多选入组／换组／脱组、主题及透明背景下不透明遮罩、工作流管理列表排版与统一配色。
- 四项旧 H3 文生／参考生视频普通版及 Turbo 版退役，加载或重置清理原内置 ID；使用原 ID 编辑的修改也会清理，升级前需导出保留。独立 ID 的手动副本及其他图生／PDD 保留。

数据库沿用 v27、归档沿用 v3，无本版新增迁移。内部工作流多产物仍只收首份，种子受服务声明和安全整数限制；无原任务回执的历史不能凭空恢复。云同步继续手动，HTTP 仅用于可信网络。Windows Legacy 无 ONNX／自动更新；macOS 仅 Apple Silicon，临时签名且未经公证。
