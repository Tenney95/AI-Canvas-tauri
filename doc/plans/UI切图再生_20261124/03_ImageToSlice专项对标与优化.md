## 3. 整页任务的具体增量

### 3.1 前移确定性切片

1. 主窗口以图像、规范解码版本、区域模板和审核版本封存分析输入。每个网格独立声明范围、行列数或单元尺寸、间距和余数策略。支持区域级网格及逐行局部竖线，锁线以原图整数坐标保存。
2. 格数模式按半开框分配余数。对长度 L、格数 n、间距 g，先用受检整数计算有效长度 E = L − (n − 1)g，并验证 E ≥ n。第 i 格由 floor(i × E / n) + i × g 至 floor((i + 1) × E / n) + i × g，i 从 0 开始。12px、3 格、1px 间距产出 [0,3)、[4,7)、[8,12)。单元尺寸模式按明确步长生成完整格，未覆盖边缘按模板标记留空或待审。空格和冲突在审核树有状态。
3. 自动切线以 alpha=0 的连续沟槽为几何证据。任何半透明前景穿越潜在边界时，标记触线并进入复核或局部精修。对完全不透明截图，低纹理分隔线和重复间距只贡献位置建议。手工锁线可用于确认合成裁片，触线提示随候选保留。
4. 几何候选进入规格核对。位于同一格中的文字、图标、底板和角标仍分别匹配交付项。规格未覆盖、小目标、穿线、重复实例以及需去字和补遮挡的区域继续走 OCR、局部分割或语义分析。只有规格和局部证据都已覆盖的对象才可跳过相应的模型请求。
5. 规则扫描借用预热的行列统计与输出缓冲，按块检查取消。现有精灵图可参考读图限额、透明度投影和预览能力。动画处理会按行使用相同列数，并可去底、缩放、对齐和批量保存帧。UI 切片独立生成候选框，经同一原生内核逐片出图。 [输入预检](../../../src-tauri/src/media/sprite_processing.rs#L149) · [投影](../../../src-tauri/src/media/sprite_processing.rs#L331) · [动画处理](../../../src-tauri/src/media/sprite_processing.rs#L367) · [动画导出](../../../src-tauri/src/media/sprite_export.rs#L98)

### 3.2 可编辑结构、底板与交付状态

- 在同一审核树保留逻辑对象和交付方式。实例可以是独立栅格、可编辑文字、受支持的形状或容器分组。角色、交付方式与像素档分别记录。例如奖励卡含底板 PNG、动态数量文字、货币图标 PNG 和分组。策划要求文字同时提供 PNG 时，单独关联该栅格交付项。字体、复杂样式和不确定层级进入审核。
- 每个覆盖关系指出目标底板、覆盖实例、来源证据、可见交叠和保留或移除建议。重复模型局部 ID 形成诊断，受影响引用待审。宿主发放稳定本地 ID，校验跨任务引用和环。模型显式 null 作为未知，上限处返回受影响条目或未覆盖 ROI。短边 1–7px 的候选按模板、证据和预算保留或待审。
- 允许写入范围取已审覆盖区与底板 ROI 的交集，再扣除保护区。为覆盖抗锯齿边，可在审核时调整建议区域。合并属于同一底板、保护边界一致的覆盖区，冻结掩膜后按底板提交。只在可写边界内羽化。基准、已合成候选、选用版本和原始模型输出各有受限引用。后到结果遇到快照、掩膜摘要或审核 revision 变化时，仅记录完成事实和隔离结果，复用前重新审核。
- 发布清单对齐素材、实例、交付项和已审版本。导入先核对素材摘要、尺寸和坐标，再验证结构树。若缺字体或少数目标不支持，报告具体实例及降级结果。新语义先进入内部审核记录，外部清单增量需冻结版本、验证旧读取器的可读投影，并重开真实导入结果。 [主协议](02_架构契约与实施验收.md#2-批次契约)

### 3.3 重跑、预算和顺序

分析缓存键绑定项目、源像素摘要、规范化版本、模板和规格、ROI、适配器及实际模型配置的非敏感指纹。复用时复验项目所有权、授权与资源可用性，并按当前审核版本重新合并。编辑触发对应区域重算，保留已锁定、拒绝和人工校准的信息。已提交但结果未知的再生请求使用既有收据与取消规则。 [主生命周期](02_架构契约与实施验收.md#4-生命周期恢复与安全)

先放行离线参考线、网格、透明沟槽、多个局部网格与一次出包，再接入 OCR、局部分割和 VLM 语义。底板补齐以授权范围、保护区逐字节一致和预算可追踪为放行条件。 [实施阶段](02_架构契约与实施验收.md#6-阶段门槛和迭代顺序)

## 4. 同稿实验与放行

| 样本和实验 | 固定输入与预期 |
| --- | --- |
| 透明图集 | 自制 1px 沟槽、奇数宽高、隐藏 RGB、空格、孔洞、低 alpha 阴影跨线和相邻粘连。以半开框和黄金 PNG 复验。清楚网格须全格正确，跨线必须进入相应待审状态。 |
| 首充卡片 | 重放 PS-Tidy 验证包，原位两张卡片 RGBA 全量一致。另标卡片、动态文本、背景和重复图标，验证嵌套对象继续进入文字和结构审核。 |
| 奖励弹窗 | 测不同行的不同列数、1–7px 标点和徽标、计时器、重复卡片及底部奖励。验证组合片、去字底板、动态文字三类结果的交付计数、素材复用和异常状态。 |
| 遮挡与回贴 | 同一原件分别制成透明源、平面合成和遮挡样本。原件严格匹配，再生保护区逐字节不变。模型回图整体偏移或尺寸映射不可靠时阻止出片并保留缺项。 |
| 路线对照 | 相同授权样本、角色表、标注、整页预算和模型版本，对比人工框选、规则切片、整页 VLM、规则 + OCR + ROI 精修四组。另固定选区对比上游和原生裁片，测像素、剪裁框和可回贴性。再生对照固定获准掩膜和角色。 |
| 失败和并发 | 注入重复 ID、null、越界、截断、超额、旧 revision、关闭后回调、并发发布及撤销。检查稳定排序、未覆盖范围、保护区、包收据和资源回收。 |
