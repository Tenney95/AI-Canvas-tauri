### 针对图例的组件树

根节点可含背景、顶栏、充值窗、底部导航。充值窗可含标题装饰组、标签组、商品卡网格、关闭按钮。识别到的每张卡保留自己的位置、价格、角标与商品图关系，如「60 钻商品卡」下有「商品图」「价格按钮（¥6）」「首充角标」。默认卡行展示该卡的合成范围及缺项数，展开后才显示子件。按钮上的小星等纯装饰默认随组件交付，策划指定的 8×9 标记仍可保留。价格文字可以附识读文本供美术编辑说明，首版 PSD 将其作为栅格像素层保存。

同模板的七张商品卡保留七个实例，各自价格和商品图。只有像素、透明度、尺寸及适用角色验证一致的素材共享文件。默认 PNG/ZIP 目标选组件级裁片，支持改选子件和明确选择两者。PSD 默认保留图层树和独立可用子层。对含子件的完整卡图提供互斥的「合成卡」与「子层分解」显示分支，当前启用的分支决定原位预览和 PSD 可见层，避免把多个来源相同的透明层叠亮。卡图也可能含原图背景，需要显式标成合成裁片。没有可靠像素证据的缺项留在列表，可手工处理或再生。

## 3. 工作台交互

### 3.1 视口与原图

- 默认适合视口、居中。鼠标在视口内按 **Ctrl + 滚轮** 围绕指针缩放，按住**中键**拖动画面。提供实际像素 100%、适合视口、缩放按钮、手形工具及按住空格左键平移。候选缩放初值 10%–1600%，结合 DPR 与设备上限约束。界面显示缩放比例与当前视图。普通滚轮在可滚动面板保留滚动，模型下拉和输入框保留原有交互。
- 仅在视口中消费可取消的 Ctrl+wheel，按 `deltaMode` 将行、页和像素输入归一化。中键在视口阻止自动滚屏和浏览器默认动作，使用 Pointer Capture 处理越界、`pointercancel`、`lostpointercapture`、窗口失焦和卸载。多快捷键均在编辑器获得相应焦点时生效。请求一帧内合并状态并分层重绘，独立窗口与 iframe 都实测页面缩放拦截和中键兼容。 [W3C UI Events](https://www.w3.org/TR/uievents/) · [Pointer Events](https://www.w3.org/TR/pointerevents3/)
- 图像层、轮廓层、选区与控制点共用 `screen = source × zoom + pan`，缩放时用逆变换求指针处源点，再设置 `pan = pointer − sourcePoint × zoomNew`。命中半径以 CSS 像素表示，运算全部回到原图坐标。DPR 仅影响绘制缓冲。低倍率先用缩略图，精修按可视区域请求有界原尺寸块。普通窗口移动和缩放只更新视口。替换或旋转源图通过独立项目操作处理，旧编辑绑定原源摘要，显式重定向才建立新版本。
- 可切换「原图」「原图与轮廓」「原位回贴」「单片透明预览」。选择列表与画面互相定位，支持仅显示选中轮廓。多层重叠可从候选菜单选目标。缩略图按需创建、滚出优先回收。左侧工具或顶部工具条、主视口、右侧图层树和属性检查器组成可调布局。窄窗口把检查器折叠成抽屉。树行可用键盘选择、展开、折叠、定位和多选。预览可绑定可访问的当前层标题。

### 3.2 编辑命令契约

| 操作 | 提交结果 | 验证重点 |
| --- | --- | --- |
| 框选、多边形、套索 | 生成或更新一个原图选区。支持新建切片、限定识别范围、与已有选区相加/相减/相交。画出 ROI 后显式选择「识别选区」 | 拖动预览即时更新，释放后提交一次。触边、缩放、孔洞、重叠下布尔运算和实际导出一致 |
| 轮廓编辑 | 加点、删点、移动点、调整矩形、增加孔洞。局部矢量轮廓给像素掩膜生成可复查来源。初版使用矩形与硬边套索，软边 A8 由后续蒙版能力承接 | 使用边界坐标与像素中心。拒绝空面积、交叉无解、越界和超预算遮罩。失败保留上一已提交选区 |
| 组合、取消组合 | 只更改图层树、选择范围和组织归属。取消组合恢复子层为同级，子层 ID 与位置稳定。成组后可选「以组件导出」生成合成快照 | 允许多件共存、重叠及排序。跨父组或非连续层先预览会变化的叠放范围；默认同一父级内的连续层无视觉改变 |
| 合并为裁片 | 同源裁片默认在原图坐标并集取样，重叠处每像素只采一次。跨版本、换位或再生层采用参考 z 顺序和确定性 source-over 合成，先预览。新裁片保存成员关系和来源修订 | 原成员保留在可恢复的先前版本中，避免重复输出。同一掩膜内部奇偶填充，多个掩膜之间使用并集，避免把重叠误当成孔 |
| 拆分裁片 | 有来源成员的合并层支持恢复子件。用户也可框选或套索切开，产生交集和原掩膜差集。两块均有像素才提交。可选按连通域提议，零碎项进入审核 | 两部分交集为空，并集恢复拆分前掩膜。拆分继承原坐标、语义与血缘，新层记录自己的偏移和透明范围 |
| 修改、重排、锁定、删除 | 可改名称、分类、用途、注意事项、轮廓、位置、显隐、导出资格及层序。锁定保护已审条目。删除保留可撤销的引用状态并检查关联和组树 | 移动图像是原位放置变化，移动选区是重新取样。两类命令分开，属性显示各自坐标。删除目录或工作稿按宿主现有用户确认路径执行 |

每次完成的交互作为一个命令。Ctrl+Z/Ctrl+Shift+Z 在工作台的编辑历史内执行。送画布走画布历史。编辑操作回滚应恢复树序、选择、几何、编辑字段与状态。整页和 ROI 重识别写入旁支提议，显示新增、相似、冲突和未找到。旧 ID 由一对一候选匹配建议保留，人工接受匹配才合并更改。重名通过角色、原位、模板关系辅助比较，人工编辑与锁定字段优先。 [现有裁剪器](../../../src/components/nodes/shared/image/CropEditor.tsx)

## 4. 组件优先的识别及语义记录

| 阶段 | 产物与约束 |
| --- | --- |
| 源图检查 | 规范化 EXIF 方向与色彩解释，记录原文件摘要、规范 RGBA 摘要、原始与规范尺寸和转换版本。原生位置与输出均基于规范图。发送信息明确接收服务与整图或局部的范围 |
| Layout | 一次整页视觉调用输出页面描述、面板、组件、重复实例、前后叠放线索和缺源原因。默认采用组件级粒度，提供「整块组件」「组件与常用子件」「深度细分」。过滤条件作用于默认交付列表，仍可查看证据 |
| Refine | 仅对用户选区、文字/图标密集区、低置信条目、高量化误差和遮挡边界启动 ROI。优先复用分割或 OCR 能力，局部模型回投按请求记录的裁区、缩放和 padding 逆变换。跨块检测做匹配建议，异角色嵌套保持父子关系 |
| Review | 结构化响应逐项验证，处理无效父 ID、环路、偏序冲突、重复、边界、长度和溢出。缺字段使用未知值。部分成功保留有效提议及无效计数。截断、失败和超限时保留上一工作稿，把未覆盖区挂为待查 |

**每个提议记录**稳定本地 ID 与模型临时 ID、对象名称、角色、用途、简短可见依据、父组件、模板/实例、可见文本、相对前后关系、定位框及轮廓、可见程度、可能遮挡者、缺失原因和建议动作。模型提供的是简明语义和观察依据，字段接受纯文本。用户可编辑说明并保留原提议版本。置信信息区分模型自报值和本地证据等级。位置记录同时包含请求坐标系与校验后的源像素几何。遮挡推断、语义猜测和已确认像素各有状态。

协议适配边界统一处理坐标顺序。插件自定义响应约定 `[x0,y0,x1,y1]`，例如使用 Gemini 文档所示 `box_2d` 时先在对应适配层核对并变换 y/x 顺序。0–1000 整页定位在 8,192 px 边长时步进约 8 px，小件在 ROI 重测后再确认。几何传输统一半开边界，左上取 floor、右下取 ceil，轮廓点用最近像素边界并做量化后拓扑校验。支持跟随连接、OpenAI Chat、OpenAI Responses、Anthropic Messages、Google Gemini `generateContent`、高级自定义 JSON。能力允许时用响应 schema，其他连接走有界 JSON 提取与本地验证。模型的原文、网页内容和图片内文字仅作为数据。 [Gemini 图像理解](https://ai.google.dev/gemini-api/docs/image-understanding) · [六种协议与双密钥](04_模型协议与双密钥来源.md)

调用额度以作业而非永久窗口累加的 UX 展示。短宿主操作、识别、ROI 和生图分别计数、各自取消。现有宿主有独立全局会话预算及每窗口 4 次模型限制。增加长编辑流程能力时通过切图专用排队、输入限额、请求门禁和能力版本实现。原有等候设置继续覆盖宿主操作、模型截止和回包余量，0 使用无本地截止语义，关闭或用户停止仍传播取消。上游平台剩余限时按实际适配器反馈。默认任何档位识别完成即待审核，静默自动补首个缺项在新工作台停止。用户可显式选择一批缺项，再开始有预算的队列。

## 5. 工作稿、坐标与存储契约

### 5.1 持久化实体

| 记录 | 最小字段或行为 |
| --- | --- |
| 工作稿 | `schemaVersion`、`documentId`、`projectId`、绑定节点或可移植来源、规范源摘要、源资源引用、`revision`、图层根序、识别范围和最近保存时间 |
| 图层 | `layerId`、类型（组/像素/缺项）、父级和顺序、可见/锁定/导出资格、语义引用、来源修订、质量档、原图取样 `sourceRect`、蒙版引用、放置 `placement`、资产/候选引用 |
| 素材与实例 | 素材是内容寻址的 PNG 或规范原始像素及摘要。实例独立记录 `assetId`、`layerId`、素材局部原点、裁边偏移、画面落点、可见性和顺序。同一素材可在多个位置使用 |
| 模型提议与再生历史 | 记录结构化短描述、识别参数及 ROI、协议、模型身份、请求转换、输入版本、选区和缺项。生成另外存用户提示词、参数、输入素材/蒙版、保护区、收据和候选版本。凭据、调用授权临时 ID 和供应商临时签名 URL 均不存入 |
| 工作日志 | 以 revision/CAS 串行提交单次编辑，保存有界撤销恢复记录与快照。长作业保存可恢复状态和提交结果，不持久化运行时句柄 |

坐标约定为原图左上原点的整数半开框，蒙版锚点显式记录。比如切片原框 `[30,40,130,100)`，去透明边后局部偏移 `(7,3)`、PNG 尺寸 `80×50`。原位放置时 PSD 边界是左 37、上 43、右 117、下 93。若用户移动位置 `(+10,−2)`，PSD 边界为左 47、上 41、右 127、下 91。原取样框保持原值。导出时分别计算有像素的有效边界、蒙版边界与文档边界。首版支持整数平移。需要缩放或旋转时先作为明确的重采样操作产生新版本。

### 5.2 保存与恢复

- 使用项目作用域的工作稿仓储。索引保存小型 revision/引用和列表摘要，源、掩膜、生成图走既有项目托管媒体或专用受控文件。原图须成为可校验的持久引用，附原图的工作包可在另一项目导入后重绑定。仅持有外部引用时要提供定位及摘要复核入口。界面显示保存中、已保存或明确失败。对话压缩、设置偏好、窗口租约及 PSD 文件均不承担工作稿真值存储。 [现有项目任务仓储参考](../../../src/services/plugins/pluginVideoReplicaJobRepository.ts) · [文件与存储约定](../../文件与存储模块.md)
- 媒体先以内容摘要写入和复核，再在 revision 提交点原子同步索引与引用。文件成功、索引失败时只有可识别孤立件，延迟清扫前确认没有其他活动或历史引用。关闭、换页、重启恢复最后已提交版本。恢复页展示缺文件、未知提交、旧 revision 和保存失败的状态。两窗口打开同稿可先以单写租约实现。被占用窗口显示只读或从已保存稿另存。最终写入仍复核 revision。
- 「保存工作稿」写项目，「导出可编辑工作包」打包 `document.json`、源或显式外部来源、资产、蒙版和素材摘要。ZIP 素材交付另带资产映射与坐标。导入先校验 schema、摘要、路径、重复文件项、文件数量、膨胀字节及像素量。缺失源的旧 ZIP 只恢复已知裁片及原位坐标。有可核验源图时可重建有记录的选区。未知的父子关系、语义、缺项和遮挡下像素留为未知，避免伪造历史。
- 项目归档和导入、备份恢复、删除项目和资产去重均纳入验收。旧宿主插件能力保持 `image.uiSlice`，工作稿服务和各写操作新增版本能力门禁。确保原有包可读取及运行，不能保存新版工作稿的环境可提示打开新版宿主或导出兼容素材。 [宿主能力与兼容](../../../plugin-host.json) · [插件开发规范](../../../../plugins/AI-Canvas-插件开发规范.md)

### PSD 编码决定

首版目标包括可编辑**像素层**、组、透明背景、中文、显示顺序、可见状态和准确的局部边界，默认可选隐藏原图参考层。无损硬边像素由复用的 Rust 裁切获得。蒙版可验证时写入 PSD 栅格图层蒙版，运行时可调它的位置和内容。若小样 writer 无法准确保留蒙版，则界面明确标成烘焙透明像素层，完整蒙版仍随工作稿保留。生成层单列来源。隐藏参考图层和生成原始候选默认关闭。最终合成预览由冻结同一稿生成，PSD 读回后与原位预览比较，核对组内顺序从上到下的映射、alpha、ICC、隐藏层、裁边偏移及出界规则。文字层、智能对象、任意混合模式、PSB 和从 Photoshop 双向回写分别留待后续法证和兼容验证。PSD 首版用于 Photoshop 编辑和交付，工作包负责完整恢复。

阶段零使用 ag-psd 做版本锁定的编码小样。生产方案以单一、受宿主管理的 writer 接口承接。小样测内存、码流可复查性、支持平台和依赖许可。若 JS writer 无法流式写入且不符合压力门槛，就选择原生端经过独立解码器和 Photoshop 验收的 RGB8 子集 writer。在写入前以 checked arithmetic 核算图层/通道大小、文件长度、数量和位图预算。实机用边界图、重叠半透明、隐藏参考、透明孔洞、Z 顺序及中文名称验收。先暂存、校验、最后独占发布，确认发布成功后才能显示完成。 [Adobe 文件格式规范](https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/) · [ag-psd writer](https://github.com/Agamnentzar/ag-psd/blob/master/src/psdWriter.ts) · [现有归档发布](../../../src-tauri/src/plugins/ui_slice.rs#L369)

### 单片再生与画布衔接

单片详情先展示本片、源上下文缩略图、遮罩和语义。推荐把「保持原构图、原尺寸及风格」「对象用途」「可改范围」写成可编辑提示词草案。提供模型、比例、尺寸、质量、输出数量，以及模型支持时的蒙版/种子/透明背景。主要流程为「基于本片编辑」「补齐遮挡或底板」「用本片作为参考生图」。区别在实际输入：第一种发送冻结裁片和可选编辑蒙版，第二种还加受授权的上下文与保护区，第三种可由图生图模型自由重绘。在画布中可创建携带提示词和参考图的图片节点，用户也可在工作台直接运行。发送到画布本身不发模型请求。 [现有图片外扩服务](../../../src/services/imageOutpaintService.ts) · [统一生成运行时](../../../src/services/ai/generationRuntime.ts) · [OpenAI 图像编辑](https://developers.openai.com/api/docs/guides/image-generation/)

宿主用租约物化完整 PNG、蒙版和参考图，插件 UI 交换资源 ID 及有界预览。现有 240,000 字符候选通道保留给兼容入口，新的原尺寸回传走项目媒体。识别和生图模型分开选择，无需搜索，列出当前目录的全部匹配项，暂不可用项给明确原因。按图像输入、图像输出、局部蒙版和多参考能力过滤实际可执行模型。模型若只能基于参考重绘，显示实际模式，原位替换仍需用户审核。宿主凭据和插件自设凭据都从 Provider 密钥服务代取，复用共享协议适配器。 [模型目录](../../../src/services/plugins/pluginModelCatalog.ts) · [资源租约](../../../src/services/plugins/pluginResourceService.ts) · [双密钥方案](04_模型协议与双密钥来源.md)

对带保护区编辑，供应商输出是候选。按冻结的 ROI 与映射将回图转换到规范画布，再在本地按确认蒙版合成，编辑区外 RGBA 必须与输入完全相同。掩膜软边与原始 alpha 各自保留，源图不可被自动覆盖。出现不相容的尺寸、长宽比或定位关系时保留回图待对齐。随候选保存模型、输入摘要、提示词、参数、位置、保护范围、输出摘要及状态。上游提交状态未知时先查收据/任务 ID，由用户决定是否重投。

## 7. 生命周期、性能与权限

- 编辑主线为 `打开/恢复 → 编辑 revision → 原子保存 → 冻结所选 revision → 消费/发布`。识别、单片再生和导出各有独立作业状态。冻结任务记录项目、目标节点、源摘要、工作稿修订、插件 revision、模型设定及操作 ID。停止后取消尚未发起的工作，已发送的远端调用记录实际状态。返回前复核所有绑定。迟到的结果只有在仍获授权时可记为该修订的候选，当前稿不会被旧任务覆盖。发布提交点之前可撤销暂存，提交点之后以收据确认结果。
- `pluginUiSessionService` 按现有 claims 检查活动插件、画布和会话。旧版 `submit` 面向一次性交付，新版工作台的连续画布发送应走受限专用 effect。只准当前项目的合格图片节点输出，成功时同一动作提交一次画布历史。项目、源图、插件停用/升级或会话终止使旧授权失效。视口在运行期处理已获授权的缩略图或受限 ROI，原生层复核本地路径、内容身份、输出版式和用户选定输出路径。 [会话宿主](../../../src/services/plugins/pluginUiSessionService.ts#L194) · [派生守卫](../../../src/services/canvasDerivationGuard.ts)
- 当前硬限制包括源图 8,192 边长和 32M 像素、单裁片 8M、批量 64M、128 个导出项、每片 16 环和 128 点、512 MiB ZIP。先保留旧发布契约。新版将逻辑组与内部处理块分开，超单片上限的最终大资产按分块或流式编码解决，避免把大背景拆成若干可见业务图层。可用空间不足时提供预检和可核查原因。范围超限的降级保留人工选择，不以静默丢片换成功状态。 [像素限制](../../../src-tauri/src/plugins/ui_slice_pixels.rs) · [宿主预算](../../../plugin-host.json)
- Windows 参考机建议记录双窗口、高清屏、同图 128 层和接近上限图的 p50/p95、Peak RSS 与响应性。交互目标 p95 单帧 ≤16.7 ms（60 Hz 参考），首次导出/识别另测。缩略缓存按字节计量，按可视区调度，鼠标移动复用已有结构和缓冲。预热后的原生扫描线/掩膜热循环做 0 次分配、0 次重分配和 0 字节分配计数。当前 Rust `render` 已用调用者缓冲和固定交点数组，`render_verified` 会 resize、编码、解码并分配。工作台 JS、IPC、编码和库内部 GC/分配需各自实测，有单独预算。 [Rust 像素热路径](../../../src-tauri/src/plugins/ui_slice_pixels.rs#L190) · [PSD2UI 实测边界](<../../../../../PSD2UI/analysis/效果图AI切图_20261123/08_首版实施与放行判定.md>)
- 文件名用 host 生成或清理，目录无意外覆盖，拒绝路径穿越、软链接/reparse、重复名字、超限解压、循环 tree 和未知高版本数据。模型字段按纯文本渲染。所有对外调用走已选连接和配置，权限校验、费用额度、敏感信息脱敏和用户提示来源复用现有宿主。下载的外部模型候选先由宿主做尺寸、解码、来源和会话验证。导出/恢复跨窗口能力需要在 iframe 和原生 WebView 分别验收。
