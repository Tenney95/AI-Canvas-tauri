# AI Canvas UI 切图再生

2026-11-24 · 开发与维护方案 · AI Canvas 0.11.12 · 初始调研 `dc589c03`，模型与凭据核对 `04f8385e58e0`

在图片节点打开「UI 切图再生」，用户选定当前效果图、交付模板和策划说明，点击一次「分析整页」。插件列出整页应交付的素材、实例和缺项，自动准备可取证的候选。对被遮挡、被压平或未展示的状态，用户可通过「再生已选缺项」授权一批候选的处理范围和费用。统一复核后一次导出原尺寸 PNG、回贴报告和可导入清单，未解决的缺项随包保留。

「一次性」指一个页面任务贯穿识别、审核和出包。宿主内部可按区域和预算排队，候选集也可在一个任务内分区复核。重复元素的每个位置均保留，确认可复用后共享同一个素材文件。产品的完成标准是**所有已确认的交付项都有结果或明确状态**，自动发现对未知缺项的覆盖率用同稿标注集衡量。

## 继承前序调研和实机证据

阅读了[「调研AI精确切图方案」](codex://threads/01a20761-9060-7e73-9fa8-e8641d3ef82c)及 [PSD2UI 九份文档](<../../../../../PSD2UI/analysis/效果图AI切图_20261123/00_决策与阅读入口.md>)。PS-Tidy 的交付路线已经从调研推进到 Windows CEP 0.7.5，本地提交 `a4dfaa0`、`577f133`。参考实现覆盖带审核的矩形和硬边套索、像素回贴、原尺寸 PNG、回读和任务取消。实机补丁修正了预览图片加载，避免将预览解码未完成误报为成功。

本次用独立 PNG 解码器只读复核了 750 × 1334 首充快照、两张 PNG 和清单文件摘要。两张充值卡分别为 314 × 217 和 321 × 217，合计 **551,180 字节 RGBA** 与快照原位逐字节相同。清单将二者标为人工矩形选区的合成图裁片。前序 Release 的零堆分配数据对应 PS-Tidy 像素内核；真实视觉模型的游戏 UI 定位精度、软边分割、整页召回及可编辑 PSD 均需专项实测。 [0.7.5 原始清单](<../../../../../PSD2UI/analysis/效果图AI切图_20261123/CEP实机验收/0.7.5-首充切图/verified-yALUGj/切图-da4b6897baf1013ca87046a4/manifest.json>) · [首版验收记录](<../../../../../PSD2UI/analysis/效果图AI切图_20261123/08_首版实施与放行判定.md>)

识别与再生各自配置模型。云端可以引用 AI Canvas 中现有连接的 API Key，或使用插件专用连接的 API Key。六种识别选项为跟随连接对话协议、OpenAI Chat、OpenAI Responses、Anthropic Messages、Google Gemini `generateContent` 和高级自定义 JSON。OpenAI Responses 支持内置协议和现有预设插件。再生连接按参考图、图片输出、蒙版、回投和成本的实际能力验收。产品默认本地执行。 [模型协议与双密钥来源](04_模型协议与双密钥来源.md)

## 产品与发布范围

| 用户具备的素材 | 预计交付 |
| --- | --- |
| 单张普通 PNG 或 JPEG 效果图 | 整页候选、手动校准、合成矩形、经复核的估计掩膜、原尺寸 PNG 和缺项报告。JPEG 精确度以固定规范化解码结果为基准 |
| 原生透明 PNG 或有授权且能验证的项目素材 | 保留原始 alpha。原件比对通过后记录源引用、独立贴图与原位关系；原件与截图在缩放、透明或混色上有歧义时进入复核 |
| 分层稿 | 后续经 Photoshop 适配导入已渲染图层和证据，处理文字、剪贴、混合模式和依赖项。首期可用 PS-Tidy 输出的扁平快照建立对照 |
| 需补遮挡、去字补底板或生成未展示状态 | 用户按已选缺项授权后发起再生。生成区域、原可见区域、参数和候选版本分别留证。拒绝或失败的缺项继续出现在报告中 |

整页预设首批覆盖**导航、首充/商城、奖励弹窗、排行榜**。策划要求拆成可检查的交付条目，例如「导航五个无字图标」「数量为动态文字」「输出按钮常态，禁用态待设计」。自动识别返回条目来源、角色、父子和叠放证据。复核界面可切原位叠加、1∶1 透明底、爆炸视图和缺项筛选。手工框套索、局部精修和整页自动在同一任务使用统一坐标、版本与审核。

实施按三次产品放行推进。第一轮提供离线参考线、区域网格、透明沟槽、手工精修和整批交付。第二轮用 OCR、局部分割和视觉语义补齐层级、小件及未覆盖规格，验收两种 Key 来源和全部六种带图识别选项，并让审核树表达可编辑文字、受支持的形状和独立栅格。第三轮按实际图片编辑通路、已审掩膜和保护区验收开放去字、遮挡补齐和新状态再生。Windows 本地桌面优先验证，跨平台桌面、Web 预览、Figma、分层 PSD 和 Unity 各自记录导入能力和版本矩阵。 [专项取舍](03_ImageToSlice专项对标与优化.md#3-整页任务的具体增量)

当前完成了调研和设计。项目自动识别及再生的准确率、性能、授权和兼容性为开发放行门槛。AI Canvas 的应用测试、构建、基准和实机验收本次未运行，待用户验收。
