## 用户 Tauri 桌面验收

前置：备份项目和应用数据，使用测试项目；按所测平台安装对应新包。模型实测需用户自备有效连接与权限，付费生成由用户自行决定。

1. 万象已有连接不先拉取，打开分组应补入未选的新候选，勾选后在节点可用；检查两款 2.6 的 PNG 参考编辑与文件顺序，GIF／SVG 仅方图文生并保留原始格式。切换 2.0 C1／C2／C3、H3 仅有 15 秒，2.5 C1／C2／C3 仅有 30 秒；旧非法值提交前要求重选，A 的整数边界、四款官转、自定义能力和历史任务恢复保留原合同。
2. 火山连接先配置北京区私有 Bucket 与 TOS AK／SK；本地及外部 URL 的图片、视频、音频参考走 TOS，人像入库共用上传但单独启用及配置入库凭据。缺配置、权限不足或取消应明确失败，不改传公共图床；模型 API Key 不能替代 TOS 凭据。
3. 配置全局自定义上传，分别检查图片／视频／音频及厂商专用上传优先级；失败停止，不换服务重试。开发模式诊断不显示凭据、素材正文或本地路径，生产包不将其变成普通日志。
4. 工作台逐个显隐分栏，编辑区和草稿保留；对大纲、剧本、原文及 MD／TXT 请求 AI 修改，预览不改原稿，明确采用后再手动保存。切换正文、继续手写、取消或生成失败时不允许旧候选覆盖新稿；核对模型／团队选择与助手同步。
5. 单节点扩图选择工作流后保留原图、只增加结果节点；遮罩保存后重开保留。模拟保存失败，应暂停并保留编辑，手动成功后恢复；回归静置不循环保存、人物提取保存、文件夹开合及撤销／重做。无火山且无历史账本时保存普通设置不触发同步警告；真实目录或账本冲突应提示具体原因。
6. 独立助手依次进入主页、项目 A／B，检查会话、模型及各页草稿跟随，发送与返回正常；清空输入后关闭不误拦，发送期间的新稿不被迟到确认清除。普通任务不因原累计预算自动暂停，显式团队及子任务预算保持；失败与待确认状态仍可见。
7. Windows 标准／Legacy 与 macOS 的安装、升级、首次打开、项目往返及下载恢复分别验收；明暗主题、窄窗口和取消路径逐项检查。跨平台结果分别记录，不用 Web 演示或单平台结果代替。
