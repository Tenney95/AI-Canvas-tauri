# 资源文本与 Markdown 共用编辑器

状态：已实施，等待用户手动验收。最初编辑器阶段按当时用户要求未运行测试、构建、类型检查或浏览器验收；后续改名能力的验证单独记录如下。

## 范围与行为

资源库及最近使用中的 Markdown、文本点击进入大屏，左侧内容、右侧提示词和文件信息。Markdown 文件与 Markdown 节点大屏共用 UI Kit 的 `MarkdownEditor`，支持编辑、预览、分栏、格式工具、查找替换、撤销重做及字符/行数。保留现有安全渲染，不引入依赖；UI Kit 展示真实可编辑样例，颜色复用主题变量。

文件编辑保留内存草稿，主动保存至原文件；未保存关闭或重新载入要求明确放弃。读取限制为 2 MB 的 UTF-8 普通文本文件，拒绝符号链接、无效编码和二进制内容。保存保持 BOM 与 LF/CRLF，比较正文摘要，检测外部改动后拒绝覆盖；失败保留草稿。摘要校验与写入间仍存在外部进程竞争窗口，当前不保证跨进程原子比较写入。文件正文不新增持久化到数据库、日志或元数据。

Markdown 节点沿用编辑内容的既有持久化语义与防抖自动保存，已有文件持续覆写同一文件，新节点只创建一次文件。文件编辑同步当前项目的匹配节点前校验正文基线、项目与 canvas derivation guard，失效不覆盖画布。生成信息只按完整文件引用匹配唯一节点和成功历史；不按文件名猜测。

节点保存基线从打开时的磁盘文件读取，与节点草稿独立，兼容旧记录中节点与磁盘正文不同步的情况。确认关联文件不存在时，将节点正文恢复保存到项目目录的新文件并更新关联；权限错误或外部修改冲突不触发恢复。保存失败展示实际失败步骤与底层错误，保留节点正文。

Markdown 节点改名复用资源库的文件改名 Action，保留扩展名并同步文件路径、资产身份和持久化引用；失败保留原名。改名与节点自动保存共用顺序队列，先保存待写入的内容，再改名，后续保存使用新路径；尚未生成文件的节点将新名称用于首次保存。

## 2026-10-08：资源文档改名

文本与 Markdown 预览标题增加与图片一致的改名入口，保留扩展名；普通 JSON 等文本分类文件和空文档同样支持。复用 Store 的资产改名 Action，保留资产身份、标签、项目归属及子目录，同步资源列表、对应节点标题、文件路径和持久化引用；后续正文保存使用新位置。未保存正文须先保存或重新载入，改名期间禁止正文编辑、重复提交和关闭；失败保留输入，引用提交失败仍按既有流程恢复原名。

文档内容校验沿用 UTF-8、2 MB、普通文件及符号链接限制，不调用图片专用非空指纹。项目内导演台预演、场景、结果清单和 AI 应用定义的固定摘要 JSON 拒绝直接改名，避免破坏内部不可变引用；普通文本副本可以改名。无新增依赖、安全配置或数据库版本变化。
