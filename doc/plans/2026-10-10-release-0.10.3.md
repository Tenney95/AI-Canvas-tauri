# 0.10.3 发布

日期：2026-10-10。目标版本：`v0.10.3`。比较基准：上一正式版本 `v0.10.2`。

用户已确认编辑中后连线自动 @ 场景正常，授权提交并恢复发布；`v0.10.3` 标签将在最终提交的远程门禁通过后创建。

## 范围

- 纳入已合入的视频复刻后台全片任务、统一素材引用、插件子目录安装、共用播放器与时间轴、提示词发送快捷键、节点模型清除、资产引用完整列表和 Win10 剪贴板降级。
- 同步应用及锁文件版本、四语言 README 徽章、站点与说明书版本；新增操作以源码核对，保留历史文档核对基线。
- 发布说明来自提交和代码差异，保留 Legacy、ONNX、可信 Python 与 macOS 临时签名的兼容性说明。发布名称和正文同步工作流，构建矩阵及权限保持原配置。
- 修复发布门禁发现的 SDK 声明缺失，并将已有播放器/节点生命周期回归更新到共用播放器边界；保留原有按需挂载、资源释放、截帧过期拒绝和全屏切换断言。
- MCP 可执行入口固定 LF，避免 Windows 干净检出后的 CRLF 触发 Vitest 模块加载错误；原生 Node 语法检查和 LF 后的定向用例已通过。
- 提示词胶囊新增拖动移动与 Ctrl/Alt 拖动复制，支持文字中间、跨行与取消；复用引用身份、序列化和编号，不触发原生文件拖放。
- 小地图移除外层重复边距，与缩放工具栏右侧对齐并缩小上下间距；热区覆盖完整小地图，窄窗口沿用相同布局。
- 补充编辑中后连入素材的自动 @ 同步修复：合并新增引用与用户输入，保留主动删除语义及中文组合输入；正在编辑的上传、导入或结果素材不再因来源角色被跳过。后连线自动引用场景已获用户确认，自动化回归纳入最终发布门禁。

## 用户验收与回滚

- 更新 Tauri 桌面端后检查模型按钮高度/悬浮效果、14px 厂商标识、× 清除和重新选择；在 @ 菜单切换分类并滚动完整道具列表。
- 自动 @ 同步修复的前置条件：使用当前代码的 Tauri 桌面端，开启“设置 → 常规 → 素材引用 → 连线后自动 @ 素材”。打开已有生成节点并输入文字，再接入第二、第三个素材；预期新引用自动出现，继续输入中文、点外失焦及重开面板后，正文和引用均保留。
- 回归重复连接、主动删除旧胶囊后连入另一素材、关闭开关后新增连线、工作流值区输入及切换节点/项目；预期引用不重复、被删旧胶囊不复活、关闭时不追加、工作流正文及其他节点/项目不被迟到输入覆盖。
- 按 M 显示小地图，检查右边缘与缩放工具栏对齐、两者之间留有间隙；调整窗口宽度并切换深浅主题，检查小地图拖动导航、缩放和四周悬浮统计。
- 混合文字和音视频/图片/文本胶囊，拖到行首、文字中间、行尾和其他行；Ctrl/Alt 复制时原件保留，引用编号同步，关闭重开保留顺序。再检查 Escape、输入框外松开、切换节点/项目、滚动与工作流值区文字选择。
- Win10 复制图片后在支持文件粘贴的目标应用粘贴；核对播放器切换、暂停释放、全屏恢复和截帧。完整视频复刻、真实厂商调用及各平台下载安装仍由对应环境验收。
- 核对正式 Release 的名称、正文、非草稿/非预发布状态，各平台安装包及签名，以及 latest.json；runner 检查不代替实际下载安装和自动升级。
- 标签推送前可撤销本批发版差异；标签推送后不覆盖标签，后续修复发布新的补丁版本。
