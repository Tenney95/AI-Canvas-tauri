# ComfyUI 官方便携版一键安装计划

**Goal:** 在主设置页安装目录旁提供安装按钮，让用户选择位置和显卡类型，下载官方项目及配套环境，完成后复用已有启动与管理入口。

**Architecture:** 主窗口专用原生命令通过系统目录选择器登记一次性安装目标；Rust 按内置官方发布清单下载、SHA-256 校验、受限解压和环境检测，原子发布新目录后保存已有原生安装授权。下载复用文件传输落盘基础设施，网络连接或读取超时后只回退一次国内加速源；取消和本地错误不切源。

**Tech Stack:** Tauri 2、React、UI Kit、reqwest、SHA-256、sevenz-rust；不新增数据库，不写全局 Python/CUDA 环境。

## 范围与实施

1. 官方清单：固定 `Comfy-Org/ComfyUI` 的 `v0.41.0` 发布资产、大小和 SHA-256（2026-10-18 从官方 GitHub Release API 读取），提供 NVIDIA、旧 NVIDIA、AMD、Intel、CPU 和 Windows ARM64 对应选择；此版本随应用维护更新，不从镜像接受可执行包摘要。
2. 原生 `media/comfyui/installer.rs`：主窗口来源校验、原生目录选择和一次性目标 ID、安装互斥、取消、官方优先/国内加速一次回退、固定清单校验、解压边界、环境检测、发布及原生授权保存。提取安装完成所需的已有持久授权与启动设置保存辅助函数。
3. UI `ComfyInstallDialog.tsx`：目录、文件夹名、环境选择、真实分阶段进度、取消及安装后启动；主设置页仅装配入口及经 Store Action 同步安装镜像，沿用现有启动流程和控制台。
4. 原生命令注册及精确权限；模块文档保留入口链接。本次不修改 README、已有安装或系统驱动，不实际下载和安装大包。

## 边界

- 安装目录和程序/URL/参数不能由 Renderer 自由提交；目标仅来自原生系统选择器登记，Renderer 只传目标 ID 与白名单环境 ID。目标父目录和实际路径每阶段复核，不增加通用 fs/asset scope，拒绝链接、目录联接、应用私有目录及路径穿越。
- 已存在的目标不覆盖。下载及解压先在同盘唯一临时目录进行，失败/取消只清理该任务自己的目录；成功校验后发布。未保存原生授权前不视为成功；安装失败保留原安装选择。
- 发布目录后分别保存启动设置和原生用途授权，授权保存失败时尝试恢复原启动设置，保留已解压的新目录供用户手动选择。两份记录不是跨文件事务；若应用在此极短阶段被强制终止，需检查原生目录选择及 CPU / GPU 设置。临时目录身份变化或无法确认时拒绝递归删除并提示核对；异常终止的残留不会在下一次安装中自动清空。
- 解压拒绝绝对路径、父路径、ADS、设备名、链接/特殊项、重复路径及超限文件集合，检查磁盘空间，保留有界内存与可取消进度。
- 环境来自官方便携包，安装时运行固定 Python 检测；不接收自由脚本，不安装任意 pip 源或第三方插件，不自动安装系统显卡驱动。GPU 不可用须明确提示，不能把包下载成功说成真实模型生成验证通过。
- 原始进程输出、完整绝对路径和密钥不写日志。显示安装路径仅用于用户核对；持久选择只进入既有原生用途授权及前端配置镜像。
- 只在受支持的 Windows 平台自动安装；其他系统保留明确说明和既有手动安装入口。

## 验收与状态

已实现：入口与弹窗、原生下载/校验/解压、依赖检测、取消与互斥、目录持久授权和安装后启动；已补充归档路径、清单及取消绑定的单元测试源码。本次未运行测试，待用户验收。功能实现阶段仅完成源码/权限/UTF-8 静态核对及 Cargo 依赖解析，未运行 lint、类型检查、构建、自动化测试或实际安装；提交时按规则通过既有钩子执行定向 ESLint，不代替功能验收。

维护发布清单时从官方 Release API 重新核对资产名、字节数与 SHA-256，并在真实 Windows 环境确认包内结构与 Python / PyTorch 依赖。镜像不参与版本或摘要决策；当前固定 v0.41.0，后续版本随应用更新。

用户在包含本次 Rust 变更的 Tauri 桌面端验收：

1. 设置 → ComfyUI → 安装，选择空闲位置和合适环境。取消目录选择应保留此前选择；现有文件夹、非法名称、链接或私有目录应被拒绝且不修改文件。
2. 官方网络可用时应显示官方源、下载字节和进度；阻断官方连接或让读取超时，应明确切换国内加速且从零重新下载一次。取消、磁盘空间不足、摘要不符或解压失败不得自动切源继续写入。
3. 在下载、校验、解压、环境检测阶段分别取消；只清理任务临时目录，旧安装仍可启动。重开或重复操作不能产生两个安装任务。
4. 成功后安装目录自动记住，重启应用仍可恢复；“安装后启动”复用既有启动/HTTP 就绪探测和运行控制台。只安装时不启动服务。缺少兼容 GPU 驱动应明确提示，CPU 选择应按 CPU 启动。
5. 两种主题、窄窗口、键盘导航及关闭设置面板场景核对。GPU 驱动兼容、真实大包下载速度、环境可用和模型生成仍需实际机器验收。
6. 对原生授权记录或启动设置制造不可写情况，确认安装不谎报成功、旧选择保留且给出新目录手动接入提示。安装过程中退出应用后检查残留，后续任务不得覆盖或擅自清理先前目录。

可选命令（由用户执行）：仓库根目录 `npm run check`；`src-tauri` 目录 `cargo check`、`cargo test comfyui::installer::tests`。

## 回滚

停止安装任务后撤销本专项源码/清单/依赖与入口；不自动删除用户已完成的安装，不撤销旧安装选择，不回滚外部模型或驱动。临时目录只由带有任务身份校验的原生清理流程处理。
