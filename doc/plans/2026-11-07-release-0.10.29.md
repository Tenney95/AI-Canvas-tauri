## 版本与兼容性

- 五份版本资料和四语言 README 徽章同步到 0.10.29；站点、说明书及当前发布导航按本轮真实源码更新，不把文档更新当作已公开。
- 数据库仍为 v27，项目包及协作交换格式仍为 v3；不新增数据库迁移或修改依赖解析。升级前备份项目与应用数据，不用安装旧程序降库。
- 稿件统一在项目 `manuscripts` 目录保存 UTF-8 TXT。原文默认为 `原文.txt`，分集使用实际名称。首次保存、旧稿转存和分集改名均由显式保存触发，原文件保留，重名分配唯一名称；外部修改通过摘要冲突拒绝覆盖，暂不监听文件自动反向同步。2 MiB 及 UTF-8 边界继续有效。详见[稿件专项](./2026-11-07-manuscript-txt-files.md)。
- 原文 AI 生成只发送有限片段，候选采用后仍需保存；工作台创作草案和团队成果遵守当前授权、预算及目标版本。只读子智能体不获得画布写权限，模型调用可能计费。
- Codex 外部执行器仅接受已登记的 0.167.0 原生程序，需单独的 OpenAI API 凭据；不接管现有桌面对话或复用 ChatGPT 订阅额度。本机进程仍具有当前用户权限，摘要登记不是系统沙箱。真实原生程序和计费调用待用户验收。
- Windows、Linux、Apple Silicon macOS 与 Windows Legacy 沿用现有工作流；不新增 Intel Mac 包。Legacy 无本地 ONNX 和自动更新；macOS 临时签名未经 Apple 公证，首次打开见[发版流程](../打包与发版流程.md#macos-临时签名与首次打开)。

## 桌面验收入口

1. 准备含两个分集的剧集，打开工作台后选另一集，应只切工作台材料。独立窗口编辑后收回，草稿与所选页签保留；生成分镜前仍需画布位于目标集。
2. 切换大纲、原文、剧本、创作要点、角色、道具与关系图，右侧工具应对应当前内容。「Agent协作」集中设置组合包、智能调度／团队、角色模型和预算；打开设置本身不发起模型任务。
3. 未添加原文时手写或按要求起笔，采用候选并保存后检查 `manuscripts/原文.txt`，重新打开核对正文。保存两集剧本应得到对应集名 TXT；旧原文转存、分集改名和同名文件均保留旧文件。回归外部改稿冲突、无权限、保存失败重试、切项目和独立窗口。
4. 在故事关系图维护人物／事件／伏笔与关系，切换卡片／点阵、时间线／列表并按分集筛选；查看原文证据不换画布。候选提取先预览再选择入图，来源修改后提示核对。
5. 配置已授权 Skill 和只读子智能体，分别从助手及工作台发起复杂创作任务，核对调用、范围、预算和草案；停止、继续和成果应用不覆盖新编辑。导出导入及三方合并保留稿件与图谱关联。
6. 插件设置核对活动版本诊断与模拟预览，缺失必需依赖时阻止执行；预览不安装插件或调用真实工具。外部执行器仅在用户自备程序与 API 凭据后单独验收，不作为发版自动付费测试。
7. 回归长对话滚动、媒体预览、资产面板、系统／深浅主题和独立窗口同步；各平台安装、升级和自动更新由用户验收，runner 检查不替代实机。
