## 范围与兼容性

- ComfyUI 普通保存明确更新、另存明确新建；原记录删除后拒绝复活，新建在串行队列内再次检查 ID 冲突。保存超时保留原请求和来源标签，重复请求复用结果；无 ID 或旧 ID 的回执不能释放当前保存，确定性无效载荷可修正后重新保存。
- 已收到的生成任务 ID 先落盘再处理本地停止；发送后结果不确定时保留防重记录与人工核对入口。旧版取消不使用全局中断，排队删除后再次查队列，远端未确认结束时仅停止本地等待。
- 参数面板与 RefMod 目录共用两种 COMBO 选项解析；API 载入返回 false 时不改绑旧图。音频生成、续查与旧缓存不把封面图片当作音频。启动服务用有界 `/system_stats` 结构识别，不盲目复用其他端口占用或结束未知进程。
- 提示词栏工作流编辑按钮移到右侧、去背景边框，底部工具下方对齐；ComfyUI 顶栏拖窗随实际菜单高度调整，真实控件与 SVG 不触发误拖。
- 累计 v0.10.26 已准备的输出描述符、相对子目录与原文件续取、保存诊断、恢复入口去重及大媒体下载等待修复；保留原任务、原服务与项目／尝试身份，不自动重投生成。
- 累计项目跨设备导入、素材关联及重开保存修复；Amam／万象模型连接与余额、MCP 断连恢复、取消及完整结果交付、独立对话窗口项目切换修复。实际范围可追溯至 `v0.10.25..HEAD` 与本次发布差异。

数据库沿用 v27，项目包沿用 v3，本版不新增迁移。保存幂等只覆盖当前主窗口会话内保留的最近 64 条请求，不承诺跨重启恢复；升级后需重开编辑窗口，旧副本不自动删除。缺少 ID 的远端请求不能自动找回；旧版无法安全取消时需在 ComfyUI 页面停止。多产物仍只接收首份匹配结果，纯 WebSocket 二进制图片暂不交付，需文件输出节点。结构识别不是进程归属证明，认证或结构不兼容服务会明确失败。Windows Legacy 无 ONNX／自动更新；macOS 仅 Apple Silicon、临时签名且未经公证。

## 桌面验收（待用户执行）

1. 升级后重开 ComfyUI 编辑窗口，从画布修改并连续保存同一工作流；列表数量与原节点选择不变。删除原记录后普通保存应报错，另存只新增一条；超时重试、切换标签和迟到回执不得新增副本或覆盖其他记录。
2. 提交刚发出时停止，分别模拟回执迟到与提交后断开；拿到 ID 的任务仍可续查，没有 ID 时保留核对与防重。旧版运行 A、排队 B 时停止 A，B 不应被全局中断；排队转运行的竞态不能误报已终止。
3. 使用两种 COMBO 声明的工作流与 RefMod 目录，核对选项及真实数值类型；非法选项、越界文件名和路径仍拒绝。仅封面音频图及旧 PNG 缓存不得作为音频交付；原历史有真实音频则取回音频。
4. 测试其他程序占用端口、真实 CPU／GPU 服务已启动，以及 API 载入拒绝；未知服务应报错且不结束进程，拒绝载入不得将旧图绑定到目标记录。核对宽窄窗口拖窗、菜单、SVG 按钮和工作流标签。
5. 继续核对正式／临时输出、中文子目录、历史已清但文件仍在的续取、保存失败后恢复及项目切换保护；重试不新增 `/prompt`。只交付首份结果的现有限制保持明确。
6. 备份后跨设备导入带中文、多层素材的项目，关闭重开后编辑保存、重新导出；损坏包与真实缺失素材仍拦截。厂商连接、余额口径、真实付费生成、MCP 断连和跨项目对话仍需分别验收。
7. Windows 标准／Legacy、macOS Apple Silicon 和 Linux 的安装升级、首次打开、签名及自动更新仍需各平台实机确认，不能由本地前端 CI 或构建启动替代。

详细故障场景与行为边界见[ComfyUI 可靠性专项](./2026-09-08-comfyui-reliability.md#2026-11-05-提交取消编辑保存与版本兼容)。
