## 升级与兼容边界

- 旧项目、素材目录、连接 ID 与凭据继续按原绑定使用；正式迁移开关保持关闭，不自动迁移真实用户数据。应用数据库仍为 v27，新项目独立仓储与 v4 包沿用 v0.11.0 边界，不在本版另做格式升级。
- 新结构继续兼容 v1/v2/v3 包；含输出历史的 v4 包需 0.11.0 或支持相同字段的读取器，早期严格 v4 客户端仍可能拒绝。升级前备份项目包和应用数据，回退旧安装包不会自动反向转换数据。
- 统一型号基线不等于覆盖用户配置或把所有渠道参数拉齐。完整旧内置 H3 的连续 4–15／4–30 秒快照仅在运行期投影为四档，部分与用户修改的能力不改写；旧节点的非法时长在上传前拒绝，不静默改成新档位。
- 万象新视频分组使用文档 API 地址；已有连接和导入的旧官方地址保留。原任务沿原来源、ID、查询和取件合同恢复，不因模板更新跨源转发 Key 或重新生成。King 的采购专用参数不进入万象客户接口，其他渠道 H3 保持自身合同。
- Windows 标准包、Linux、Apple Silicon macOS 和 Windows Legacy 按既有矩阵发布。Legacy 无本地 ONNX 与自动更新；macOS 为临时签名，未公证，下载后首次打开仍需按说明处理并实机验证。

## 验收缺口

模板统一提交曾通过相关回归及推送门禁，但后续万象、Muse 和画布改动不能复用这些旧结果作为本版证明。Muse 纯文字生图有用户返回反馈，参考图／视频完整交付和 Mac/Linux 网页能力仍需验收。万象四档时长及不同素材组合尚未做真实付费出片验收；渠道线路可能只接受部分组合，失败不得静默删素材或换档重投。

v0.11.0 记录中的新结构复杂恢复、多窗口剪辑、MCP 独立工程 ID／占位重叠和 prompt-only 全局素材可移植性等缺口，没有因本轮参数修正而宣告解决；详见[原发布计划](./2026-11-09-release-0.11.0.md)和[新结构测试记录](./2026-11-09-新项目结构测试记录.md)。实际下载安装、自动升级与跨平台桌面行为继续单独验收。

Tauri 桌面回归重点：

1. 在旧万象 H3 连接和新视频分组检查四档按钮及默认 15 秒，分别提交受控 15/20/25/30 秒请求；16、21、29 秒须在上传前拒绝。其他渠道及自定义能力保持原限制。
2. 检查 C2/C3 的 5/10/15 秒、C3 音频拦截、2.5 C1 的 21:9 及参考编号；完成、断网、取件失败和重启均沿原任务，无第二次生成提交。
3. 对旧 URL 回执与新 `/content` 回执分别恢复；刷新配置前后不换任务和来源。提交仅返回 `task_id` 时可继续原 ID，双字段冲突保留未知。
4. Muse 已登录后检查纯文字、参考图和视频发送就绪及送达状态；上传／发送异常不补发，已出现媒体可续取。不要把点击成功或网页文字当作实际生成完成。
5. 本地媒体节点可复制文件路径、打开所在位置；仅远程链接不显示路径入口。没有待恢复转场任务时，不显示空的检查卡片。
