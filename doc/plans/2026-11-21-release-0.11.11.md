## 运行时与兼容性

- Tauri 核心采用本地补丁的 2.12.7，Wry 运行时为 2.12.5。Dialog、Global Shortcut、Process、Shell 和 Updater 在 npm 与 Cargo 中使用配套版本。主窗口文件权限改用显式操作许可与默认拒绝规则。实例级 IPC 队列、取数权限、关闭撤销和 WebView 隔离继续由本地补丁管理。 [本地 Tauri 补丁](../../src-tauri/vendor/tauri/PATCHES.md) · [默认 capability](../../src-tauri/capabilities/default.json)
- 本地 Channel 取号和 MCP 并发计数使用 `try_update`。vendored Tauri 声明最低 Rust 1.95，源码及发布工作流固定 Rust 1.99.1。 [Cargo 清单](../../src-tauri/vendor/tauri/Cargo.toml) · [发布工作流](../../.github/workflows/release.yml)
- 数据库版本沿用 v27。Windows Legacy 不含本地 ONNX 与自动更新。macOS 仅提供 Apple Silicon 临时签名安装包，未经 Apple 公证。Linux 安装包暂停。 [数据库 schema](../../src/services/indexedDb/schema.ts) · [打包与发版流程](../打包与发版流程.md)
