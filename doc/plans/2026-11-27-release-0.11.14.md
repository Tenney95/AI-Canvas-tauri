## 发布门禁

本版涉及原生权限、网络传输、项目持久化和 Windows 打包脚本，按全量源码门禁准备。应用数据库沿用 v27，旧项目不会自动迁移。当前安装包为 Windows x64 标准版和 Legacy，以及临时签名的 macOS Apple Silicon 版。Windows Legacy 不含本地 ONNX 和自动更新。Linux 安装包暂停。[打包与发版流程](../打包与发版流程.md)

- 版本号、README 徽章、官网说明书和 Release 资料一同提交。`master` 与 `v0.11.14` 同次原子推送并绑定同一个发布提交。
- Release 只在同标签、同 SHA、同次尝试的 `Frontend quality`、`Rust check`、`Full source quality` 及前端产物通过验证后启动平台构建。
- Windows、macOS 和 Legacy 成功后公开安装包、签名和自动更新清单。实际状态见 [源码 CI](https://github.com/Tenney95/AI-Canvas-tauri/actions/workflows/ci.yml) · [发布工作流](https://github.com/Tenney95/AI-Canvas-tauri/actions/workflows/release.yml) · [目标 Release](https://github.com/Tenney95/AI-Canvas-tauri/releases/tag/v0.11.14)

## Tauri 桌面待验收

1. 在「设置 → API Key」添加具备权限和额度的 MAGI-2 连接。先预览协议，再用视频节点生成短视频。按渠道检查首尾帧、混合参考和本地上传。暂停或切换项目后回到节点续查，核对仍使用原任务和原连接。更换 Key 后续查应暂停，恢复原 Key 后可继续。[MAGI-2 接入说明](./2026-11-26-magi-2-video-integration.md)
2. 安装并启用「UI 切图再生」插件，在图片节点打开工作台，编辑选区、恢复工作稿、导出 PNG 或 ZIP。核对最小化后能恢复同一窗口，重新生成只覆盖选中的操作范围。[UI 切图维护手册](./UI切图再生_20261124/05_切图实现与维护手册.md)
3. 在 Seedream 5.5 普通单图任务中分别核对 1K、1.5K 和 2K。用高分辨率本地图片检查全屏与对比，用远程图片检查现有传输限制。分平台检查安装、升级与首次启动。

若源码检查或打包失败，按本次 Actions 记录定位，公开前停止。应用回退前先备份项目和数据，原任务可用原厂商连接核对，UI 切图已有导出可继续读取。已公开标签与安装包保留原内容。
