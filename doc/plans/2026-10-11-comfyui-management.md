# ComfyUI 独立管理窗口实施计划

**Goal:** 在「启动 ComfyUI」和「打开 ComfyUI 页面」之间新增设置入口，以独立 Tauri 窗口管理本地内核版本、自定义节点和常用启动选项。

**Architecture:** 沿用按 `?view=` 懒加载的独立窗口入口、现有主题运行时与 UI Kit。ComfyUI 安装选择由主窗口原生对话框写入用途专属的私有持久授权，普通配置只保留路径显示镜像；Rust 以该授权复核启动及管理会话，负责固定 Git 操作与白名单启动选项。

**Tech Stack:** React、TypeScript、Tauri 2、Rust、系统 Git；不新增 IndexedDB object store。

## 实施顺序与源码入口

1. 原生安装授权、识别和启动设置：`src-tauri/src/media/comfyui/installation.rs`、`mod.rs`、`launch_settings.rs`；前端领域类型为 `src/types/comfyLaunch.ts`。目录通过 `select_comfyui_installation` / `get_comfyui_installation` 选择及恢复，前端镜像由主窗口 Store Action 保存。保留固定回环监听；读取实际安装的 CLI 参数声明，未知选项失败关闭。
2. 版本和节点管理：前端 `src/types/comfyManagement.ts`、`src/services/comfyManagementService.ts` 对接 `src-tauri/src/media/comfyui/management.rs` 的固定 command。所有路径在原生复核，不开放任意 `argv`、工作目录、Python 脚本或下载地址。
3. 窗口与会话协议：`src/services/comfyManagementService.ts`、`src/RootView.tsx`、`src/main.tsx` 与 `src/components/settings/ComfyUISettings.tsx` 的中间入口。独立窗口不初始化主应用，不加载凭据或全量配置，不自行保存主窗口配置。
4. 界面为 `src/components/comfyui/ComfyManagementWindow.tsx`、`ComfyVersionList.tsx`、`ComfyLaunchSettings.tsx`，使用 `src/styles/ui-kit.css` 的控件、表格与卡片。启动配置桥接为 `src/services/comfyLaunchSettingsService.ts`；专用权限为 `src-tauri/capabilities/comfyui-settings.json` 及对应 command 声明。
5. 收尾同步本计划和模块文档，保留未运行检查与真实桌面验收缺口。

运行控制台入口为 `ComfyRuntimeConsole.tsx`、`useComfyRuntime.ts`、`comfyRuntimeService.ts` 与原生 `runtime_console.rs`。主设置页沿用同一个原生启动核心；主窗口通过 `comfyRuntimeHostSync.ts` 复核原生状态后同步服务地址。

## 数据与执行边界

- 只管理用户已选择的本地安装；远程服务地址继续用于工作流与显存操作，不据此执行远程文件或进程操作。
- 安装授权保存在 `{appLocalData}/comfyui-native-private/installation.json`，只由本地主窗口原生选择器写入；getter 只恢复原生已提交记录，不接收 Renderer 路径。普通 `config.comfyUIPath` 仅作显示镜像，不能成为目录授权。启动和管理调用按持久记录重新校验真实安装根、固定入口及深层子项；不向公共 fs/asset scope 追加授权，普通插件不会因易失的一层 scope 而被误跳过。
- 安装授权私有目录及真实路径由 `installation::privacy_plugin` 隔离：插件紧随 fs 插件注册，在 `Builder::build` 的插件初始化阶段拒绝 fs/asset 访问，早于各平台配置窗口及 Renderer 创建；初始隔离失败则应用启动失败，不能先启动未隔离的 Renderer。每次记录读写再次要求隔离成功，通用 `path_policy` 拒绝该目录及递归访问其祖先。授权记录不进入项目、IndexedDB、日志或管理窗口快照；记录有 schema/体积限制，存储与安装目录链、源码和记录文件拒绝链接/Windows reparse。主记录损坏时失败关闭；主记录缺失只可恢复已提交备份，未完成的临时文件永不成为授权。
- 旧配置尚无原生记录时，只把路径作为待校验候选：本轮已有合法 fs 授权可登记持久安装授权，否则通过一次原生信任确认记住现有安装，无需重新选址。取消不保存；已有原生记录只允许匹配同一真实安装根，不能随 Renderer 镜像变化自动改址。更换需先关闭管理窗口再走原生选择器，原生保存成功才回传选择；取消或保存失败保留此前已提交授权。
- 主设置页挂载、启动及打开管理窗口时读取原生选择，并经 Store Action 同步配置镜像；迟到的旧恢复结果不能覆盖新选择。若镜像保存失败，原生已提交选择仍是权威，后续 getter 可重新同步。安装盘离线、目录移动、链接替换或记录损坏时明确报错，不静默扩大权限或改用镜像；恢复盘符或重新选择有效安装后再使用。
- `find_main_py` 在候选内部先过滤安装根外目录，再查找固定 `main.py` 入口，保留根内 `resources` 等布局。只有固定启动器的 Windows 安装可在默认启动设置下兜底；源码/API 模式与版本管理仍需有效根内源码。Comfy Desktop 的源码位于所选 Electron 目录同级时，应选择包含源码的基目录，不自动访问同级目录。
- 内核及节点版本来自本地 Git，网络刷新只更新远端引用。稳定版页展示标签，开发版展示提交，分支页展示本地/远端分支；非 Git 安装可展示其目录和状态，不能伪造分支、提交或版本切换。更新只快进当前分支；独立提交/标签版本需先切换分支。一键更新按内核及启用的 Git 插件顺序执行，失败即停止并保留已完成项。
- 切换与更新拒绝已跟踪文件的本地修改；整合包的 Python、Git、启动器等未跟踪目录不被误判为脏内核。切换与快进更新使用 `--no-overwrite-ignore`，不使用强制覆盖、清理或硬重置；目标版本与未跟踪/忽略文件发生路径冲突时由 Git 拒绝。下载、更新、重命名和移除必须限制在真实安装目录及允许的自定义节点子目录，拒绝链接、私有目录和越界目标。
- 官方目录及手动安装只支持 GitHub、GitLab、Gitee 和极狐的无凭据 HTTPS 仓库主页；不支持的 `copy`、多文件或其他来源条目不进入可安装列表。自定义节点属于外部 Python 代码，目录收录不证明安全或兼容。安装先暂存、成功后以 `.disabled` 停用目录登记；`requirements.txt` 依赖需单独通过原生信任确认安装，不执行 `install.py`。Git 下载成功不代表节点可执行验收通过。
- 卸载移动到当前安装 `custom_nodes/.ai-canvas-removed.disabled`，支持恢复，恢复后保持停用；不永久删除节点。恢复目录同样使用 `.disabled` 后缀，避免被 ComfyUI 加载。停用/启用使用既有 `.disabled` 目录语义。
- 常用启动设置保存到原生固定 `comfyui-launch.json`，只包含有限枚举和端口，不接收自由文本参数，不放松现有 CORS、调用方或路径授权边界。新保存端口范围为 1024–65535；启动时读取实际源码声明，不支持的选项失败关闭。通过主设置页启动本地 ComfyUI 后，主窗口 Store Action 同步默认服务地址到相应回环端口；额外服务器不受影响。
- 当前运行的 ComfyUI 不因保存设置自动停止或重启；版本/节点写入检查默认、配置及本轮实际启动端口上的服务状态，仍需用户先停止该安装的所有运行实例。安装授权跨应用重启保留，管理会话仍是内存状态；关闭管理窗口撤销会话并回收该会话的 Git/pip 进程树，不撤销已提交安装选择。
- 窗口权限单独声明必要 command，不能直接授予所有敏感原生命令；配置事件不得携带 API Key、MCP 令牌、厂商配置或完整本地文件正文。
- 安装/插件展示快照保留在 Rust 内存，与关窗即撤销的管理会话分开，按安装根、源码根和 Git 程序绑定；只保留一个安装与最近八个仓库的版本列表。重新打开同一安装优先复用缓存，仍重新校验窗口来源和真实安装授权，并使用当前会话的外观/语言。点击「刷新列表」强制扫描本地信息，「刷新远端版本」强制更新对应版本列表；缓存不落盘，应用重启后的首次打开仍需扫描。外部启动器或命令行修改后手动刷新。
- 管理写入在执行前清空展示缓存，包括失败或部分完成的操作；更换安装在原生授权保存成功后清空，取消选择保留原数据。缓存只用于展示和目录条目已安装提示，Git 切换/更新及插件修改始终重新校验实际路径、状态与目标版本，不以缓存放行操作。插件目录读取复用展示快照，避免额外重复扫描所有 Git 仓库。
- 主设置页和管理页均可启动当前已授权安装。固定 Python 入口使用隐藏子进程，分别读取 stdout/stderr，强制 Python UTF-8、非缓冲输出。管理页只接收运行 ID、状态和普通文本行，不提供 shell 输入或任意启动参数；输出移除终端控制序列、遮蔽凭据行并将安装/用户目录前缀相对化，仅在原生及当前视图内存保留，最多最近 2000 行 / 1 MiB，不写磁盘、IndexedDB、通用日志或聊天元数据。标准错误流不直接判为失败，退出状态与警告分别展示。
- 控制台按运行 ID 和序号读取有界分页，支持自动跟随、手动滚动暂停和清空当前显示。切换管理分类、关闭后重开窗口仍可读取当前安装的最近输出；切换安装不能读取旧安装输出。管理窗口只可停止运行 ID 与当前安装匹配的自有进程树，需前端显式确认，不接受 PID。关闭管理窗口不停止服务，退出整个应用停止其直接托管的进程树；外部服务和启动器不受停止命令控制。
- 重复启动复用自有活动进程并返回其实际端口；配置端口已被外部服务占用时不认领进程、不虚构输出。固定 bat/GUI 启动器兜底明确标为外部运行、无法捕获输出。启动早期尚未监听端口时同样阻止版本/插件/模型写入。只有原生确认自有启动状态的端口通知才由主窗口 Store Action 保存到默认服务地址，额外服务器不变；管理窗口不加载主 Store 或全量配置。
- 管理分类及版本类型复用共享 `Tabs` 横向页签；安装异常提示默认收起，展开后在限高区域读取具体原因，首次加载不额外显示刷新成功条。停服提醒只保留一处；跳过表示该次扫描未收录插件，不执行停用、卸载或删除。
- 已装/安装插件页的列表占据剩余高度，使用独立双轴 `ui-scroll` 和可键盘聚焦的 region；表头吸顶。搜索位于页签右侧，安装目录刷新与搜索同组，窄窗可换行；「加载更多」在列表末尾随内容滚动，扩展 URL 表单固定在底部。内核和常用设置保留页面整体滚动。主设置页「启动 / 设置 / 打开页面」使用同一 UI Kit 尺寸、三等列布局；以上已实现，待用户桌面验证。
- 外部 ComfyUI 页面 capability 显式设置 `local: false` 且保持空 permissions，以未授权的默认拒绝隔离原生命令；不附加管理命令的显式 deny。当前使用的 Tauri ACL 拒绝判断以 `Option<bool>::is_some()` 处理来源匹配结果，任意 deny 记录都会拒绝该命令，`local: false` 单独不能修复。已移除该组 deny 声明；主窗口与管理窗口仍使用原有最小 allow、原生调用方及目录校验，待用户重启原生应用验证。

## 官方契约依据

- [ComfyUI CLI 参数源码](https://github.com/Comfy-Org/ComfyUI/blob/master/comfy/cli_args.py)：支持端口、显存、精度、注意力、预览与智能内存选项；具体可用项以用户安装版本的声明为准。裸 `--listen` 会扩展监听范围，应用继续显式使用 `127.0.0.1`。较新版本的动态显存机制会影响 `--lowvram` 的效果。
- [ComfyUI-Manager Git 节点目录](https://github.com/Comfy-Org/ComfyUI-Manager/blob/main/custom-node-list.json)：顶层 `custom_nodes`，仓库安装取 `files`；`reference` 可与安装仓库不同。只处理受支持的 Git 安装条目，描述按普通文本展示，不执行其中的标记或代码。
- [Manager API 源码](https://github.com/Comfy-Org/ComfyUI-Manager/blob/main/glob/manager_server.py)与 [OpenAPI](https://github.com/Comfy-Org/ComfyUI-Manager/blob/main/openapi.yaml)：节点管理使用操作队列；入队成功与执行完成必须区分。本批采用本地 Git 管理时不要求安装 Manager。
- [官方节点发布说明](https://github.com/Comfy-Org/docs/blob/main/custom-nodes/backend/manager.mdx)：Manager 安装可能涉及 `requirements.txt` 和 `install.py`；仅下载仓库不保证依赖已满足。[目录说明](https://github.com/Comfy-Org/ComfyUI-Manager/blob/main/node_db/README.md)记录了向 CNR 的迁移，本批不宣称完整覆盖 Registry 管理。
- [Git checkout](https://git-scm.com/docs/git-checkout)与 [Git merge](https://git-scm.com/docs/git-merge) 手册都支持 `--no-overwrite-ignore`。[快进源码](https://github.com/git/git/blob/master/merge.c)设置忽略文件保护并走 [unpack-trees](https://github.com/git/git/blob/master/unpack-trees.c) 的未跟踪文件冲突拒绝，不依赖强制覆盖。

## 用户验收

前置条件：使用 Tauri 桌面端，选择一个可备份、具有 Git 和对应 Python 环境的本地 ComfyUI 安装；版本/节点写入前先结束生成任务并停止该 ComfyUI 进程。

1. 在设置 → ComfyUI 点击中间设置按钮。预期打开独立窗口，能够拖动、最小化和关闭；重复点击聚焦已有窗口。主设置页三个按钮在普通、加载及禁用状态均等宽同高。管理分类与稳定版/开发版/分支横排，方向键可切换，缩窄窗口时页签横向滚动；首次载入不堆叠成功与重复停服提示。分别在主应用暗色/浅色下重开管理窗口，核对表格、吸顶表头、输入框和按钮可读；内核/常用设置整体滚动，窗口不加载主应用画布。
2. 内核页刷新信息，核对真实远端、分支、提交、标签和开发提交。切换一个兼容版本后重新读取；修改已跟踪源码时应拒绝，非 Git 安装禁用版本写入。整合包附带未跟踪 Python/Git/启动器目录时允许正常管理且保留这些目录；在测试副本构造与目标版本同名的未跟踪/忽略文件，切换和更新应拒绝覆盖并保留文件。
3. 已装插件页搜索框位于页签右侧。鼠标列表内滚轮、触控板和聚焦列表 region 后按 PageDown 均应滚动列表，页签/搜索与吸顶表头保持可见；窄窗长分支/URL 场景可横向滚动到最右侧操作，搜索无结果显示空行提示。选择含深层 `custom_nodes` 和内置 Git 的整合包根，普通目录应正常收录并识别 Git 信息。在测试副本构造同名启用/停用目录或链接时应拒绝管理，提示显示具体原因；大量提示默认收起，展开后可滚动且不挤走表格。启停、切换版本/更新后重新启动并核对节点加载及提交变化；卸载后列表保留「已卸载」项，恢复后处于停用。一键更新遇到脏仓库、独立版本或网络失败应停止，并准确显示已完成数量。
4. 安装页的搜索/刷新目录在页签右侧；同样核对鼠标、触控板、region PageDown 和横向滚动。无结果有明确提示，「加载更多」位于列表滚动内容底部并能追加结果；列表滚动时 URL 安装表单固定可见。安装一个已确认来源的 Git 节点或手动仓库，下载成功后应停用。安装依赖需原生信任确认，取消不执行，仍不运行 `install.py`。重复安装、无效/含凭据/不支持来源地址及断网应给出明确错误，失败暂存不成为有效安装。断网时本地状态仍可读取，远端刷新/目录读取不能伪造成功。
5. 常用设置调整端口与一个支持的启动选项，保存、关窗并重开；停止后重新启动 ComfyUI，核对实际监听端口及参数。现有进程不因保存设置立即重启；无效端口、旧版本不支持参数、启动配置损坏均应提示处理方式。
6. 回归默认/额外服务器、工作流绑定、打开 ComfyUI 页面、工作流编辑保存，以及显存读取/释放。切换本地端口后确认默认连接与入口使用已保存地址；额外服务器不被误改。
7. 在主设置页原生选择有效安装，保存后连续退出并重启应用两次。每次直接打开管理窗口或启动本地 ComfyUI，预期恢复同一原生安装选择，无需重新选择或重复授权。旧配置只有路径镜像时，首次使用可原生确认一次已有目录；取消不能创建授权，确认后的后续两次重启不再询问。
8. 打开管理窗口时点击「更换」，应提示先关窗。关窗后选择另一个有效安装，原生记录与主窗口镜像应更新；在目录选择器取消，或取消旧配置首次确认，原选择/状态保持。测试环境模拟原生授权存储不可写，选择应失败并保留旧记录；仅普通配置镜像保存失败时，后续 getter/重启仍应恢复已提交原生选择，不能退回旧镜像授权。
9. 在测试安装副本模拟盘符离线、目录移动、安装根/源码/记录被链接替换，以及损坏/超限授权记录。启动和管理应拒绝并给出准确错误，不自动跟随链接、旧镜像或未提交临时文件。盘符恢复且安装结构未变化后可恢复使用；损坏记录通过重新选择有效安装修复。主记录缺失且存在已提交备份时可恢复；确认通用文件/asset 访问授权私有目录及递归读其祖先仍被拒绝。
10. 对具有根内 `resources` 源码的安装核对识别，根外同级候选不能遮蔽后续根内入口。Comfy Desktop 若只选 Electron 目录，默认固定启动器可兜底，但源码管理不得越界读取同级目录；改选包含源码的基目录后应正常识别。原生隐私插件初始化隔离失败时，应用应在创建配置窗口/Renderer 前终止启动。
11. 使用有配套 Python 的测试安装，在管理窗口点右上角「启动 ComfyUI」，应自动切到运行控制台，实时显示插件导入、服务启动和后续输出；状态随监听、正常退出或失败更新。重复点击及与主窗口同时启动不得产生重复进程。主窗口启动等待期间点击「设置」同样可读输出；Python 提前退出应及时停止等待并提示查看控制台。改为非默认端口后分别从两个入口启动，核对主窗口默认服务地址同步为实际端口；先启动再改保存端口，活动实例不得被错误归为新端口。
12. 在输出区向上滚动应暂停跟随；点自动跟随可回到最新输出。长行、连续大量输出、中文、stderr 中普通 INFO、WARNING 和真实异常应可读，超限提示较早内容已省略；清空只影响当前显示。关窗后重开可读取当前安装最近输出，切换安装不能读到旧输出。暗浅主题、窄窗口和键盘滚动均需验收。
13. 在控制台点停止服务，取消确认应继续运行；确认后仅结束当前运行 ID 对应的自有服务及子进程，显示退出状态且可再次启动。自有进程刚启动尚未监听时，版本/插件/去重替换仍拒绝写入。关闭管理窗口应继续服务，退出整个应用应回收自有进程树。外部端口占用或固定启动器兜底应明确提示无法捕获输出，停止按钮不可用；从外部启动的服务必须由原启动器停止。
14. 同一次 Tauri 应用运行中首次打开管理窗，等安装信息和内核版本读完，关闭后连续重开两次：应直接复用已有信息，无逐个插件的长时间重新读取；在暗浅主题或语言变化后重开，外观应沿用当前主窗口。手动刷新列表后应读取真实本地信息，刷新远端版本应执行网络读取。启停/切换/安装后重开应显示新状态；模拟执行部分修改后失败，重开也须重新读取。切换另一个安装不能显示旧安装插件；取消更换不清空原缓存。重启整个应用后首次打开重新读取符合预期。使用外部 Git 修改后先手动刷新，随后写入仍须受真实脏状态及路径校验保护。
