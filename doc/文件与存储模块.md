# 文件与存储

负责项目与配置持久化、本地媒体引用、项目导入导出、资产索引、回收站和存储健康。凭据的原生保护边界见[桌面运行时与安全](./桌面运行时与安全模块.md)。

## 主要入口

| 入口 | 职责 |
|---|---|
| [fileService.ts](../src/services/fileService.ts) / [fs](../src/services/fs/) | 统一前端文件能力与资产管理 |
| [mediaUrl.ts](../src/utils/mediaUrl.ts) | 媒体 URL 来源分类与本地 asset/file 路径解码 |
| [indexedDbService.ts](../src/services/indexedDbService.ts) / [schema.ts](../src/services/indexedDb/schema.ts) | 数据库 CRUD 与 schema 版本权威 |
| [projectTransferService.ts](../src/services/projectTransferService.ts) | 项目整体导入导出 |
| [storageHealth.ts](../src/services/fs/storageHealth.ts) / [原生 files](../src-tauri/src/files/) | 存储检查与原生传输/归档能力 |

## 关键边界

- 数据库升级必须兼容已有项目；schema 版本以源码为准，不在模块说明中固定副本。
- 持久化媒体引用需要考虑重启、项目移动和归档恢复，不能仅依赖页面 Blob 或临时签名 URL。
- `asset://localhost` 与 `http(s)://asset.localhost` 按真实主机名识别为本地素材；网络地址的路径或查询参数中出现相同文字不改变来源。模型/工作流输入先上传本地素材，项目保存对 asset/file 复用授权流式复制，data/blob 继续执行内存大小限制。来源分类不代替网络访问或本地路径权限校验。
- 资源 grant、控制器、窗口句柄和敏感文件正文不进入普通项目持久化；凭据只通过专用服务进入原生凭据存储。
- 导入、归档和递归文件操作必须保留路径校验与私有目录拒绝规则；长传输支持取消与进度。
