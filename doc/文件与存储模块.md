# 文件与存储

负责项目与配置持久化、本地媒体引用、项目导入导出、资产索引、回收站和存储健康。凭据的原生保护边界见[桌面运行时与安全](./桌面运行时与安全模块.md)。

用户操作见[资产库与节点卡片](../site/manual.html#asset-sidebar)、[资源视频预览](../site/manual.html#asset-video-preview)和[设置保存与恢复](../site/manual.html#settings-save)。结构化数据库当前新增的 `projectSummaries` 提供轻量项目列表；完整项目仍在 `projects`，旧库通过游标回填摘要，详情和版本以 `schema.ts` 为准。

节点“复制图像”由 `clipboardService.ts` 优先按原格式写入 WebView 位图剪贴板；缺少接口、格式不支持或实际写入返回 `NotSupportedError` 时，Tauri 桌面端降级为既有 `copy_files_to_clipboard` 系统文件剪贴板，不转码。优先复用素材 URL 的真实路径或节点本地原文件；无本地文件时经 `fileService.ts` 保存到操作开始时捕获的项目，再复制文件，保存副本保留在项目素材目录，不写回节点。原生路径授权保持不变；Web 环境、权限拒绝、读取或保存失败不误报成功。文件粘贴是否被图片编辑器或聊天工具接收由目标应用决定。回归入口为 `tests/services/clipboardService.test.ts`；本次未运行测试，待用户在 Win10 桌面端验收 JPEG 文件降级、PNG 位图、远程/内嵌图片保存及失败提示。

## 关键边界

- 图片预览支持编辑提示词、参考图与标签，也可选择文本视觉模型反推提示词和标签。反推复用 `ai/reversePrompt.ts`，校验结构化结果后通过既有保存 Action 原子替换提示词与标签，不增量合并原标签，不创建画布节点；成功后自动保存并退出编辑，保留参考图编辑，之后仍可手动修改。保存失败或取消保留生成草稿，用户可重试保存而不重新调用模型。关闭或切换图片会取消调用，过期结果不回填；保存比较图片版本、内容与调用前的标签基线。预览、保存 Action 与反推服务 3 个定向测试文件共 29 项通过，包含真实 IndexedDB 的原子保存及标签冲突保护；`assetImageMetadata.test.ts` 另有 2 项原有断言未匹配事务选项参数，相关服务与测试未改动。未进行真实模型调用或桌面验收。
- 资产库工具栏「批量反推」冻结当前筛选结果及项目归属，包含尚未分页显示的可用本地图片；只读识别已保存提示词和生成历史，已有提示词的图片显示标记、默认不选中，仍可手动勾选替换。列表复用 UI Kit 紧凑横排，统一模型，默认 3 路并发、可选 4/5。成功项在同一事务中完整替换提示词和标签并保留参考图；比较图片版本、标签基线与内容指纹，冲突或失败项不覆盖旧信息。停止/关闭/切换资源范围取消未完成调用，已提交项保留；失败与停止项仅手动重试，运行期队列不持久化。实现和用户验收要点见[专项计划](./plans/2026-10-07-asset-image-batch-reverse.md)。按用户要求未运行自动化或真实接口测试。
- 图片预览标题提供磁盘重命名：保留扩展名，检查名称与目标冲突，只处理已登记目录内的普通图片。沿用资产身份及引用迁移日志，更新列表、当前画布与持久化引用；对应节点标题同步为新文件名，覆盖生成图、源图片和自定义标题，撤销历史与剪贴板引用也同步，普通移动不改节点标题。提示词、标签和参考图继续关联原资产；引用提交失败时尝试恢复原文件名，无法恢复则明确报告部分完成。编辑草稿须先保存或取消再改名；旧版已经出现的标题不一致不会回溯修复，需再次实际改名触发同步。相关引用迁移、移动、文件改名、分组与项目共 87 项回归通过；尚未进行桌面实际改名验收。

- 当前 IndexedDB schema 为 22，真值为 `schema.ts` 的 `DB_VERSION`。`appearanceThemes` 保存完整自定义外观预设；视频批次存于 `metadata` 的 `video-batches:<projectId>` 项，保留最近 30 批，不新增平行数据库。运行期控制器、文件 grant 和临时窗口状态不持久化。
- 方舟图片/视频节点的本地用量使用 Rust 独立 SQLite 账本，支持目录配置、迁移、分页查询及默认脱敏的 Excel 导出，不属于项目 IndexedDB 或官方云端账单；范围和清理边界见[账本计划](./plans/2026-09-26-火山方舟节点计费系统设计.md)。
- AI 镜头预演场景以项目相对路径、SHA-256 和字节数引用不可变 JSON 文件，复用项目复制与归档往返；不把完整场景作为聊天摘要保存，读取和派生写回守卫见[导演模块](./导演台与Blender模块.md)。

- 存储健康单独列出当前 ONNX 模型目录中已登记的三个模型和 SenseVoice 词表，按实际文件大小显示占用。逐文件删除需在界面二次确认；原生命令只接受固定登记文件名、受信本地窗口调用和普通文件，删除后相关功能按既有流程重新下载。该占用不计入项目文件扫描总量。

- 画布无修饰键 `Tab` 打开/收起左侧资产库，`Esc` 或收起按钮关闭；设置的快捷键页列出“资产库 — Tab”，名称复用现有多语言词条。快捷面板复用 `AssetsPanel.tsx` 的项目文件、全局资产、创作资产、搜索筛选和拖拽；每次从画布打开默认跟随当前项目。原资产库入口保留大弹窗，左侧文件固定三列，范围与搜索同排，不改写大弹窗列数。
- 抽屉沿用右侧助手面板的平滑弹簧节奏，镜像为从左向右整幅滑入、向左退出；关闭时保留上次展示模式的动效宿主，退场完成后才卸载。此交互动效在性能模式下保留，系统减少动态效果时只淡入淡出，大弹窗继续使用原有动效设置。
- 独立资源搜索的来源下拉框复用资产库的统一 `Select` 与样式，保留项目、外部文件夹和全局资产的来源分组及筛选逻辑。
- 全局资产以左侧文件夹导航浏览：全部资产汇总去重文件，导入文件仅显示全局 `file` 目录，外部目录保留真实父子层级和空目录。选中目录只显示本层文件，搜索、分类、标签、视频预览与拖拽作用于当前目录；目录切换清除类型/标签筛选，保留搜索词。窄抽屉使用可折叠目录区，文件仍固定三列。
- `fs/assetLibrary.ts` 的 `listExternalFolderContents()` 一次扫描返回运行时目录和文件；目录状态区分可读、不可访问与未扫描，单根默认最多 3000 个文件、3000 个目录、8 层深度，达到上限明确提示，不跟随符号链接。原 `listExternalFolderFiles()` 继续为独立搜索等入口提供递归文件列表。移除根目录只取消配置引用，不移动或删除本地内容；目录条目不进入 IndexedDB 或新增授权。
- 导入文件与外部目录支持右键新建真实子文件夹、复制整个文件夹到系统剪贴板，以及在选中目录粘贴。导入目录同样保留子目录层级；根视图仅展示本层文件，全部资产及独立搜索包含子目录文件。粘贴每次读取当前系统文件剪贴板，源目录须已授权（外部来源需先添加到资产库），不会用文本路径或应用缓存冒充系统复制。
- 目录粘贴由 `files/transfer.rs` 复用流式传输执行，原生端复核主窗口、源/目标授权及私有目录保护，拒绝链接、特殊文件和粘贴到自身后代。预扫描最多 100000 个条目、128 层；同名通过独占创建生成副本，禁止覆盖。支持进度及取消；失败或取消保留已复制内容并刷新列表，不删除源文件。Windows 使用 CF_HDROP，macOS/Linux 沿用系统剪贴板工具；Linux 依赖已有的 xclip 或 wl-clipboard 系统工具。
- 第四个页签“节点列表”浏览当前画布的全部节点类型（包括笔记和插件节点），计数、名称和列表随画布更新，不受项目文件页签的跨项目范围影响。支持名称、类型及编号搜索与增量加载；只在节点页订阅节点标识和内容，移动位置不会触发列表内容重绘。“查看节点”复用历史记录的 `canvas-focus-node` 事件及回弹效果；抽屉保持打开，大弹窗关闭后定位，迟到请求在项目变化或节点已删除时不再发送。
- 节点列表使用 [CanvasNodeCardContent.tsx](../src/components/assets/CanvasNodeCardContent.tsx) 展示大卡片：图片复用画布缩略图缓存，视频展示已有封面或共享封面缓存，文本显示摘要，音频按需播放。输入/输出端口叠放在预览内，不增加底部行高；音频端口避让播放器。媒体按视口加载，旧请求与预览租约在切换、离屏和卸载后释放；小图无需缩略图时沿用画布的原图回退行为。
- 左侧节点卡片的输入/输出端口可拖到画布节点的对应端口或主体左右半区；[assetNodeConnection.ts](../src/utils/assetNodeConnection.ts) 复用实际端口及 Store `onConnect`，创建正常画布边，进入原有项目保存、撤销与重做流程。拖动预览不写 Store；松开时重新校验项目、节点与启用端口，拒绝重复、自连接和同方向连接。Esc、失焦、指针取消、面板卸载或源端口失效时取消；空白处不新增节点。画布笔记不展示虚构端口，插件使用启用清单的真实端口 ID 并要求精确命中目标端口；大弹窗仅展示内容和查看按钮。
- 资产快捷键不抢占输入框、可编辑内容、交互控件和其他弹窗的 Tab 焦点导航。左侧面板避让侧栏且不遮挡其余画布；异步文件列表在关闭、切换项目或发起新读取后忽略旧结果。
- 资源视频统一使用 [ResourceVideoPreview.tsx](../src/components/shared/ResourceVideoPreview.tsx) 与 [useResourceVideoPreview.ts](../src/hooks/useResourceVideoPreview.ts)：只有 Tab 资产抽屉和独立资源搜索指定 `inline`，保持面板内浮动播放；资产大窗、项目分集资产、节点列表大窗、角色动作素材与输出历史默认打开应用全屏信息面板。原卡片和列表位置保留，同一窗口只选一项，相同资产 ID 的重复卡片也只由实际点击的实例打开播放器。关闭或切换资源范围停止并释放播放器；浮动播放结束自动收起，全屏播放结束保留信息面板。
- 全屏视频由按需加载的 [AssetVideoPreview.tsx](../src/components/assets/AssetVideoPreview.tsx) 展示，与图片共用布局和主题；左侧等比居中视频，底部提供进度、播放/暂停、倍速、静音和播放器全屏，右侧提供提示词复制及已有生成参数、真实尺寸/时长与文件信息。成功视频历史经 [assetVideoDetails.ts](../src/services/assetVideoDetails.ts) 按完整路径或原始媒体地址查询，项目资源限定所属项目/分集，历史卡片直接使用所选记录，拒绝同名推断和过期结果。没有记录显示暂无生成信息，读取失败可重试；视频信息本阶段只读，不新增元数据结构或参考素材存储。细节、验证及回滚见[视频全屏预览计划](./plans/2026-10-06-资源视频全屏预览.md)。
- 视频封面沿用画布串行、可取消的共享缓存与租约，只对接近视口的资源取帧；本地地址通过已有文件服务转换，失败时可使用条目已有源 URL，不修改媒体文件、资产索引或文件授权。封面不可生成时保留显式播放入口，加载失败可重试；播放器设置与清理媒体源保持对称，兼容开发模式的 effect 重放。
- 项目文件与全局资产中的图片点击后铺满应用窗口，左侧复用图片缩放和平移，右侧展示提示词、保留的原始生成参数和真实文件信息。上一张/下一张及方向键作用于当前筛选后的全部图片；Esc 只关闭预览，保留目录、筛选和列表位置。项目、目录或面板展示模式变化时撤销预览，旧查询结果不得跨图片显示。
- 图片生成信息只读查询现有成功图像历史，按完整文件路径或媒体地址匹配，不按同名文件猜测。项目文件限定所属项目，全局资产可查跨项目记录；仅展示模型、供应商、生成时间和白名单参数，不投影任意参数对象或凭据。历史仍沿用每项目最多 16 条的保留策略；记录不存在显示暂无信息，读取失败可重试，两者不混淆。不解析或改写图片元数据，不新增数据库结构。
- 快捷指令等生成图片的历史缺失时，提示词读取按所属项目和完整媒体路径匹配唯一成功生成节点；当前项目用实时画布，其他项目只读持久化画布。节点改名后优先用其原输出地址找回同节点历史；历史已清理则展示节点当前提示词并注明来源，不伪造生成时间，不按文件名、缩略图或输入参考图匹配。此回退共用于详情、悬浮、复制与批量反推的已有提示词识别；不覆盖用户保存或主动清空的提示词。按用户要求未运行测试或真实桌面验收。
- 帧动画 Sprite Sheet 同样纳入图片来源查询。单次及批量生成保存实际提交的完整提示词（用户内容与动画默认约束），并记录拼接版本和处理参数；旧历史按已保存的动作、帧数与比例复用现有规则重建，注明并非原始完整文本。历史已清理时可按唯一生成节点的当前内容与原图宫格快照重建；缺失的旧处理参数使用当前默认规则，不能保证还原当时自定义设置。不覆盖用户已保存的编辑信息；按用户要求未运行测试或模型调用。
- 用户编辑的提示词与参考图关联独立存于 `metadata` 的 `asset-image:` 记录，经 Store Action、内容校验及 revision 事务提交，不改写原生成历史或标签。参考图复制至数据根目录的 `asset-image-references/`，只保存相对引用；原图删除不清理信息，同名替换不继承旧编辑记录，改名/移动须内容一致且归属明确。参考图缺失显示不可用，移除仅删关联；备份须包含数据库与托管副本。存储决策、旧路径历史的验证限制和回滚见[图片信息编辑计划](./plans/2026-10-06-资产图片信息编辑.md)。
- 悬浮播放在点击时记录实际缩略图矩形，按其在父面板中的位置向可用空间展开，收起沿相同路径反向回到该矩形。位移与缩放使用同一弹簧曲线，回弹后才淡出；裁剪层限制回弹仍在父面板内，收起开始即停止解码。切到其他视频时立即撤掉旧层，避免双层动画重叠；播放器局部保留动效，不被画布性能模式禁用，系统减少动态效果时仍仅淡入淡出。
- 数据库升级必须兼容已有项目；schema 版本以源码为准，不在模块说明中固定副本。
- 数据库打开失败必须释放失败缓存，允许后续读取重新连接；其他实例请求升级时主动关闭旧连接。升级被占用时明确拒绝本次读取，并释放随后才打开的连接。旧版本遇到更高 schema 必须拒绝，不删除数据库或绕过版本校验。
- 配置读取只有记录确实不存在才返回空值；数据库读取或凭据迁移失败必须向上抛错并阻止默认值保存。单个渠道凭据读取失败时保留引用和错误标记，普通设置仍可使用；重读失败只在凭据引用和版本均未变化时保留原内存 Key。旧模型连接转换在凭据迁移前执行，确认迁移成功后才清理旧明文并更新普通字段。仅需普通字段的独立窗口使用脱敏且不读取凭据的入口。
- 主窗口和独立素材窗口按实际修改字段保存。Store 捕获编辑快照、脱敏基线和修改序号，IndexedDB 在同一个事务内比较当前值并提交；不同字段合并，同字段冲突拒绝，数组视为一个字段。保存期间的新编辑重放到提交结果，旧回调不能清掉后续修改。保存失败始终拒绝并保留修改，设置面板仅在未加载、未保存、保存中、冲突、错误或凭据未读时显示提示条，正常已加载/已保存状态不常驻；按状态提供重试和重新加载；丢弃未保存修改的重新加载需用户确认。
- 普通字段保存不核对或回写无关 Key；只有显式变更 Key 才提交对应渠道凭据，旧格式迁移、引用恢复及已提交的删除清理另走对应流程。凭据版本只由持久化协议推进，表单重建渠道对象不能清掉引用或版本。桌面新旧连接凭据保存失败均拒绝配置提交；Web 环境凭据只能保留在当前会话。数据库与原生凭据仍不是跨介质原子事务，数据库失败不会回滚此前成功的凭据更新；显式重试可按原生同值结果收敛。
- 删除渠道先读取清理指纹，再在同一配置事务中提交连接删除及 `_pendingSecretCleanup`。原生清理只在数据库提交后执行，并按 SHA-256 指纹条件删除；失败保留不含明文的计划供重试或重新加载恢复，原生值已变化时作废旧清理意图。清理失败仍能读取普通配置，并提供重试状态；部分成功也推进 Store 基线，保证后续重新添加渠道能被正确识别为新修改。
- 配置保存、迁移和凭据删除共用队列，等待事务完成或中止，失败不阻断下一次操作。支持 Web Locks 时使用同源排他锁；锁失败直接拒绝，缺少该 API 时仅保证当前窗口操作顺序。普通字段补丁仍在数据库事务内检测冲突；旧版整份快照客户端及不同存储源不享有相同保证。
- 关闭主窗口时先收集窗口尺寸防抖任务和工具栏编辑草稿，再冻结设置修改并等待 Store 与共享队列。失败时可重试、取消退出或明确放弃；取消退出恢复编辑。圆环菜单仅在保存成功后提示并关闭；独立素材窗口只提交目录字段，失败保留目录选择，重试使用最新基线。
- 凭据、配置与工具栏读取区分缺失和失败，仅对明确的忙碌/中断最多尝试 3 次；失败的写入调用不自动重试，损坏、权限拒绝、高版本或未知错误也不自动重试。诊断只记录操作、白名单错误码和尝试次数，不保留原始错误、条目名、路径或凭据；原生现返回结构化分类，旧字符串仍按 unknown 处理。
- 工具栏加载失败保留旧布局并禁止保存，长按时可重试加载。按节点类型在同一个事务内比较编辑基线并局部更新，独立类型不互相覆盖，同类型冲突拒绝。失败及保存期间的新修改保留草稿；冲突后由用户确认重新加载该类型，退出重试不能无条件覆盖冲突。配置和布局关键写入请求 strict durability，仅在运行时明确不支持 options 时回退，真实权限/空间错误不得降级重试；不改变项目/媒体事务策略。
- 删除整组或删除最后一个组内节点时，将分组目录整体暂存至项目根 `.trash/<时间>-<随机标识>-<组名>`，不在组内创建回收站；目录内历史文件与旧嵌套回收站一并保留。单独删除组内媒体、导演 Scene bundle 也使用项目根回收站，整目录与子文件不会重复移动。
- 撤销先等待暂存完成，再恢复分组目录和单独暂存的文件；重做复用同一批量删除入口。恢复不覆盖后来创建的同名文件或目录；暂存失败保留原件，不降级至系统回收站。目录含组外存活节点、消息或受保护产物的引用时不整体回收，只处理独占文件；特殊目录、路径穿越和符号链接不扩大回收范围。
- 持久化媒体引用需要考虑重启、项目移动和归档恢复，不能仅依赖页面 Blob 或临时签名 URL。
- 项目根 `.thumbnail` 是可重建的画布图片缓存，Windows 设 Hidden，macOS/Linux 使用点目录；复用现有项目/分集共享目录映射。缓存不进入素材索引、孤儿/重复文件扫描或项目导出，分组/外部目录中的同名用户目录保持原语义。前端入口为 `fs/thumbnailCache.ts`，原生 `files/thumbnail_cache.rs` 复核主窗口与真实路径授权，缓存写入不触发资产变更通知。范围与验证见[大画布交互性能优化](./plans/2026-09-09-canvas-interaction-performance.md)。
- 帧动画节点和编辑页通过 `animationService.ts` 传入调用方项目目录，`media/sprite_processing.rs` 将去背景、切帧及对齐后的完整透明精灵图保存为 `.thumbnail/sprite-v1-*.png`，旁边的 JSON 保存源版本、PNG 摘要和帧布局信息。命中后只读取缓存，不重复处理原图；源文件大小/修改时间、处理参数或算法版本变化时失效，缓存缺失或损坏时重建。复用缩略图缓存的路径校验、隐藏目录与原子写入，写入失败仍可显示本次结果，原图和逐帧编辑数据保持独立；导出继续使用原图与当前处理参数。回归入口为 Rust `sprite_processing::tests`、`thumbnail_cache::tests` 和 `tests/services/animationService.test.ts`。
  验证：相关 129 项前端回归、26 项 Rust 回归、应用与测试类型检查、定向 ESLint 和 `cargo check` 通过；原生临时目录实测缓存命中跳过处理、迁移复用、源与参数失效、损坏重建和写入失败回退。真实项目在桌面重开后的完整验收尚未完成。
- `asset://localhost` 与 `http(s)://asset.localhost` 按真实主机名识别为本地素材；网络地址的路径或查询参数中出现相同文字不改变来源。模型/工作流输入先上传本地素材，项目保存对 asset/file 复用授权流式复制，data/blob 继续执行内存大小限制。来源分类不代替网络访问或本地路径权限校验。
- 资源 grant、控制器、窗口句柄和敏感文件正文不进入普通项目持久化；凭据只通过专用服务进入原生凭据存储。
- 导入、归档和递归文件操作必须保留路径校验与私有目录拒绝规则；长传输支持取消与进度。

### MCP 资源导入

- `file_import_media_to_canvas`：一次导入 1–20 个媒体，按输入顺序返回节点 ID。每项 `path` / `uploadId` 二选一，允许混合：path 复制已授权本地图片、视频、音频，uploadId 领取当前 MCP 对话已完成的图片。支持名称、单项坐标和默认网格排列；不修改源文件、不调用生成模型、不自动扩大目录权限。
- `file_media_upload`：MCP 客户端分块发送 PNG/JPEG/WebP 字节，无文件或单批总字节数业务上限。固定 256 KiB 块、末块余量，流式落盘并按 `sha256-chain-v1` 读回复核；文件头与 MIME/尺寸须匹配。绑定项目、对话、revision 和存储配置；空闲十分钟失效，可查询或取消。已完成 uploadId 在批量导入后消费一次，正文与路径不进入 MCP 审计。协议、故障残留和验证见[图片上传导入计划](./plans/2026-09-11-mcp图片上传导入.md)。
- `canvas_paste_external`：读取系统图片或纯文本。Windows 桌面端使用仅主窗口可调用的 `read_canvas_clipboard`，支持 PNG / DIB / DIBV5 和 UTF-16 文本；其他平台保留 Web Clipboard 读取并报告权限失败。不跟随 HTML、URL 或文件路径，不使用应用内部节点剪贴板。
- `ui_capture_to_canvas`：把主窗口真实可见界面截图直接持久化为图片节点，始终启用敏感元素过滤；截图字节不进入工具结果。
- 三个入口共用 [资源导入服务](../src/services/canvasResourceImportService.ts) 和既有文件服务、Store 批量写入。整批准备成功后提交一次历史；项目、revision、画布状态变化或取消时不回填。已复制但未提交的媒体可能留在项目素材目录中，不自动删除。
- 原生剪贴板限制输入 32 MiB、文本 100000 UTF-16 单元、图像边长 8192 和解码字节 128 MiB；结果只返回节点 ID、类型、坐标和 revision，不记录路径、剪贴板正文或图像 Base64。
