# 模型与生成

负责模型目录、厂商协议、图片/视频/音频生成及工作流适配。生成成功、取消、产物保存是需要分别处理的状态。

## 共用模型选择菜单

[ModelPicker.tsx](../src/components/shared/ModelPicker.tsx) 提供 UI Kit 的厂商分组菜单 `ModelMenu` 与表单选择入口 `ModelPicker`。菜单共用厂商徽标、名称/说明、折叠、选中和禁用样式；UI Kit「下拉选择」展示真实交互。组件只接收展示分组、条目和回调，不读取 Store、厂商配置或凭据。普通参数仍使用 `Select`。

节点 [ModelSelector.tsx](../src/components/nodes/shared/ModelSelector.tsx) 保留目录筛选、厂商可用性、模型偏好、工作流服务检测及编辑入口，菜单内容改用 `ModelMenu`；模型与工作流的执行身份不变。插件目录由 [pluginModelCatalog.ts](../src/services/plugins/pluginModelCatalog.ts) 附带可选 `group` 白名单，包含名称、说明、徽标文字和主题色类别，供插件复用同一展示。CCC 仍通过模型名称后缀区分连接分组，不改通用模型路由；ComfyUI 仍按既有工作流过滤规则提供。

## 新建图片与视频节点参数偏好

图片记住画质与比例；视频记住分辨率、比例、时长、帧率、帧数和有声开关。图片、视频各保留一份最近参数，绑定完整模型值和 Provider，与现有模型选择偏好一样保存在本地 `localStorage`，重启后可继续使用。只缓存声明字段的字符串、有限数值和布尔值，保留 `false` 与自动时长，不保存提示词、素材、摄影参数或凭据。

`store.nodes.ts` 在当前节点的参数编辑 Action 后更新偏好，在单节点插入入口为新建空白生成节点应用同模型缓存；工具栏入口未提供模型时补齐现有模型偏好，右键、快捷键及拖线新建共用参数恢复。项目明确配置的默认参数优先，图片同步调整节点比例。源素材、已有内容、带提示词或编号的节点及批量导入/复制保留原参数；后台生成结果不会刷新偏好。本次不修改数据库 schema。

`AINodeDialog.tsx` 切换图片模型时恢复该模型声明的默认画质、比例，未声明时沿用基础默认值；切换视频模型时清除上一模型的参数，由既有控件与生成解析器采用新模型默认值。重选相同模型保留参数；模型清除或工作流选择使当前类型的参数偏好失效，切回旧模型也不恢复旧缓存。

5. 为项目设置明确的图片/视频默认参数，再新建节点，预期项目配置优先；清除模型、切换工作流、旧缓存缺失/损坏或本地偏好不可用时，编辑与创建应继续可用。回归参数撤销/重做、深浅主题和连续输入时长/自定义分辨率。

## 快捷指令文件夹

自定义快捷指令按文本、图片、视频、音频分别管理一层逻辑文件夹。管理器提供新建、改名、移除和指令归类，未归类的指令直接列出，不自动显示「未分组」文件夹；只有用户创建的文件夹显示文件夹行。`/` 菜单由「快捷指令」直接打开二级列表，自建文件夹在二级列表内分区显示，不再增加菜单层级；子项仅显示名称与执行方式，说明留在悬浮提示。空的自建文件夹保留，旧记录及失效关联按无分类处理。移除文件夹原子解除关联并保留指令；保存成功后才更新 Store，失败保留草稿，分类变化不重载正在编辑的正文。

入口为 `PresetManager.tsx`、`SlashCommandMenu.tsx`、`store.presets.ts`、`utils/presetFolders.ts` 与 `indexedDb/catalogRepository.ts`。文件夹保存在既有 metadata，指令只新增可选 `folderId`，无需 schema 升级，不改变指令 ID、模型覆盖、模板或顺序执行语义。已实现，待用户验收；本次未运行测试。范围、回归用例与桌面验收见[快捷指令文件夹计划](./plans/2026-10-13-preset-folders.md)。

## 视频查询暂停与恢复

异步云视频拿到任务 ID 后，轮询超时改为暂停本地查询；视频节点和提示词窗口提供「重试」，继续查询/下载同一个远端任务。暂停记录在重启及项目切换后保留，等待用户续查；明确的上游失败仍显示错误。再次生成前，旧任务移到独立恢复节点，原节点生成新视频。结果保存及恢复回填复核项目、任务身份和画布版本，任务记录不保存 Key。提交阶段没有拿到 ID 的超时无法伪造恢复任务，也不自动重提。

实现入口：`pollTask.ts`、`pollManager.ts`、`VideoTaskStatus.tsx` 及视频生成适配器。已实现，待用户验收；本次未运行测试。范围、预算、回滚和桌面验收见[视频轮询恢复计划](./plans/2026-10-13-video-polling-recovery.md)。

- 自定义连接的图片模型在各自的调用协议设置中选择 GPT-Image 中转站 JSON、OpenAI 官方 Images、Google 原生图片或 xAI 原生文生图；不兼容时编辑高级自定义 JSON。图片与文本模型不展示复杂协议表单。短暂提供的连接级图片默认值只在编辑旧连接时复制到已选图片模型，不继续作为运行时隐式默认值。范围、验证和回滚见[图片调用协议选择计划](./plans/2026-09-23-image-protocol-selection.md)。

- 自定义协议的表单与 JSON 共用示例变量、脱敏请求预览、响应路径校验和 AI 配置说明复制入口；表单提交请求体复用 JSON 的左侧变量、右侧编辑框布局，点击变量插入光标位置或替换选中内容，窄窗口改为上下排列；轮询请求体保留紧凑输入框。布局调整待桌面验收。草稿或子表单无效时禁止试跑，执行前重新解析当前草稿。异步接口可用 `poll.response.result.download` 在轮询成功后按提交任务 ID 发起同源 GET 下载；与响应结果映射互斥，鉴权仅运行时注入，恢复描述只保存绑定任务的请求。下载失败或取消不重提生成。配置与验证见[自定义模型协议计划](./plans/2026-07-19-custom-model-execution-protocol.md#2026-10-07试跑一致性json-预览与任务结果下载)。
- 自定义视频协议的素材覆盖校验只统计真实素材 URL：`seedanceContent` 的 `type`、`role` 和提示词不算素材，检查子路径时保留原数组下标。标准整数组与原生 `content` 都可完整接收素材；只发第一项或漏发某类素材仍在提交前拦截。回归使用实际视频变量构造器，覆盖两图、内联素材、混合素材及模拟提交/轮询/下载，见 `modelProtocol.test.ts`、`generateVideo.test.ts`；桌面真实渠道调用仍待用户验收。
- 参考图按已声明协议传输：标准 `edits-multipart` 直接读取原图，不先上传第三方图床；高级自定义协议优先保留自身路径、字段和响应/轮询映射，multipart 的 `$file` 图片引用转换为受限 data URL 后编码为文件。`$file` 可接收数组并按原字段名提交多个文件；请求预览逐文件脱敏。APIMart 继续使用自身上传服务，未确认支持 multipart 的厂商不自动切换或失败后重提生成。
- 内置图片合同由 `resolveBuiltInImageRequestContract` 统一选择：CCC 目录中声明 `edits-multipart` 的图片模型使用 OpenAI Images；GRSAI 文档列出的 Nano Banana / GPT Image 使用原生 JSON。已确认合同执行时优先于旧 Provider、旧通用模型保存的参考图模式或 `executionProfile`；不迁移持久化配置。其他厂商、自定义连接、未收录模型与工作流保持原协议优先级，未知厂商不按模型名称猜协议。multipart 和 data URL 请求中的提示词参考图优先使用本地素材，不复用生成结果的远程 sourceUrl。自定义协议缺少参考图映射时仍在本地拦截。
- 参考图压缩复用 `prepareReferenceImageUpload`：标准 multipart、GRSAI/自定义 Base64、自定义文件表单、APIMart/通用图床、RunningHub 图片及工作流内联图片均接入。直接交给服务商读取的公网 URL 不额外下载转存；有效上传缓存继续复用，视频/音频保持原处理方式。
- 连线及 `@` 引用有本地副本的媒体时优先使用本地素材，不让生成结果的旧 `sourceUrl` 绕过上传缓存；需要公网 URL 的接口复用现有 2.5 小时上传缓存，到期重新上传，multipart 和内联接口沿用各自传输方式。只有公网地址的素材仍直传。验证入口：`generateVideo.test.ts`、`referenceImageTransport.test.ts`。
- 共享预处理先读取图片头：JPEG、静态 PNG、静态 WebP 的最长边达到 3840 px 时等比缩到 2048 px，再按透明像素输出 PNG 或 JPEG；不放大小图，超过 2400 万像素的超大源图仍保留原字节。未达到 4K 的图片继续沿用原规则：只有超过 4 MiB 的 8 位 RGB/RGBA 静态 PNG 才尝试 JPEG（质量参数 0.95），保留像素尺寸且体积减少超过 20% 才采用。RGBA / tRNS 按像素检测，存在任何真实透明像素就保留原图；动画、索引色、其他格式或解码失败也保留原字节。只改变临时上传副本，JPEG 转换属于有损压缩，不能将质量参数解释为保真百分比。
- 图片数组最多同时准备 2 项、全局一次解码压缩 1 张；按原下标回填，任何读取失败均中止该组，不过滤失败项造成参考编号错位。取消排队立即返回，仍在运行的浏览器编码结束并释放位图/画布后才释放解码槽。Base64 原图读取受既有 32 MiB 内存预算约束，压缩后仍执行单图 8 MiB、最多 6 张、合计 24 MiB 限制；媒体工作流保留自身预算。
- 自定义 multipart 图片的文件 MIME 和扩展名跟随实际 data URL 类型，覆盖模板遗留的 PNG 标记；预览与实际请求保持一致，路径、字段名和响应协议不变。标准图片网络提交失败或 HTTP 504 显示实际模型、参考图数量、提交体积及等待时间；原生错误只保留类别与系统错误码，不泄露 URL 参数。结果不确定时不自动重提生成。
- 自定义连接已移除「导入文档」按钮、示例解析面板、结果应用和撤销快照；模型仍可拉取、手动添加或通过助手配置，现有连接和已保存协议保持可编辑。JSON 配置文件导入导出独立保留。已实现，未运行测试，待用户桌面验收：打开已有自定义连接，确认没有文档导入入口，模型勾选、手动添加、参数模板与协议编辑仍可使用；先取消确认配置未变，再保存并重启确认设置保留。

## 帧动画节点

- [AnimationNode.tsx](../src/components/nodes/AnimationNode.tsx) 统一显示为「帧动画」，单击选中、双击打开懒加载编辑弹窗；生成通过按钮或空格键进入。编辑页复用 UI Kit 与深浅主题，采用大预览、右侧参数和底部帧序列；支持原图导入、宫格校正、帧排序/停用、像素偏移、帧率和循环控制。编辑器内快捷键不操作背后的画布。原图格数/动作保存为独立快照，不随下一次生成参数变化；应用编辑和导入可撤销。
- [animationPrompt.ts](../src/services/ai/animationPrompt.ts) 为单节点和批量生成共享提示词：明确身份图/动作图职责，固定朝向、比例、非对称细节、隐形中心轴与安全区。提示词不能保证每帧像素一致。
- [sprite_processing.rs](../src-tauri/src/media/sprite_processing.rs) 使用 Rust 完成绿/品红底色清理、软边去色、透明沟槽分帧、脚部/全体 Alpha 质心对齐和共同缩放；缩放后重新计算锚点，统一脚底线。跳跃默认保留纵向轨迹，可逐帧修正武器等造成的质心偏差。
- 原图只读；处理参数与编排持久化，预览只使用短期 Blob。导入/生成结果经过项目和画布派生守卫；关闭编辑器丢弃待返回的导入结果。原生命令复用调用方和路径授权，限制输入体积、像素及帧数。
- [sprite_export.rs](../src-tauri/src/media/sprite_export.rs) 与预览使用相同处理和帧编排，导出 GIF、PNG 序列帧或 PNG 图集 + JSON；JSON 包含绝对帧矩形、fps、loop、durations_ms。逐一授权派生文件，拒绝覆盖已有文件，失败清理本轮新文件。
- 不依赖 Python，不新增依赖或数据库版本。仅移植上述图像流程；视频转循环、RIFE、场景合成未接入。参考、验证与回滚见[专项计划](./plans/2026-10-07-animation-node-rust.md)。
