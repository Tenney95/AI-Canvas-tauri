## 用户操作与显示调度

### 节点提示词发送快捷键

`PromptPanel` 的发送按钮右键菜单和「设置 → 快捷键 → 发送快捷键」共用 `AppConfig.promptSubmitShortcut`，支持 Enter、Shift+Enter、Ctrl+Enter、Alt+Enter；未设置或非法值回落 Shift+Enter。选择后立即生效，通过既有 Store 配置保存队列持久化，保存失败保留错误状态与待保存修改。输入框提示与两处选择同步，菜单复用 UI Kit 并按窗口边界定位，支持方向键、Escape 和点击外部收起。

`MentionEditor` 精确匹配修饰键，中文输入法确认和普通 Enter 的 @ 候选选择优先于发送，按住发送键不重复触发。Enter 发送模式使用 Shift+Enter 换行，其他模式保留 Enter 换行；其他独立编辑器未指定新偏好时沿用原有父级按键配置。图片长按数量选择和点击单张生成保持原有入口。

验证入口：`tests/components/promptSubmitShortcut.test.ts`、`tests/store/config.test.ts`，与设置保存、引用编辑器共 72 项定向回归通过，应用/测试类型与定向 ESLint 通过。真实组件预览核对四种发送、换行、两个入口同步、空输入右键、菜单键盘选择、Escape 与深浅主题；配置重新加载由 Store 回归覆盖。尚未完成 Tauri 桌面端实测。

### 节点提示词引用交互

`MentionEditor` 通过 `mentionEditorChipDrag.ts` 的指针会话拖动引用胶囊：松开时移动，Ctrl/Alt 松开时复制；支持文字中间与跨行插入，复用既有 DOM 序列化、父级 Store Action 与媒体编号同步。使用原胶囊 DOM 或其深拷贝保留引用身份，不接收外部拖放 HTML；输入框外松开、Escape、失焦、源引用删除、提示词/节点切换或卸载时取消。工作流值区保留文字选择与内层引用拖动，工作流胶囊不能嵌套。回归入口：`tests/components/mentionEditorChipDrag.test.ts`，Tauri 桌面拖动与真实生成顺序仍需验收。

`AINodeDialog` 的紧凑提示词框将常驻缩略图条收进左上角同材质圆弧，最大化保留右上角；悬浮、键盘聚焦或点击展开引用扇形。`ConnectedNodesPreview` 沿同一圆弧显示全部素材，卡片方向朝向圆心，数量多时压缩间距并叠放，悬浮或聚焦的卡片置顶；复用点击引用、长按全屏、断开连线及宫格选择，窗口边缘按旋转后的卡片边界向面板内展开；其他宿主保留内联缩略图条。

`MentionEditor` 的 @ 节点胶囊悬浮显示实时内容小卡片，宫格显示所引用的裁片；滚动、切换节点和退出时清理悬浮状态，Escape 优先收起引用预览。样式归 `prompt.css`，沿用 UI Kit 与主题变量，减少动态效果时关闭扇形位移；不增加依赖或持久化状态，回滚不影响节点数据、连线格式或项目存储。

验证入口为 `tests/components/connectedNodesPreviewInteractions.test.ts`，引用几何与弹层定位共 21 项回归通过，覆盖 20 份素材叠放、径向旋转及 320px 窗口边界；独立真实组件预览验证深浅主题、全部素材展开、第五份素材点击引用与键盘聚焦置顶。此前 Tauri 开发桌面实测扇形展开、Escape 收起、@ 图像卡片、视频播放与最大化还原；当前径向叠放、桌面浅色与长按全屏仍待完整实测。扩大节点回归时，既有视频截帧测试仍查找旧 `<video>` 结构，1 项失败，本次未修改该节点或该测试。

## 关键边界

- `ai-app` 仅内部 Agent/MCP 可创建，用户可以打开、使用、保存和删除；菜单、复制、剪切复制及模板插入不能创建新实例。首版支持 HTML/CSS、Worker JavaScript、只读绑定素材及无界面动作；状态/结果须显式保存，写入复用项目版本与历史。代码更新先验证候选并读回不可变定义，失败保留旧版；当前节点与撤销栈里的定义文件均参与存储健康引用保护。阶段、限制及验收见 [AI 应用节点计划](./plans/2026-10-08-ai-app-node.md)。

- 分镜表及节点批量连线复用 Store 写入与一次历史快照。Agent/MCP `canvas_connect_nodes` 支持 `sourceIds` 多源连接，先校验整批并跳过重复与已有边；端口、布局提醒与兼容旧单源参数见[MCP 模块](./MCP控制模块.md)。
- [store.videoBatch.ts](../src/store/store.videoBatch.ts) 通过 [videoBatchPlanning.ts](../src/services/videoBatchPlanning.ts) 预检物料指纹，再由 [videoBatchRunner.ts](../src/services/videoBatchRunner.ts) 串行提交。取消只清理等待项，项目变化停止后续提交；重开后原在途项标记为待核对，不自动重投。批次保存在项目域 metadata，完整范围见[逐镜工作台计划](./plans/2026-09-24-episode-workbench.md)。

- 「设置 → 常规 → 素材引用」提供“连线后自动 @ 素材”，默认开启（旧配置未设置时同样开启）。新建普通/批量连线及连线创建节点时，Store 将真实上游节点引用追加到生成节点提示词，保留原文、按节点 ID 去重，分组来源展开为成员素材。关闭后新连线不追加引用，已有提示词与引用保留；切换开关不补写旧连线，提示词沿用现有撤销语义。复用普通配置保存与真实 MentionEditor 标签渲染；回归入口为 `tests/store/history.test.ts`、`tests/components/settingsPersistence.test.tsx`。
  正在编辑时后连入的素材由输入基线与实时 Store 提示词合并，避免旧 DOM 的输入/失焦回写覆盖新增引用；保留用户正文及主动删除的旧引用，按节点 ID 去重。DOM 在布局阶段同步，IME 组合输入期间延后刷新，先回写再结束连续编辑。此修复已实现、待用户在桌面端验收；补充回归为 `tests/components/promptConnectionMentions.test.ts` 与 `tests/components/nodeCriticalInteractions.test.tsx`，本次未运行测试。
  此前自动引用入口验证：103 项定向回归、应用/测试类型、定向 ESLint 与生产构建通过；最终布局另跑设置 9 项回归与应用类型。构建版 Web 页面实测深浅主题、开关保存刷新及拖线新建节点后真实 @ 标签显示；未验证桌面安装包和真实模型生成，不涵盖本次编辑同步修复。

- 分组与多选批量生成共用 `utils/batchExecute.ts`。工作流节点（带 `workflowId`）按界面展示编号数值升序串行执行，生成及结果保存结束后才启动下一项；缺少编号的旧节点排在最后并保留原顺序。同批普通节点仍按连线依赖串行、独立节点并发。编号顺序与依赖构成环时，环内工作流以编号顺序为准；单项失败后继续，不自动重试。队列仅约束本次批量调用，不合并其他批次或手动生成。回归入口：`tests/services/batchExecute.test.ts`；本次与音频及节点交互共 61 项回归、前端/测试类型与定向 ESLint 通过，未执行真实工作流生成。定向 Vitest 须排除 `.planning/**` 的旧源码副本，避免同名用例混入。回滚仅撤销调度及对应测试修改，无持久化迁移。

- 画布空白处右键可创建空白宫格分镜：支持 4/9/16/25 格预设、可视行列选择与 1–20 行、1–20 列输入。新宫格仍使用 `ai-storyboard` 的行列和空格数据，空格可接收拖入的图片；已有图片裁切生成的宫格保持原有语义。宫格创建和填格都进入画布历史。

- 展开分组的内部空白区透传画布事件，支持右键新建和连线拖放新建；标题栏负责整组拖动与管理，边框保留缩放。单节点创建按中心位置加入展开分组，拖入空节点与有内容节点使用同一套实际几何判定，父节点排序在子节点之前；节点、连线与成员关系共用操作历史，折叠分组不自动接收新建节点。

- 图片节点生成历史卡片支持将项目内普通媒体文件移入系统回收站并删除记录，也可仅删除记录；文件缺失时清理记录，仍被当前画布、对话或其他历史引用时拒绝回收。远程链接不发起服务器删除，项目切换后旧操作失效，回收失败保留记录。

- 按住 Command / Ctrl / Alt 拖拽节点时，副本只复用提示词、模型、工作流输入、生成参数与上游连线，清空已有内容、媒体文件身份和运行状态；原节点、原连线与下游引用保留，拖拽复制可一次撤销。生成节点和源素材节点均按空白副本处理，画布笔记仍完整复制，AI 应用节点沿用复制限制。普通复制粘贴与助手复制仍保留内容；媒体文件准备成功后才插入副本，失败不退回共享本地文件。回归入口为 `tests/store/clipboard.test.ts`。
- 分组归档、解组与改名真正移动文件，提交历史及资产引用迁移并保存后再清理源文件和空目录；失败保留源文件并记录待恢复迁移，旧共享节点先拆分。范围、回滚与验证见[独立媒体复制](./plans/2026-09-17-independent-media-copy.md)。

- 共享状态通过 Store Action 修改；画布写入纳入历史，批量操作只提交一次快照。
- 框选至少两个可连接节点后，选区右侧显示与普通节点端口同样外观的临时批量连接手柄。拖拽预览由每个源节点的右侧端口分别出线，并在鼠标位置汇合；拖拽开始锁定源节点与项目。连接已有标准节点时一次创建多条普通入边，重复边跳过且只提交一次历史；拖到空白处可一次创建目标与全部连线。手柄不作为画布节点持久化，插件类型端口、分组和笔记不参与。下游沿用各节点的现有普通连线输入语义；自动 @ 开启时同步补入提示词引用，文本生成仍以提示词中的 `@` 引用为准。
- 图片节点全屏预览通过 `CanvasImagePreview.tsx` 按展示编号升序浏览当前项目内有图的生成/源图片节点，跳过空节点和角色库收纳节点；两侧按钮与 ↑/↓（兼容 ←/→）切换，首尾不循环。切换复位缩放，浏览不修改画布选择和历史；关闭后释放预览，项目切换或当前图片节点消失时退出。
- 音频节点双击打开 `CanvasAudioPreview.tsx` 全屏播放器，支持播放/暂停、进度拖动、音量/静音及真实 Web Audio 频谱。当前项目有音频的生成/源音频节点按展示编号数值升序切歌，跳过空节点和角色库收纳节点，首尾不循环；播放结束自动进入下一曲，末曲停止。方向键切歌，滑块保留原生键盘操作；浏览不修改画布选择或历史。节点内播放交接到全屏，关闭、切歌、项目切换和当前来源失效时释放旧播放器及分析资源；跨域或分析能力不可用时使用独立普通媒体元素保留基础播放。详见[音频播放器计划](./plans/2026-09-16-audio-fullscreen/task_plan.md)。
- 图片节点在画布内使用按屏幕尺寸分档的项目磁盘缩略图与有界内存预览；三平台统一项目数据目录下的 `.thumbnail`，Windows 额外设置隐藏属性。高清查看和编辑仍使用原图；连接按钮缩放补偿由画布统一维护。资源队列、失效与回收边界见[大画布交互性能优化](./plans/2026-09-09-canvas-interaction-performance.md)。
- 节点工具条首次可见才挂载，随后隐藏时保留编辑和弹窗状态。视频待机使用共享内存封面，单选或实际操作时加载播放器，暂停且不再单选时释放；封面生成串行并服从画布交互暂停。历史面板隐藏时停止整图差异计算；完整节点、选择、连线和历史语义保持。
- 异步结果不能写入已切换的项目；笔记和普通节点复用选择、历史与持久化语义。
- MCP 剪辑只绑定当前项目的素材节点，工程更新比较完整版本；人工剪辑窗口打开时拒绝后台修改。输出最多 1080p 等像素面积、60 fps、300 秒；支持主轨、叠加文字、转场和音量包络。后台导出复用合成器，写盘前后复核工程、来源与画布，成功只提交一次历史；抽帧图像仅作为瞬时 MCP 内容返回。接口与验收边界见 [MCP 视频制作](./plans/2026-09-11-mcp-video-production/task_plan.md)。
- 分镜表使用稳定镜头 ID；局部修改保留画面绑定，补图绑定真实图片节点。镜号只读，按行顺序显示；新增、删除和拖动排序后同步重编号，镜头 ID 与素材绑定不变。支持双击表头或空白处全屏查看；表格始终铺满节点与全屏容器，镜号列固定 48px 并居中、时长列固定 84px，均不可调；其他列按剩余空间的百分比分配宽度，可拖动表头或在「列」菜单中微调，修改一列时其余列按原比例分配。旧像素列宽按相对比例读取，编辑后保存为列权重；隐藏列保留设置，恢复默认同时清除旧列宽与新权重。单元格和列设置复用 UI Kit 的 Number Stepper、输入、多行文本、勾选与 Select 下拉；景别、运镜、转场仍可选择自定义并编辑原文。列宽随节点保存，普通与全屏视图共用；拖动仅在松开后写入一次，取消、项目切换或画布版本变化时丢弃预览。镜头行、列、旧列宽与新列权重纳入结构化撤销快照。回归入口为 `tests/components/nodeCriticalInteractions.test.tsx`、`tests/store/history.test.ts`；分镜表与宫格分镜节点职责独立，范围及验收见[本集分镜制作与助手联动](./plans/2026-09-08-shotlist-production.md)。
- 补图取消立即停止本地等待并保留完成项，参数改动使排队/在途结果失效；再次补图只处理仍无绑定的镜头。助手读取镜头按 JSON 大小分页，须按返回偏移续读完整正文。
- 分镜表提供整表诊断与单镜优化的助手草稿入口，发送时读取最新镜头；单镜请求使用稳定 ID，并沿用会话模式与写入策略。

- 节点界面调用模型/文件服务，具体 Provider 请求归[模型与生成](./模型与生成模块.md)，项目落盘归[文件与存储](./文件与存储模块.md)。
