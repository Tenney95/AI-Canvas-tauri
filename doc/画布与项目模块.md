## 节点显示尺寸与估算边界

吸附、共享包围盒、分组命中和新建分组包围盒共用 `utils/nodeBounds.ts` 的 `getNodeSize()`。宽高逐轴按有效正数读取：实测 `measured` → React Flow 显式／初始化尺寸 → 数值或 px 样式 → 业务卡片／笔记尺寸 → 类型默认。没有实测值时仅估算，不将估值写回节点；百分比与相对单位不脱离容器解析。多选对齐、分布和压缩副本通过共享包围盒取得同样的显示尺寸。

吸附保留父链 Map 索引；创建分组按当前节点关联尺寸，不依赖选中顺序。逐镜排版与折叠展开主动设置目标尺寸的逻辑保留原职责。Q02 已实现，完成静态核对，本次未运行测试，待用户验收；定向回归、桌面步骤与回滚见[质量审查 Q02](./plans/2026-10-30-code-quality-audit.md#q02-p2-节点尺寸计算存在多套优先级)。

父链偏移由同一模块的 `getParentOffset()` 统一计算；当前节点与已访问祖先不会再次累加，缺失父级时保留已找到的偏移。包围盒、吸附及分组共用此规则，数组与 Map 均可输入，吸附不丢弃既有索引。读取不修复或持久化异常父链，也不代表归档及整个画布已支持坏数据。Q03 运行时保护已实现，静态核对完成，本次未运行测试，待用户验收；入口策略缺口与回归步骤见[质量审查 Q03](./plans/2026-10-30-code-quality-audit.md#q03-p2-两处父级遍历缺少循环终止条件)。

## 分组缩放与成员归属

展开分组在缩放松手后，通过 `store.nodes.ts` 的 `settleGroupMembersOnResizeEnd()` 一次性同步范围与成员：范围内可见、未锁定、尚未归组的普通节点加入；范围外的直接成员脱组。两向均沿用节点中心规则，中心在边界上仍归组。其他分组及其子节点不被收纳；已有子分组超出范围时整体脱离，自身成员保留。新成员转为相对坐标，脱组成员转为完整画布坐标并解除父级约束，不自动转入其他分组；画布位置、连线、模型与素材身份保留，空分组仍可继续调整。父节点排序和后续文件同步沿用既有链路。

缩放开始保留手势前快照，松手结算成员后保存结束快照；历史比较纳入分组显式宽高，撤销／重做同时还原该分组框、成员及左／上边缩放时补偿的子节点位置，其他分组保留独立布局。已实现并补充回归源码，提交时复用既有钩子执行本批 5 个 TS／TSX 文件的定向 ESLint；本次未运行测试、类型检查、构建或桌面验收，待用户验收。

Tauri 桌面验收：在一个音频节点位于组外的测试画布扩大分组，松开后节点数量应增加，拖动或折叠分组时该节点应跟随；再缩小至该节点中心落在组外，松开后计数应减少，节点留在原画布位置，拖动／折叠原组不再影响它。从右下及左上分别调整，核对同次加入／移出、嵌套坐标与连线不跳动；一次撤销／重做应同时恢复尺寸和归属。回归边界中心、脱空后保留分组、子分组整体脱离、隐藏／锁定节点不被吸纳、其他分组不被抢占，以及保存重开后的归属与素材可用性。未执行的回归命令（仓库根目录）：`npx vitest run tests/store/groupFolders.test.ts tests/store/history.test.ts tests/components/nodeCriticalInteractions.test.tsx`。

### 节点工具栏与快捷指令

图片节点工具栏的「无损压缩」复用 Rust OxiPNG / libjpeg-turbo，入口为 [imageLosslessCompression.ts](../src/services/imageLosslessCompression.ts)；上传与手动操作共用 [referenceImageUpload.ts](../src/services/ai/referenceImageUpload.ts) 的原格式校验和串行原生压缩队列。仅处理 PNG/JPEG 原始编码，不转码、不缩放；保持尺寸、透明度及既有元数据保护边界，动画或无法安全减重的文件保留原样。单图上限为 32 MiB、2400 万像素、单边 16384 像素，本地图片分段有界读取，远端沿用原生 HTTP，读取超时明确报错。

仅在结果实际变小时，才保存项目内独立文件并在源节点右侧创建素材副本；原节点、原文件、生成记录和资产绑定不变。无收益时只提示，不创建重复节点；读取、压缩或保存失败通过提示说明，不覆盖节点正文或状态。项目/revision、源节点及媒体字段在异步边界复核；切项目、删除、换图或取消后不发布迟到副本，已保存但未发布的文件尝试移入回收区。副本使用一次 Store 插入与撤销历史，按绝对位置复用现有分组规则。旧自定义工具栏可从「更多」使用，再加入自己的布局；不重置已有排序。
