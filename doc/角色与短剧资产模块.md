## 关键边界

- 全局角色与项目资产分开管理；分集以剧集的 `seriesOwnerId` 共享资产，删除单集不删除共享素材。
- 资产变更走领域服务和 Store Action；Agent 入口继续校验项目上下文和 `asset_write` 策略。
- 参考图与声音元数据复用媒体和文件服务，模型适配与二进制落盘分别归对应模块。
- MCP / Agent 新增 `drama_reference_image_add` 与 `drama_voice_add`：本机素材先通过 `file_import_media_to_canvas` 导入，再用 `assetId + nodeId` 绑定到项目或全局角色。工具只接受当前画布有效的对应媒体节点，不接受任意文件路径或 URL；沿用 `asset_write` 权限并复核项目与画布 revision。可指定素材用途和主素材，重复绑定同源节点复用素材 ID，返回精确角色引用；角色详情同时返回参考图 ID、用途和主图标记。源节点保持不变，不隐去、不生成；全局角色不保存项目节点 ID。新增源码需要重新加载应用后才能在 MCP 发现接口，真实音色效果需另行生成验收。
- 火山方舟虚拟人像库作为远端权威素材源，通过「设置 → API Key → 编辑火山方舟连接」弹窗内的独立可选配置启用，资产侧栏只负责查看与管理；项目名称默认 `default`。AK/SK 不进入普通配置或 IndexedDB，只保留 Rust 凭据条目引用。只有远端素材处于 `Active` 状态时才允许被 Seedance 生成入口消费。
- 有音频产物的生成音频、上传音频节点，右键提供「添加到角色库…」。复用角色添加弹窗的声音素材页，可试听并选择项目或全局已有角色、声音用途、台词及主音色；通过 `bindAudioNodeToCharacterVoice` 保存，沿用来源去重与资产持久化语义。弹窗的「添加后隐藏画布节点」默认勾选；仅保存成功且项目、源节点与画布 revision 仍有效时隐藏，取消勾选则保持显示。其他声音绑定入口不默认隐藏。
- 从画布添加动作素材（新建或追加）可选择添加后隐藏节点，默认勾选；动作缩略图右下角支持显示／隐藏切换。关联保存在来源项目节点的 `characterLibraryLinks` 中，按范围、角色、动作和素材 ID 区分，与参考图关联共存。
- 动作素材保存成功且项目、节点与 canvas revision 仍有效时才建立关联并隐藏；显隐复用画布历史与选中语义。移除素材、动作或角色时清理相应关联，无其他角色库关联的隐藏节点恢复显示。旧素材仅在当前画布有唯一媒体身份匹配时允许显隐，无对应节点或存在歧义时禁用按钮。
- 节点提示词的资产选择器在角色名旁提供「动作」入口，按动作、素材两级选择；有动作的单图或无图角色也可进入。动作引用保存角色、动作与素材 ID，读取库内素材，不随来源节点隐藏、删除或重新生成而改变；素材已删除或引用损坏时明确报错，不回落到主视觉。
- 动作图片与 GIF 进入参考图通道，视频进入视频生成的参考视频通道；文本模型、生图兼容入口与工作流文本输入沿用现有视频 URL 文本语义，不扩展模型能力。原参考图单选与合并引用保持兼容。
- 音频节点的资产选择器只列出库内有音频的角色，点击直接引用主音色；主音色不可用时取第一段有效音频。引用保存角色与声音片段 ID，读取库内音频，不随主音色切换或来源节点变化而替换；片段删除或引用损坏时明确报错。音频生成入口将其作为参考音频传给适配器，其他节点的图片与动作选择行为保持兼容。
- 视频生成节点的角色引用菜单在「动作」旁提供「声音」入口，列出角色全部声音片段并逐个插入指定声音的 @ 引用；只有声音的角色也可进入。失效片段禁用选择，引用复用既有角色声音协议与参考音频收集链路，实际支持范围由视频模型适配器决定。
- 视频参数的「参考角色」从角色库选图时，如该角色明确设置了可用主音色，同时保存参考音频；节点列表只展示一条角色记录并标示含主音色，移除角色时一起移除音频。普通连线图片没有角色声音，缺失或失效主音色不自动回落到其他片段；模型不支持参考音频时沿用生成前的能力校验，不绕过限制。
- 视频请求保留每个 @ 位置的角色 ID 与素材用途，合并显式素材、首尾帧和连线并去重后再编译编号与「角色参考对应」说明。同名角色使用本次请求内的角色序号区分；多图、多段声音和跨角色共用素材均保留归属。只重写系统生成的引用位置，不修改正文手写的编号；音色、台词、情绪分开标注，不自动把样本台词写入对白。归属信息仅在本次生成中使用，不增加持久化字段或向厂商发送未声明的接口字段。
- APIMart 带角色图片数组按适配器的首尾帧在前、参考图在后编译；独立首尾帧字段使用「首帧图片／尾帧图片」，不占参考图数组编号。本地工作流按本地素材数组编译角色引用，普通 ComfyUI／RunningHub 工作流保持既有 URL 提示词语义。实际外观与声音一致性仍取决于所选模型能力和真实生成结果。

- 创作资产支持按人物／场景／道具本地上传图片，也可给已有资产上传图片。桌面端复制到归属项目目录的 `Library/`，分集素材统一放在剧集目录；新资产默认以文件名命名，角色图片同步进入参考图库并设为主图。上传取消、复制失败或期间切换项目不会新增／绑定资产；浏览器模式仅保存图片数据，不承诺本地目录落盘。

## 界面入口与预览

创作资产同时可从资产大面板和 Tab 左侧资产库进入，角色库仍保留项目/全局范围。角色视频参考、动作视频和创作资产视频复用统一资源预览：封面按视口加载，点击后在所属面板内悬浮播放，切换项目/筛选或关闭面板清理旧播放器。预览不改变资产绑定或源文件；共享生命周期归[文件与存储](./文件与存储模块.md)。

节点 @ 资产候选按完整项目库分类与搜索，不截取前 20 条。共用 `MentionPicker` 保留全部卡片位置，缩略图复用 `ViewportImage` 的可视区加载与离开后延迟卸载；分类、搜索或下钻内容变化时滚动复位，键盘高亮只滚动卡片列表。面板限制视口高度，超出的卡片在内部滚动，滚轮不继续传给画布。图片资源生命周期沿用既有回归，完整候选与滚动定位见 `mentionEditorSources.test.ts`、`mentionPicker.test.tsx`；本次未运行测试，大量资产滚动、窗口边缘、小窗口及深浅主题仍待桌面验收。

角色卡片的声音列表默认收起，通过下方工具栏的声音图标展开／收起；收起时停止试听并关闭音频绑定列表。切换角色、项目／全局范围或重新打开角色库时恢复收起状态。

底部角色栏支持拖拽排序：图标抬起跟手、相邻角色弹簧让位，释放后回落；边缘自动滚动并露出最终落点。轻点仍选中角色，拖拽不切换当前预览，Esc／指针取消不保存；支持 Alt + 左右键及系统减少动态效果。交互入口为 `character/CharacterDock.tsx`。

手动顺序通过 `DramaCharacter.libraryOrder` 保存，项目角色沿用项目／剧集共享资产保存，全局角色仅在 IndexedDB 单事务更新排序字段；不重存媒体、不改变角色修改时间。首次排序前保留原来的最近修改顺序，排序后新增角色追加在末尾，跨范围复制不继承来源顺序。搜索仅交换可见角色占用的槽位，隐藏角色保持原位；保存失败回退排序字段，保留同时进行的角色编辑，旧项目结果不回填到新项目。

角色参考图与声音定位复用历史记录的定位后放大回弹动画。声音条目在当前画布存在来源节点时提供显示／隐藏按钮；节点隐藏时不显示定位按钮，通过显示按钮恢复后才可定位。

视频节点的角色声音引用卡片右下角提供试听／暂停按钮，试听不插入引用；切换列表或关闭菜单停止播放。引用菜单的资产卡片统一为 9:11 比例，无可用图片、动作或声音的角色禁用引用。

用户步骤见[角色与动作库](../site/manual.html#character-library)和[@ 动作素材](../site/manual.html#character-action-mentions)。
