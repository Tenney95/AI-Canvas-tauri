# 角色与短剧资产

负责全局角色库、项目人物/场景/道具、角色参考图与声音素材，以及剧集下各分集共享的资产语义。

## 主要入口

| 入口 | 职责 |
|---|---|
| [CharacterLibraryPanel.tsx](../src/components/CharacterLibraryPanel.tsx) / [characterLibraryService.ts](../src/services/characterLibraryService.ts) | 全局角色界面与数据服务 |
| [DramaAssetsPanel.tsx](../src/components/DramaAssetsPanel.tsx) / [store.dramaAssets.ts](../src/store/store.dramaAssets.ts) | 项目短剧资产与状态操作 |
| [characterReferenceMerge.ts](../src/services/characterReferenceMerge.ts) / [dramaAssetPrompt.ts](../src/services/dramaAssetPrompt.ts) | 角色参考媒体与提示词组合 |
| [dramaAssetTools.ts](../src/services/chat/tools/dramaAssetTools.ts) / [dramaAssets.ts](../src/types/dramaAssets.ts) | Agent 工具适配与领域类型 |

## 关键边界

- 全局角色与项目资产分开管理；分集以剧集的 `seriesOwnerId` 共享资产，删除单集不删除共享素材。
- 资产变更走领域服务和 Store Action；Agent 入口继续校验项目上下文和 `asset_write` 策略。
- 参考图与声音元数据复用媒体和文件服务，模型适配与二进制落盘分别归对应模块。
