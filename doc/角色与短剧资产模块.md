## 作用域与资产身份

项目资产保存在 `CanvasProject.dramaAssets`；分集以 `seriesOwnerId` 使用所属剧集资产库，删除单集不删除共享素材。全局角色沿用唯一的 `globalCharacters` 记录，场景／道具存于 `globalDramaAssets`，不依赖项目节点。全局分类与导入文件、外部文件夹分开，普通目录不按名称自动分类。删除创作卡片保留共用媒体，文件删除仍由文件入口处理。

项目与全局复制得到独立的业务卡片和目标媒体身份，后续编辑不自动双向同步，也不按同名合并。全局媒体先保存到受管目录再写元数据，剥离源项目节点和路径；本集绑定全局资产同样先复制到本剧。文件落盘与使用位置查询归[文件与存储](./文件与存储模块.md)，项目云端共享另见[S3 同步专项](./plans/2026-10-26-shared-asset-library-s3-sync.md)，不等同于全局库自动同步。

旧单图角色的 `imageNodeId/imageUrl` 在读取时归一化为首张参考图，保留旧字段兼容；每张图有独立身份、用途、提示词和来源，主视觉与默认头像分别唯一。场景／道具支持最多 32 张参考图及标题、说明，主图保留顶层兼容投影；显式清空后不补回旧图。声音和动作仅属于人物。

## 资产包与列表管理

项目、全局和 @ 候选共用名称、别名、声音、动作及领域字段搜索。创作列表的名称／创建时间／更新时间排序与升降序独立持久化，不改变角色栏的手动顺序；多选只处理可见卡片，分类、搜索、项目或本次导入视图变化后清理选择。使用位置查询和删除影响读取失败时，不得按“未使用”继续删除。

项目顶部导出全部创作资产，全局顶部导出当前分类，均不受搜索影响；卡片导出单项，多选导出所选条目。`.aicassets` 只含所选资产及依赖媒体，不含整个项目、画布、对话、凭据或环境绑定。导入先校验和预览，再按全新身份追加；全局人物与场景／道具跨两表原子追加，无当前项目也能操作。项目保存、媒体提交及迟到取消的边界、默认文件名、四语交互和异常验收统一见[素材库管理与资产包专项](./plans/2026-10-24-asset-library-management.md)。

人物卡片主体直接打开对应范围的角色界面，声音／动作按钮定位相应区域，资源库保留在背景。全局卡片不提供“解绑图”；项目卡片解绑需二次确认，清除图片关联但保留声音、动作、节点和文件，确认期间目标变化不得继续提交。入口层级及整页／弹窗／抽屉回归也归上述专项。

角色库上方参考图支持鼠标拖拽排序及 Alt + 左右方向键移动。拖动只预览，松开后通过 `saveCharacterCard` 保存参考图数组；左右边缘自动滚动，Esc、失焦或列表／版式更新取消拖动。排序保留参考图身份、主图、头像及当前选中项，项目切换或旧视图失效后不提交。已实现，本次未运行测试，待 Tauri 桌面验收：分别准备项目／全局角色的三张不同比例参考图，拖动首尾图跨位并关闭重开，顺序应保留；检查轻点选图、双击编辑、右键菜单、键盘排序、单图、边缘滚动、Esc 取消及拖动中切角色／项目，主图与头像应保持原图，深浅主题均可见。定向回归入口（仓库根目录，由用户执行）：`npx vitest run tests/components/CharacterReferenceGallery.test.tsx`。

## 武器分类与角色关联

武器使用 `DramaProp.propType='weapon'`，沿用道具表和 `@drama` 协议；项目、全局与 @ 选择器提供独立分类，普通道具不重复包含武器。「角色库 → 武器」用通用弹窗多选同库武器，无图条目也可绑定，每个角色最多 64 项。同一武器可绑定多个角色；角色引用不自动带入武器参考图，生成时由用户显式选择武器。

角色 `weaponIds` 记录同一作用域的业务卡片 ID，分集使用所属剧集资产库。解绑与删除角色不删除武器；删除武器清理角色关联并保留本地媒体，全局操作在同一 IndexedDB 事务内完成。仍被绑定的武器须先解绑才可改成普通道具。失效绑定允许明确移除，不按同名补绑。

导出、导入与跨库复制由 `characterWeapons.ts` 和现有资产包服务统一补齐武器依赖、重映射目标身份；本集绑定全局角色也沿用这条路径。云同步复用顶层卡片映射，武器先于角色发布／下载；前后端均校验字段与 ID。本次不新增数据库表、依赖、原生命令或权限。旧资料可继续读取；团队处理带新字段的共享资料时应统一升级客户端。

实施范围、回归用例及 Tauri 桌面验收步骤见[武器分类与角色绑定计划](./plans/2026-10-28-character-weapons.md)。本次未运行测试，待用户验收；重点检查重开后的多武器绑定、删除后的解绑、单角色导入导出、跨库复制和两台客户端同步。

## 本集清单与提取

剧本工作台的「本集角色」「本集场景」「本集道具」按分集保存独立清单，正式资产仍归全剧共用库。AI 读取当前已保存正文，只返回待审候选；确认后才进入本集清单，另行选择「加入资产库」才创建正式资产。右侧全剧提取也先预览，不自动加入当前分集。本集说明、备注、出现场次和剧本依据不覆盖正式资产设定。

绑定使用 `DramaAsset.id`，无图资产也可选择；同名只提示，不自动绑定／覆盖。重提取保留人工编辑与绑定，移出本集／解绑保留正式资产和文件，已删目标显示失效。提交复核精确分集、所属剧集、正文与清单版本，切走再切回也拒绝旧结果。正式入库与绑定分别等待保存；资产已保存但绑定失败时保留资产，重试复用稳定身份。

本集清单复用分集保存、摘要及整剧归档，外部记录经过版本、字段、大小与 ID 白名单归一化；场景列表使用可选 `scenes` 字段，缺省视为空，旧记录归一化不强加该字段；不新增数据库表，不属于独立 `.aicassets` 包或当前 OSS 正式资产同步协议。分镜准备只将有效绑定编译为真实 `@drama` 引用，未绑定／失效项保留文字，条目说明中的标记不变成额外媒体输入，不创建角色／场景／道具连线。左侧分集标题固定、列表在剩余高度内独立滚动，小窗口保留横向列表；主弹窗与独立窗口共用此布局。本集场景及滚动修复已实现，本次未运行测试，待用户验收；桌面验收、回退前归档及旧版重新保存可能丢清单的限制见[本集资产清单计划](./plans/2026-10-28-episode-asset-roster.md)。

文本节点的提取入口与工作台预览分别保留各自输出合同。`dramaAssetExtract.ts` 共用输入与结果校验：内置模板正文为空或仅有占位符时，用当前节点可见 `output` 补正文；面板和直接执行补齐后追加项目提示词，分组沿用原组合。已有正文或显式 @ 保持原样，仅连线不自动注入上游文本；无可用正文／引用时请求前提示。

节点面板、直接执行及分组批量均先校验结果。无效 JSON、空条目、错误类别或请求失败时保留原 `output`，节点错误与失败历史记录原因，不写成功记录、不入库，也不把模型原文当正文；有效结果才按该入口更新简介表及合并入库。工具条派生新节点的引用语义不变。

## 参考媒体与画布收纳

从有产物的图片节点添加新角色或追加参考图时，通过领域服务及 Store Action 校验素材、保存角色，再建立来源关联和按用户选择隐藏节点；同一节点重复加入同一角色复用原参考图。图片／角色持久化失败时保留源节点可见并提示，不能先隐藏再把失败当成功。隐藏节点的连线仅随可见性过滤，显隐复用画布历史；取消、切项目或目标失效不能隐藏其他项目节点。移除关联、参考图或角色后，已无其他角色库关联的隐藏节点恢复显示；源节点缺失时可从有效库媒体创建新节点，不能假定位旧节点。

音频节点右键「添加到角色库…」复用声音页，可试听并选择已有角色、用途、台词及主音色；`bindAudioNodeToCharacterVoice` 沿来源去重，添加后隐藏默认勾选，仅保存成功且项目、源节点与 canvas revision 仍有效时隐藏。其他声音绑定入口不默认隐藏。动作素材新建／追加也可选择保存后隐藏，默认勾选；关联以 `characterLibraryLinks` 的范围、角色、动作和素材 ID 区分。旧素材只有当前画布中存在唯一媒体匹配才可显隐，无对应节点或歧义时禁用。

本地上传图片复制到所属项目的 `Library/`，分集使用剧集目录，新卡片以文件名命名，人物同步为主参考图。取消、复制失败或切项目不新增／绑定；Web 演示只保存数据，不承诺桌面目录落盘。角色参考图、声音定位复用历史定位动效；隐藏节点先恢复显示再定位。

角色的声音列表默认收起，切角色、范围或重开后恢复收起，收起时停止试听并关闭绑定列表。底部 `CharacterDock` 支持点击、拖拽让位、边缘滚动、Esc／指针取消、Alt + 左右键及减少动态效果。`libraryOrder` 仅更新排序：全局在单事务中保存，不重存媒体或改变修改时间；首次排序前沿最近修改顺序，排序后新增追加，跨库复制不继承源顺序，搜索只交换可见槽位。失败回退排序字段并保留其他编辑，旧项目结果不回填新项目。

角色可关联 ComfyUI RefMod 包，`DramaCharacter.refmods` 只记录服务器身份、加载格式、精确文件名和默认强度，不保存工作流槽位或替换授权；不复制／转换模型。H3 多人物仍须匹配目标服务器与加载器，不编造角色编号。兼容范围与待完成的桌面验收见[RefMod 接入计划](./plans/2026-10-22-comfyui-refmod-library.md)。

火山方舟虚拟人像是远端权威源，由「设置 → API Key → 编辑火山方舟连接」中的可选配置启用，项目名默认 `default`；资产侧栏只管理展示。AK/SK 只留 Rust 凭据引用，不进普通配置或 IndexedDB，只有远端 `Active` 素材能进入 Seedance。

## 生成引用与 MCP

库中人物、场景和道具（含武器）统一插入 `@drama` 胶囊，显示名称和库来源；单图也保存确切参考图 ID，不转成数字节点引用。换主图不替换已有单图引用，删除所选图明确失败；多图、动作和声音沿既有下钻选择。全局身份保留 `global/`，旧普通节点引用不猜测迁移，库引用不自动连线。

动作引用保存角色／动作／素材 ID，不随源节点隐藏、删除或再生成而改变；损坏时不回落主视觉。动作图片／GIF 进参考图通道，视频进视频参考通道；文本模型、生图兼容入口与工作流文本沿原视频 URL 语义，不扩展模型能力。

音频节点只列有有效声音的人物，直接选择主音色，不可用时取首段有效声音；选定后固定片段 ID，不随主音色变化替换。视频角色引用可选择特定声音，只有声音的角色也可进入；失效项禁选，卡片试听不插入引用，关列表停止播放。音频能否生成由模型适配器检查。

视频参数「参考角色」复用真实 `MentionPicker`，按项目／全局分别搜索，不列连线图片；「参考帧」仍从连线选择，实际能力校验继续统计连线素材。同 ID 不混范围，全局角色不从当前节点补图，旧引用只显示／移除，不自动迁移。选择主图时仅自动携带明确且可用的主音色，移除角色一并移除音频；缺失时不回退其他片段，方舟绑定及模型能力检查仍生效。

视频请求在本次内存中保留每个 @ 的角色和素材用途，合并显式素材、首尾帧和连线去重后编译编号与角色对应；同名、多图、多段声音及共用素材不丢归属。只重写系统生成的位置，不改手写编号或把样本台词当对白，不添加未声明接口字段。APIMart 按首尾帧在前编译图片数组，独立首尾帧字段不占参考图编号；本地工作流按本地数组编译，普通 ComfyUI／RunningHub 保持既有 URL 文本语义。实际一致性仍需真实生成验收。

Agent／MCP 写入走领域服务和 `asset_write`，复核项目、取消与画布 revision。`drama_reference_image_add` 接受当前画布 `assetId + nodeId`，覆盖项目／全局人物、场景和道具；外部文件须先经 `file_import_media_to_canvas`，不接受任意路径／URL。人物可指定用途与主图，场景／道具追加独立参考图并返回精确引用；全局素材固化到全局目录，不存项目节点 ID，不隐藏或生成源节点。`drama_voice_add` 仅绑定人物声音。

`canvas_create_nodes` 的项目 `ai-image` 可关联已有 `dramaAssetId`，整批先校验资产和类型；仅保存关联，生成成功再经 `syncDramaAssetImageFromNode` 回填，不额外调用资产写入或模型。已有图用 `drama_reference_image_add`，未知资产／非图片生成节点整批拒绝。

MCP 写提示词时，唯一匹配库中同一可用图片的节点引用优先转精确 `@drama`，项目优先全局且保留 Picture 顺序。名称不参与匹配；歧义、缺图、分镜单格、非图片及普通内部助手显式节点引用不转换。`canvas_query(detail=true)` 给 `preferredMention`，资产查询给 `imageReady` 与项目绑定节点 ID；只有文字不算图片输入，不新建引用线或擅删已有线。

## 选择器与预览

资源库的 @ 导航只浏览／选择，复用创作分类与文件夹，不提供管理操作；目录、标签、搜索组合过滤，音频节点创作分类只提供有声音的人物。项目候选取完整库，不截前 20 条；`MentionPicker` 保留卡片位置，`ViewportImage` 按可视区加载和延迟卸载，分类／搜索／下钻变化复位滚动。列表内部滚动不传给画布，键盘高亮只滚动卡片区。

资产库、角色库和文件胶囊复用节点悬浮卡片、120ms 延迟与交互抑制，精确展示指定图／动作／声音。全部图最多四格并标总数，无图显示简介，文件图仅悬停后解析 URL，不扫描目录。库引用不高亮节点或连线；切项目、滚动、按下、拖动时隐藏，异步结果不能重开旧浮窗。角色视频参考、动作及创作资产视频共用封面加载与面板内悬浮播放，切项目／筛选或关闭面板清理播放器，不改变绑定及源文件；共享生命周期归[文件与存储](./文件与存储模块.md)。
